# 方子（Fangzi）

> 说说你遇到的问题，给你开个小方子。

「方子」是一个覆盖**生活、工作、合规、开发、安全**等场景的单点工具集合 PWA（渐进式 Web 应用）。每个工具只解决一个具体痛点，用户用一句口语化的问题搜索，就能对症找到并直接使用；也可以把常用工具收藏到首页。

- **极简首页**：一个搜索框 + 一个「开方子」按钮 + 随机浮动的常见提问。
- **双模式检索**：默认高质量中文关键词检索（2-gram + 关键词重叠 + 命中高亮）；配置 OpenAI 兼容 Embedding 后自动升级为「向量 + 关键词」混合排序，接口异常时自动降级，用户无感。
- **强可扩展工具框架**：新增一个工具只需新增一个目录、填一份 manifest，**零核心改动、零路由改动、零检索改动**，并提供脚手架命令。
- **内置计费能力**：免费 / 一次性买断 / Freemium / 按次（量）计费四种模式，网页工具与插件统一接入。
- **可安装、可离线**：PWA 支持添加到桌面，Service Worker 预缓存应用外壳。
- **移动端原生体验**：手机上主导航移至屏幕底部、自动避让刘海与 Home 指示条、边到边布局最大化屏幕；小游戏、健身摄像头等强沉浸工具可一键全屏（应用内沉浸全平台保底，支持处再叠加系统全屏），PC 端仍保持顶部导航与桌面布局不变。

## 快速开始

```bash
# 环境要求：Node.js >= 20.19（推荐 22 LTS）
npm install        # 安装依赖
npm run dev        # 本地开发，默认 http://localhost:5173
npm run build      # 类型检查 + 生产构建，产物在 dist/
npm run preview    # 本地预览生产产物，默认 http://localhost:4173
```

质量与工具相关命令：

```bash
npm test           # 运行单元测试（搜索 / 计费 / 业务算法等）
npm run type-check # 仅做严格类型检查（vue-tsc --noEmit）
npm run verify:tools  # 用真实搜索引擎回归校验首页示例提问，保证每条都搜得到对应工具
npm run new:tool -- <kebab-id> <web|plugin> "工具名称"  # 生成新工具骨架
```

## 如何新增一个工具（可扩展框架）

工具框架基于 Vite 的 `import.meta.glob` **自动发现**，约定目录：

```
src/tools/<tool-id>/
├── manifest.ts   # 必需：工具元数据（名称/分类/关键词/场景/痛点/计费等）
├── index.vue     # type=web 必需：工具页面（固定位置自动带「用户指导 / 收藏」工具条）
└── guide.md      # 用户指导（web 可选；type=plugin 必需，作为使用手册）
```

新增步骤：

1. **生成骨架**
   ```bash
   npm run new:tool -- my-helper web "我的助手"
   # 插件类把 web 换成 plugin
   ```
2. **补全 `manifest.ts`**：重点写好 `keywords`（含同义词、口语说法）、`scenarios`、`painPoints`、`targetUsers`——这些字段质量直接决定搜索命中率；并声明 `billing` 计费规则。
3. **实现工具**：网页工具完善 `index.vue`（需要计费时 `const billing = useToolBilling('my-helper')`）；插件工具写好 `guide.md` 手册，并把压缩包放到 `public/plugins/<tool-id>/`，用 `sha256sum` 回填 `sha256` 与 `sizeBytes`。
4. **校验**：运行 `npm run verify:tools`（若希望它出现在首页浮动提问，在 `src/core/sample-queries.ts` 增加一条并指定 `expectToolId`）。
5. **登记**：更新本 README 的工具清单（七字段 + 更新时间）。

无需修改注册表、路由表、搜索代码或首页——应用启动时会自动发现并对 manifest 做合法性校验（id 与目录一致、日期合法、计费字段自洽、web 必须有 index.vue、plugin 必须有手册和下载声明），不合法会直接报错并指出问题。

## 检索引擎说明

- **关键词模式（默认，零配置）**：中文按 2-gram（bigram）切词并以单字回退，拉丁字母按整词；对名称、简介、场景、痛点、关键词、目标用户做字段加权覆盖率 + 关键词整词重叠打分；命中片段经转义后用 `<mark>` 安全高亮。
- **混合模式（配置 AI 后）**：调用 OpenAI 兼容 `/embeddings` 生成向量，余弦相似度与关键词得分用 RRF（k=60）融合排序；向量缓存在 IndexedDB（按模型隔离、内容哈希去重）。接口 8 秒超时或报错时**自动降级**为纯关键词，检索不中断。
- 在「设置」页配置 **接口基础地址 / 嵌入模型名 / API Key**（仅保存在本机浏览器），或构建期注入环境变量。

## 计费框架说明

计费为 Provider 抽象（`src/core/billing/`）：

- 默认 `LocalMockProvider`：下单即到账，订单、权益、用量存本机，离线即可完整演示。
- 配置 `VITE_BILLING_ENDPOINT` 后切换 `RemoteBillingProvider`，与自有支付后端对接（前端不接触支付密钥）。
- 支持权益判定、买断授权、Freemium 功能开关、按次额度扣减、额度包购买与周期重置；插件类同样通过授权码接入。

## 多卡还款日·免息期管家（card-billing · 2026-10-19）

- **简介**：集中管理多张信用卡账单日与还款日的本地工具。确定性日期引擎支持「账单日后第 N 天 / 固定每月某日」两种还款日规则、账单日 31 号小月自动落到月末、跨年顺延；还款看板按还款日从近到远倒计时（逾期/今天/3 天内分级标色），可一键标记已还/撤销并导出 `.ics` 还款提醒；免息期选卡器输入计划消费日即按可享免息天数排序、推荐最长免息卡（账单日当天消费计入当期/下期可切换）；年费刷免追踪笔数/金额达标进度；按默认日利率万分之五演示循环利息、分期手续费与违约金。**不录完整卡号/密码/CVV、不代查账单、不自动还款、不碰资金，全程只存本机。**
