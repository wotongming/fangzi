# 家庭财务管家 · 用户指导

## 这个工具解决什么问题

把微信、支付宝、银行卡等各平台的收支拢进一个**本地家庭账本**，提供记账分类、月度预算与超支预警、月/年报表与趋势、省钱洞察，形成「记录 → 分析 → 决策 → 行动」的财务闭环。数据只存在你浏览器的 IndexedDB 里，不上传服务器。

## 怎么用

1. **记账**：在「记账」页选支出/收入，输入金额、分类（可自定义）、平台、日期与备注，点「记一笔」。首页「最近流水」可随时删除误记。
2. **看板**：查看本月收入、支出、结余，支出分类占比环形图与平台分布，快速知道钱花哪了。
3. **预算**：在「预算」页为总支出或每个分类设置每月预算（元），保存后实时显示使用进度，超支变红。
4. **报表**（Pro）：「报表」页选月份查看收入/支出/结余、分类占比、环比变化、月内日趋势与近 12 个月趋势图。
5. **洞察**（Pro）：「洞察」页给出高占比类目、预算超支、环比上升、储蓄率等省钱建议。
6. **备份**：页面底部可导出/导入备份；开启加密口令后导出为 AES-GCM 加密备份（Pro）。

## 注意事项 / 边界

- 数据存浏览器本地，**清除浏览器数据会丢失账目**，建议定期导出备份。
- 金额单位为人民币元，展示保留两位小数。
- 加密备份口令忘记无法找回，请妥善保存。
- 工具为 PWA 内网页功能，离线可用；多端同步为后续可选能力（当前为本地加密备份）。
