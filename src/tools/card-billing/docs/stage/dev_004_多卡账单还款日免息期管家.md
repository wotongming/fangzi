## 技术选型落地
Vue3+TS+Vite；IndexedDB（库 `fangzi-card-billing` v1：cards/payments/feeYears）；Notification、Blob/.ics；零新增 npm 依赖；金额整数分；fflate 不需要。

## 模块设计
- `models.ts`：Card/PaymentRecord/FeeYear/Enums + 日期/整数分工具。
- `cycle.ts`：`billingCycle(card, today)`、`repaymentDate(card, billingDate)`、`interestFreeDays(card, spendDate, today)`；月份工具处理 dayOfMonth（账单日31在小月落到月末，规则 `clampToMonthEnd`）。
- `timeline.ts`：给定月聚合事件 `{cardId,type:'bill'|'due',date,daysLeft,urgency}`。
- `annual-fee.ts`：年费年度窗口、达标判定。
- `interest.ts`：利息/违约金演示（默认日利率 0.0005 可改，强调估算）。
- `store.ts`：openDB/txn + 深度 toRaw（保留 Blob/Date）再 put（沿用 shopping-claim 修复）。
- `notify.ts`：buildICS（VALARM）+ requestNotification。
- `manifest.ts`：id `card-billing`、category `life`、type web、freemium（FREE_CARD_LIMIT=2，priceCents 买断、subscription 月/年），features basic/multi/picker/fee/interest。
- `index.vue`：顶部吸顶 `.seg`（看板/卡片/选卡器/年费/设置）+ 编辑表单（editing 态，避免 v-if 分支吞表单）+ 升级卡；禁止 fixed 底栏。

## 关键实现方法（伪代码）
```
repaymentDate(card, billDate):
  d = card.dueMode==='fixed' ? dateInSameOrNextMonth(billDate, card.dueDay)
                             : addDays(billDate, card.dueOffsetDays)
  return clampMonthEnd(d)
cycle(card, today): // 取 today 所在账期（账单日当天按 postingCutoff 归属）
interestFreeDays(card, spend, today):
  bill = firstBillingDateOnOrAfter(spend) // 账单日当天归属规则
  due = repaymentDate(card, bill)
  return diffDays(due, spend)
```
数字输入一律 `String(x??'')` 归一；写库前 toPlain 深度 toRaw。
