# 部署运维指引：多卡账单日·还款日免息期管家

- 对应 architect：architect_004_多卡账单还款日免息期管家.md
- 编写日期：2026-10-19

## 部署架构与环境准备
纯静态 PWA，**无后端、不接银行、不碰资金**；EdgeOne Pages 托管 main 自动部署。数据仅本地 IndexedDB（卡名/尾号/日期，不存卡号密码）。

## 软硬件配置清单
无服务器；仓库 Node/npm 构建链；Playwright 用于发布前验证。

## 部署步骤
1. `npm ci`；2. `npx vue-tsc --noEmit`（0 错）；3. `npm test`（含 card-billing 日期引擎单测）；4. `npm run build`；5. `npm run verify:tools`（=25）；6. 显式路径提交推送 main，EdgeOne 自动发布；7. 访问 `https://www.fangzi.asia/#/t/card-billing` 抽测建卡/选卡/年费。

## 配置项说明
账单日归属（默认账单日消费入下期）、还款日模式（固定日/账单后N天）、利息日利率（默认 0.0005，可编辑）均为前端常量/用户可改；无环境变量、无密钥、无第三方接口。

## 上线/灰度方案
随主站静态全量；可先在 EdgeOne 预览环境验证；回滚=回退 `src/tools/card-billing/` 所在提交（自动发现、零耦合，不影响其他工具）。

## 平台对接指南
- **EdgeOne Pages**：GitCode main 连接自动构建静态站，免费额度（5GiB / 20000 文件 / 单文件 25MiB）；本工具零大资产；不使用服务端函数。
- 无银行/支付/插件商店对接；计费为方子统一前端框架（useToolBilling），不处理真实支付通道。

## 运维监控指标与告警
无服务端日志/指标；依赖 EdgeOne 平台统计。关注点：不同银行还款日规则差异（固定日 vs 账单后 N 天、个别银行遇周末规则）——保持规则可配置并在 UI 标注"以银行账单为准"；移动端通知不可达以 .ics 导入系统日历兜底（已提示）。

## 日志管理/备份与容灾
无服务端数据；提供 JSON/日历导出供换机；清浏览器数据会丢失，首次进入明示。

## 常见故障排查与回滚预案
- 免息天数/还款日不对：先核对卡片的账单日与还款模式配置，再用 `test/card-billing.test.ts` 定位 cycle 纯函数（大小月/跨年/账单日归属）。
- 保存无反应：检查 number 输入是否 String 归一、写库前是否深度 toRaw（防 Proxy 结构化克隆失败）。
- 提醒不响：检查 Notification 授权；改用 .ics。
- 严重缺陷：直接回退该工具目录提交即下线，不影响方子主体。
