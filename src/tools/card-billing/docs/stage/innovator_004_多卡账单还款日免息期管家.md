# 功能建议：多卡账单日·还款日免息期管家

- 序号：004
- 建议形态：网页应用（PWA，纯前端本地工具）

## 使用场景
谁：持有 2 张以上信用卡/花呗等账单制信贷的用户、想用足免息期的人、担心年费刷免次数不够的人。
时机：每月账单日/还款日分散；大额消费前想选免息期最长的卡；年初想确认各卡年费刷免进度；出国/长假怕漏还。
问题：各卡账单日、还款日、出账规则不同，靠记忆易漏还（罚息+违约金+征信）；不知哪张卡当下刷最划算（最长免息期）；年费减免需刷满笔数/金额易忘；不愿把全部银行卡授权绑给第三方聚合 App（隐私/安全顾虑）。

## 功能描述
1. 卡片档案：录入卡名、尾号、账单日、还款日（或"账单日后 N 天"规则）、额度、年费规则（金额/刷免笔数/金额/年周期），不录卡号密码。
2. 每月还款时间线：按日列出本月所有卡的账单日、还款日、建议还款额（手动填或按账单），倒计时与已还标记，.ics/Notification 多级提醒。
3. 免息期选卡器：输入计划消费日期，计算各卡该笔消费可享的免息天数，推荐最长免息卡（含账单日次日最优规律说明）。
4. 年费刷免追踪：按年费年度统计已刷笔数/金额，临近期满提示还需刷几笔，避免被扣年费。
5. 免息期/利息测算：按全额还款/最低还款/分期，演示利息差异（明确以银行账单为准）。
6. 零授权隐私：全部本地，不碰账号密码、不自动扣款，仅做规划与提醒，还款跳转用户自行去银行渠道。

## 目标人群
中国数亿持卡人中的多卡用户（规模大）。付费意愿：一次逾期罚息+违约金+征信代价远超工具价，"省利息、免年费、保征信"是直接资金价值；每月刚需、持续高频。

## 建议形态
PWA：用户对"把银行卡账号密码交给第三方"高度警惕，纯手动、本地、只读规划的工具反而安心；每月查看、随时选卡，手机+PC 皆可；无需后端。

## 落地价值
省资金（避免罚息违约金、用足免息期、刷免年费）、保征信、省对账时间。多场景链路：用卡选卡（消费当下）→ 月度还款规划提醒 → 年费周期管理 → 利息测算 → 全年复盘，贯穿日常支付全周期。

## 多场景链路与红海规避判断
- 是否同质化小工具：否（不是单卡还款日闹钟，含多卡时间线、免息期选卡、年费刷免、利息测算的决策链路）。
- 多场景链路：消费决策→账单→还款→年费→年度，月频持续。
- 持续使用频次与付费空间：每月多次、长期；可买断或年度订阅（高级选卡/年费规则库/多张卡）。
- 红海规避：云闪付等聚合工具强但需绑卡授权、偏支付通道；银行 App 各管各的；差异化在**零授权、纯本地、不碰资金、专注"规划/选卡/年费/提醒"的中立计算器**，服务不愿授权的谨慎用户。

## 强规则核对
| 强规则 | 是否满足 | 依据 |
| --- | --- | --- |
| 真实价值 | 是 | 避免逾期罚息与征信损失、用足免息期、免年费（直接省钱） |
| 购买意愿 | 是 | 多卡用户规模大、月频刚需，一次逾期代价即覆盖付费 |
| 形态贴合目标人群 | 是 | 不碰账号密码的本地 PWA 契合金融隐私谨慎心理，跨端可查 |

> 边界：只做日期/免息/年费的规则测算与提醒，不录敏感卡号密码、不自动还款、不代查账单，规则与金额以各银行实际账单为准。
