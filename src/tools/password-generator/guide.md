# 安全密码生成器 · 用户指导

## 这个工具解决什么问题
帮你生成**又长又随机、难以被字典/暴力破解**的密码，全程在本机浏览器运算，密码不会发送到任何服务器。

## 怎么用
1. 拖动滑块设置密码长度（建议不少于 12 位，重要账号 16 位以上）。
2. 勾选需要的字符集：大写、小写、数字、符号。
3. 勾选「排除易混淆字符」可去掉 `0/O`、`1/l/I` 等，方便人工誊抄。
4. 可一次生成 1~50 个，点击「复制」取用。

## 结果怎么理解
- 界面显示的「熵（bit）」表示密码的随机强度：50 bit 以下较弱，80 bit 以上较强，112 bit 以上极强。
- 生成使用浏览器 `crypto.getRandomValues` 加密级随机源，比 `Math.random` 安全得多。

## 注意事项
- 生成后请尽快存入密码管理器，不要通过聊天工具明文长期传播。
- 不同网站应使用不同密码，避免一处泄露牵连多个账号。
