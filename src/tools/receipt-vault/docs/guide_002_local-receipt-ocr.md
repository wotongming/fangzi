# 小票本 使用指南

拍一张小票/发票，本地识别出商家、日期、金额、税额，校对后按项目挂账，导出 CSV 报销报税。**图片不上传、纯本地处理。**

## 用法
1. 点「选择小票图片」拍照或上传。首次会本地加载语言包（约 30MB，仅一次，之后离线可用）。
2. 识别结果自动填入商家/日期/金额/税额，置信度低时会提示，请人工核对修正。
3. 选项目（差旅/餐饮/办公/交通），保存。
4. 多记几张后点「导出 CSV」，按项目/金额自动汇总。

## 隐私
无后端，图片与文本不出设备；数据仅存本机 IndexedDB。
