# 行光阅读器 LineLight Reader · 使用手册

> 版本 0.1.0 · 适用 Chrome / Edge / Brave 等 Chromium 内核浏览器（102 及以上）
> 纯本地运行：不建账号、不上传网页内容、无远程脚本、无遥测。

在长文章上获得**逐行冷暖引导色**、**焦点行高亮**、**纯净去广告**、**本地 TTS 朗读**与**摘录导出**。插件只在你点击图标时对当前标签页注入专注层，再点一次即退出还原，不后台采集任何页面。

---

## 一、功能说明

| 功能 | 说明 |
| --- | --- |
| 逐行引导色 | 按视觉行把文字染成冷（蓝）→ 暖（橙）渐变，帮助眼睛找到下一行；含代码块/表格/图片的复杂段自动整段浅色兜底，不破坏链接、图片与代码 |
| 焦点行 | 当前视口附近段落高亮，其余段落减透明；覆盖层不引起页面重排，随滚动与朗读位置更新 |
| 纯净阅读 | 内置 Readability 抽取正文生成干净阅读视图，广告/侧边栏噪声不进视图；抽取失败自动回退原页仅叠加引导层 |
| 排版 | 行距、段距、页宽三项均可在弹窗实时调节 |
| TTS 朗读 | 浏览器原生语音合成，按句朗读并高亮当前句、自动滚动；支持暂停/恢复/上一句/下一句与语速调节；退出自动停止 |
| 本地摘录 | 选中文字保存到浏览器本地存储，选项页导出 Markdown / JSON（含标题、URL、时间） |
| Dyslexic 字体 | 内置 OpenDyslexic（400/700 woff2，OFL-1.1）；拉丁字母启用，中文走系统字体栈 |

## 二、安装步骤（Chrome / Edge）

本插件以 zip 形式分发：

1. 在本页下载 `line-light-reader-chrome-0.1.0.zip`。
2. **校验完整性（推荐）**：下载后核对 SHA256，应与下载页显示一致：

```text
27017839476805d0bd1fe1852c82cacdb1067de9a863070ae81f9703514b27f9
```

3. 把 zip **解压**为文件夹（确保解压后根目录能直接看到 `manifest.json`）。
4. 打开扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
5. 打开右上角「开发者模式」，点「加载已解压的扩展程序」，选择解压出的文件夹。
6. 浏览器工具栏出现行光阅读器图标即安装完成。

> 受商店政策限制，本 beta 版以「加载已解压扩展」方式分发；上架商店后可一键安装。

## 三、使用方法

1. 打开任意文章页（新闻、博客、技术文档、中文长文均可）。
2. 点击工具栏图标，页面右上角出现专注层工具条：
   - **引导色 / 焦点行 / 纯净阅读 / Dyslexic 字体**：点击切换开关；
   - **⏮ / 朗读 / ⏭**：上一句、播放暂停、下一句；
   - **摘录**：先在页面选中文字，再点「摘录」保存；
   - **退出**：移除全部注入样式与工具条，原页 DOM、链接、图片保持不变。
3. 点击图标旁的弹窗，可调节行距、段距、页宽与朗读语速；偏好自动保存在本地。
4. 点弹窗底部「选项 / 摘录 / 许可码」进入选项页，查看摘录列表、导出 Markdown / JSON、切换 Dyslexic 字体。

## 四、隐私说明

- 所有设置、摘录仅保存在当前浏览器本地存储（`chrome.storage.local`），不上传任何服务器。
- 插件权限最小化：`activeTab`（仅当前标签页）、`storage`（本地存储）、`scripting`（点图标时注入脚本）；**未申请** `<all_urls>` 后台读取权限。
- TTS 使用浏览器内置语音合成，文本不经过第三方服务。
- 无账号、无登录、无统计埋点。

## 五、FAQ

**Q：点图标没反应？**
受限页面（`chrome://`、扩展商店、新标签页、部分 PDF 内置查看器）不允许注入脚本，请到普通文章页再试。

**Q：退出后页面样式没还原？**
点工具条「退出」即可；若异常，刷新页面会清除全部注入层（注入层不写入原页 DOM 持久节点）。

**Q：朗读没有声音？**
确认系统未静音、浏览器语音已启用；语速可在弹窗调整。个别站点的语音合成会被浏览器限制，属浏览器策略。

**Q：摘录存在哪里？会同步到云端吗？**
仅存在本机浏览器；卸载扩展会一并清除。需要备份请先在选项页导出 Markdown / JSON。

**Q：什么时候收费？**
beta 期全部功能免费开放。将来接入买断后，Pro 功能在选项页输入许可码本地验签解锁（离线校验、不联网、不建账号），基础引导色与焦点行永久免费。
