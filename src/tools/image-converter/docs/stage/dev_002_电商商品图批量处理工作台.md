## 技术选型落地
无新依赖；Vue3+TS、OffscreenCanvas/Worker、现有 MODNet(商用友好)、JSZip(MIT)。零后端、零新增模型，dist 体积基本不增。

## 模块设计
通用模式与电商模式共享 IO/队列/预览；电商模式 = presets(配置) → compose(逐张纯函数处理) → watermark(叠加) → pack(命名/zip)。compose/watermark 设计为 `(ImageBitmap, Spec) => Promise<Blob>` 便于单测与 Worker 复用。

## 关键实现方法（伪代码）
```
processOne(img, spec):
  cut = spec.mode==='cover'? coverCrop(img,spec.ratio): contain(img,spec.ratio,spec.bg)
  if spec.replaceBg: cut = compositeOnBg(matte(img), spec.bg)   // 复用 MODNet
  if spec.watermark: drawWatermark(cut, spec.watermark)
  blob = encodeToSize(cut, spec.format, spec.targetKB)         // 质量二分
  name = renderTemplate(spec.nameTpl, {idx,meta,platform:spec.platform})
```
