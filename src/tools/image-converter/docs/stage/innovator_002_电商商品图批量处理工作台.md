# 功能建议：电商商品图批量处理工作台（本地 AI 抠图 + 多平台规格 + 打包）

- 序号：002
- 建议形态：网页应用（PWA，纯前端 WebGPU/WASM + Canvas，本地 AI 抠图）

## 需求来源
电商小卖家上新需要对**大量**商品图重复做抠图/换底、统一尺寸、压缩、加水印、重命名、按平台打包；云端工具普遍按张计费/月导出上限、压缩分辨率、要排队上传。2026 年“本地批量、全分辨率、买断、无张数上限”成为明确卖点：
- Operimage（macOS 本地批量：缩放/转换/压缩/水印/抠图，100% 本地，AI 解锁 **$49 一次买断**）：https://operimage.com/es/
- Photomop（设备端 AI、全分辨率、无上传、无队列）：https://photomop.com/
- Serverless Tools AI Background Remover（批量、全分辨率、ZIP、零水印/零分辨率上限，痛点直指免费云服务的 0.25MP 预览与订阅）：https://serverless.tools/background-remover/
- 水印云《2026 免费抠图工具实测》：电商商家批量抠商品图优先选批量能力强的工具：https://hg.shuiyinyun.com/news/5115.html
- Tooliverse《Photoroom Review 2026》：高质量但**月导出上限**让高频卖家不满、AI 背景偶出错：https://tooliverse.ai/tools/photoroom
- Listicler 批量商品图对比（Canva Bulk Create/多规格是批量核心诉求）：https://listicler.com/best/photo-editing-tools-batch-processing
技术契机：WebGPU/WASM 让浏览器本地跑抠图模型（MODNet/U²-Net 类）与批量像素处理成为可能（检索词「WebGPU browser local AI 2026」：Hugging Face WebGPU kernels、on-device AI 趋势）。

## 使用场景
谁：淘宝/拼多多/闲鱼/小红书/抖音小店/跨境（Temu、Shopee、独立站）小卖家、个人店主、上新助理；没有设计师、自己拍图自己上架的人。
时机：一次上新几款到几十款，每款 3–10 张图，要赶平台规格；或大促前批量重做白底图/主图。
问题：手工一张张在 PS/美图里抠图改尺寸要数小时；云端工具要上传（新品图还怕泄露）、按张/月收费、限分辨率、限张数、排队；不同平台主图/详情/SKU 尺寸（1:1、3:4、800/1200px 等）和文件大小限制各不相同。

## 功能描述
1. 拖入整个文件夹/几十上百张图，浏览器内批量队列处理（Web Worker + WebGPU 加速）。
2. 本地 AI 抠图/去背景 + 纯色/自定义底图/场景底替换；边缘羽化、发丝级开关；抠坏可快速笔刷修补。
3. 规格预设：内置各主流电商平台主图/详情/封面比例与边长、JPG/PNG/WebP、目标文件大小（如 ≤300KB）自动压缩。
4. 水印（文字/平铺 logo，可调透明度位置）、锐化、居中留白、批量圆角/边框。
5. 批量命名规则（商品名_颜色_序号_平台）、按平台分文件夹。
6. 一键打包 ZIP（或 ZIP 分片）本地下载；导出处理清单 CSV。
7. 全部原图与成品留在本机，不上传；处理参数可存为“上新模板”复用。

## 目标人群
画像：月上新数十到数百 SKU 的中小卖家与个体店主、跨境铺货/无货源从业者、上新外包。规模：中国电商主体超千万，活跃小卖家数以百万计；跨境个人卖家群体庞大。付费意愿：已有 $49 买断、云工具月订阅被验证；卖家把它视为直接提升上新效率与转化率的生产工具，愿意一次付 ¥69–199 买断或按月付 ¥10–30。

## 建议形态
纯前端 PWA（WebGPU/WASM + Canvas）。理由：①批量像素与抠图算力可在本机完成，正好发挥 WebGPU；②原图不出本机，消除新品泄露与上传等待；③免安装、跨 Win/Mac，卖家换机也能用；④无后端、零边际成本，支撑“买断 + 不限张数”模式。

## 落地价值
解决问题：把一次上新几十上百张图的处理从数小时压到十几分钟“拖入即打包”，全分辨率无张数上限，直接省掉云工具订阅与人工。市场空间：对标 Operimage $49、Photoroom/Cutout 订阅，面向海量中文电商卖家做本地化平台规格与命名。盈利点：freemium（免费低分辨率/限量，本地基础压缩永久免费）→ 买断解锁本地 AI 抠图 + 批量 + 全部平台规格 + ZIP；跨境/团队可买多端授权。

## 多场景链路与红海规避判断
- 是否同质化小工具：否。不是单一抠图或单一压缩，而是覆盖“拍图导入→抠图换底→多平台规格→水印→命名→打包→上架”的上新生产链路。
- 多场景链路：触发（上新/大促）→ 处理（批量抠图+规格+水印）→ 产出（按平台分目录 ZIP + 清单）→ 后续动作（直接上架、模板复用到下批、按转化回调主图）。
- 持续使用频次与付费空间：高频（每周/每大促）、随店铺经营长期使用；可延伸白底图合规检测、主图 A/B 出图、视频封面帧、跨境多语言图等付费场景。
- 红海规避：通用抠图（remove.bg 类）是红海，但“**本地批量 + 全分辨率 + 不限张数 + 中文电商平台规格/命名/打包一条龙 + 买断**”组合仍差异化；Operimage 仅限 macOS、Photomop 偏单张编辑，均未覆盖中文多平台打包链路。
