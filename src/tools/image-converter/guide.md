# 图片格式转换压缩器 · 用户指导

## 解决什么问题
在本地把图片在 **PNG / JPEG / WebP** 之间转换、按质量与尺寸压缩，解决「照片太大传不上系统」「想要更小的 WebP」等问题，图片不上传、无水印。

## 怎么用
1. 首次使用需**一次性买断**（示例 29.9 元，本地演示环境点击即解锁）。
2. 点击选择图片。
3. 选择输出格式、质量（PNG 为无损无需质量）、最大宽度（超出会等比缩小）。
4. 查看转换后的体积、尺寸与压缩比例，点击「下载」保存。

## 格式怎么选
- **WebP**：同画质体积通常最小，现代浏览器与主流系统均支持；老环境兼容时选 JPEG/PNG。
- **JPEG**：适合照片，不支持透明，会自动铺白底。
- **PNG**：无损、支持透明，适合截图/图标，体积较大。

## 边界
- 动图 GIF 仅处理首帧；超大图受浏览器内存限制。
- 若转换后反而变大（常见于已经高度压缩的 JPEG 再转），会明确提示，建议更换格式或降低质量。
