# GPU 大数据可视化面板 · 用户指导

版本 1.0.0 · 更新于 2026-10-15

## 这是什么 / 能做什么

在浏览器里直接分析百万级数据点的纯本地可视化面板：拖入 CSV / TSV / JSON 即可在高帧率下流畅缩放、平移、框选，提供散点密度图、热力图、折线（按列均值）三种视图，支持导出 PNG 截图与框选结果。数据全程留在本机，不上传任何服务器，无需注册、无需后端。

**重要边界**：解析与渲染全部在浏览器本地（含 Web Worker、GPU）完成；它是探索式可视化工具，不做统计推断或建模结论。

## 快速开始

1. 打开面板，在「导入数据」区拖入 / 选择文件，或直接粘贴表格文本，或点「载入 100 万点示例」体验。
2. 导入后提示检测到的行数 / 列数，在下拉框选择 X 轴与 Y 轴（二者不能为同一列），点「载入 N 点」。
3. 用工具栏切换散点密度 / 热力图 / 折线，滚轮缩放、拖拽平移，或切到框选模式拖出矩形看选区统计。
4. 免费可导出 PNG 截图；全量数据、CSV / 报告导出、嵌入组件为专业能力。

## 分步用法

### 1. 导入数据（三种方式）

- 拖入 / 选择文件：`.csv` / `.tsv` / `.json` 拖到虚线框或点「选择文件」，由浏览器内 Worker 流式解析，不产生网络请求。
- 直接粘贴数据：把表格文本粘进文本框。
- 载入 100 万点示例：立即生成一份传感器簇模拟数据用于体验。
- 导入后选择 X、Y 两个不同的数值列再载入。

### 2. 切换视图

- **散点密度**：以半透明点叠加呈现点云密度，观察数据簇与离群点。
- **热力图**：基于网格聚合，色带高亮密集核心。
- **折线（按列均值）**：按 X 分桶后对 Y 取均值，用于看趋势 / 波形。

### 3. 缩放、平移与框选

- 滚轮缩放（移动端双指捏合），以光标为中心缩放；默认「平移」模式按住拖动视图，点「重置」回到全局。
- 切到「框选」模式在图上拖出矩形，下方立即显示选区统计（点数、X / Y 的最小 / 均值 / 最大值）；双击或拖一个极小框可清除选区。

### 4. 导出与嵌入

- 导出 PNG：把数据层与坐标网格、轴标合成为一张高清 PNG 下载（免费）。
- 导出 CSV（X/Y）/ 导出选区 CSV：导出全部或框选结果的原始数值（专业能力）。
- 嵌入组件：生成一段可放入自己网页 / 系统的嵌入代码，让访客在你的页面内使用该面板（专业能力）。

### 5. 渲染后端自动降级

- 推荐 Chrome / Edge 113+、Safari 26+（支持 WebGPU，百万点走 GPU compute 最流畅）。
- Firefox 及较旧浏览器自动降级到 WebGL2（真实 GPU 渲染，兼容模式）；极旧环境再降级到 Canvas2D（单次上限 10 万点）。显示「WebGL2（兼容模式）」属正常降级，不影响使用。

## 数据与隐私

- 解析、聚合、渲染全部在浏览器本地完成（Web Worker + GPU），页面不发起任何数据上传请求。
- 超大文件解析期间浏览器可能短暂占用较高内存，属正常现象；WebGL2 后端上限 500 万点，超出会提示。

## 常见问题

- **顶部显示「WebGL2（兼容模式）」或提示不支持 WebGPU？** 属正常降级，只是百万点极限帧率略低，升级最新版 Chrome / Edge 即可走 WebGPU。
- **载入大数据帧率较低？** 无独立显卡或软件渲染环境下帧率会明显下降，可先用 50 万点以内数据，或在真实 GPU 设备上使用。
- **提示「X 轴与 Y 轴不能是同一列」？** 在导入预览里把 X、Y 选为两个不同的数值列即可。
- **数据会被上传吗？** 不会，全部本地处理。
