# PM 评估报告：GPU大数据可视化面板

- 对应 innovator：innovator_002_GPU大数据可视化面板.md
- 评估日期：2026-10-15
- 结论：**可集成（新增）**

## 与 fangzi 现有功能去重与整合判定

对照 fangzi README 与 `src/tools/`：现有 12 个工具中无任何图表/数据可视化工具（家庭财务管家的「报表/看板」是记账域的固定报表，非通用图表引擎；批量文本处理器是文本处理，非数据可视化）。innovator_002 提出的是**通用 GPU 加速大数据可视化分析**（百万点渲染、CSV 导入、GPU 聚合），解决目标（大数图表卡顿/被迫降采样/服务端聚合成本）与任何现有功能无实质重叠。

- **判定不重复** → 按常规流程评估，结论为新增独立工具。

## 需求真伪判断

- 真需求。证据链：SciChart/LightningChart 商业库以数千美元/年授权收费且用户规模可观；公开基准显示主流开源图表库（Recharts/Chart.js）在 100K-1M 点冻结/OOM；ChartGPU 曾登 Hacker News 热榜；金融/IoT/临床多行业对全量数据可视化有刚性需求。
- 使用频次：数据分析/运维/金融人群为日级高频。与 fangzi 用户群匹配：fangzi 有开发者/工作场景用户（正则、JSON、时间戳、哈希等 developer 工具），数据分析人群与其相邻，可被「数据分析」「图表」「csv」等检索词命中。

## 技术可行性

- 完全可行，纯前端实现：
  - CSV/JSON 本地解析（File System Access API / 拖拽 File API）；
  - GPU 渲染：WebGPU（compute shader binning 聚合 + vertex buffer 绘制）优先，WebGL 回退；自研轻量渲染管线（不引重型图表库，避免体积与授权问题）；
  - 数据存 typed array + 可选 IndexedDB（复用 `reusable-module/indexeddb-kv`）；
  - 导出截图/筛选结果用 Canvas 快照 + 可选 CSV 导出。
- 技术风险：WebGPU 兼容性需降级路径；百万点内存占用需流式分块读取。

## 集成成本与侵入性

- 新增 `src/tools/gpu-data-viz/`（manifest.ts + index.vue + 渲染模块），工具框架自动发现，**零核心改动、零路由改动**；
- 不触碰 Service Worker / manifest / 现有路由；渲染模块如较大则动态 import。
- 对存量影响：无（纯新增工具）。

## 架构兼容性

- 与 fangzi 零后端、纯前端、原生 CSS 架构兼容；不引入 UI 框架；
- 自研 shader 渲染避免重型图表依赖，符合「不引入破坏架构的重型依赖」约束；
- 数据全程本地处理，契合 fangzi「隐私本地优先」的产品气质。

## 平台合规评估

- EdgeOne Pages：静态托管，无服务端需求；部署包增量小（自研渲染代码 + 少量工具库），合规；
- 不进插件商店，无商店政策问题；内容合规无风险。

## 资金成本

- 零成本可行：自研渲染管线（无商业授权费）、CSV 解析用原生/轻量 MIT 库；无任何付费服务依赖。

## 时间成本与开发难度

- 复杂度：中高（WebGPU compute binning + 渲染管线 + 降级）；
- 独立开发者估算：渲染核心 4-5 天、数据导入与交互 3-4 天、降级与回归 2-3 天，合计约 9-12 人日。

## 用户真实价值

- 核心痛点：大数图表卡顿/崩溃/OOM；被迫降采样丢信号；为绕客户端瓶颈建昂贵服务端聚合；
- 使用频次：分析人群日级；对 fangzi 的价值：新增「数据分析」品类入口，提升开发者/分析人群留存，为后续 Pro 计费提供载体。

## 市场与竞争

- 竞品：SciChart/LightningChart（贵、面向企业）、ECharts/Chart.js（性能天花板明确）、Falcon 等学术方案（非产品）；
- 差异化：免费 + 百万点 60fps + 零后端 + 本地数据 + 工具集合生态导流，平价细分市场空白。

## 盈利方式建议

- freemium：基础版数据量上限（如 50 万点、基础图型）；Pro（buyout 或订阅）解锁全量数据、流式、导出报告、嵌入式组件；或按次（大文件处理）。建议 freemium 先行。

## 结论与依据

- **可集成（新增）**：与现有功能无重复；纯前端零资金可行、不破坏存量、平台合规；百万点可视化是真实高频需求且有明确付费空间（商业库高价 vs 开源性能不足的空白带）。
