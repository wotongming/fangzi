# 离线语音转写与会议纪要 · 用户指导

版本 1.0.0 · 更新于 2026-10-15

## 这是什么 / 能做什么

把会议、采访、课堂、通话录音拖进浏览器（或直接用麦克风录制），全程在本机完成语音识别：生成带时间戳、可点击回听的文字稿，自动抽取会议要点 / 待办 / 决定，并导出文本、Markdown、SRT 字幕。音频与文字稿都不出设备，首次下载模型后可离线转写，无需按分钟为云端服务付费。

**重要边界**：当前为 Whisper tiny 最小模型，英文 / 清晰录音效果最佳，中文可识别但准确率有限；会议纪要为纯规则抽取式，不是生成式 AI 摘要，不会改写润色。录制他人讲话前请先取得对方同意。

## 快速开始

1. 打开工具，默认在「转写」页；可点麦克风直接录音（再点停止，可放弃），或点「选择音频文件」/ 直接把音频拖入虚线框。
2. 导入后显示音频时长，选择语言（英文场景建议手动选 English，避免自动检测偏差）。
3. 点「开始转写」，进度条显示模型下载 / 推理进度；完成后得到带时间戳文字稿、波形播放器与本地抽取纪要。
4. 右上角导出 TXT / Markdown / SRT；「历史」标签回看与管理记录。

## 分步用法

### 1. 导入音频或麦克风录音

- 支持 wav / mp3 / m4a / ogg / flac / webm（浏览器原生解码，统一重采样到 16kHz 单声道）；麦克风经 MediaRecorder 录制。
- 模型（约 40MB）与推理内核由方子站点同源自托管，仅首次使用需联网加载，之后由浏览器 / Service Worker 缓存，离线可转写；可先点「提前下载模型」。
- 无跨域隔离头时使用单线程 WASM，长音频推理速度一般。

### 2. 开始转写与结果页

- 点「开始转写」后，顶部提示实际推理耗时，右侧出现结果区。
- **文字稿**：按时间戳分段，点任意时间戳让播放器跳到该位置回听核对；点文字可就地修改错别字。
- **波形播放器**：Canvas 波形 + 播放 / 暂停、0.75×–2× 变速、点击波形任意位置跳转。
- **会议纪要（本地抽取）**：纯规则在本地抽取「一句话摘要 / 关键要点 / 待办行动项 / 已做决定」，不调用任何云端大模型。

### 3. 导出

- 结果页右上角可导出 **TXT**（纯文字稿）、**Markdown**（含纪要与分段）、**SRT**（带序号与时间轴的字幕文件，可直接用于剪辑软件）。

### 4. 历史记录

- 「历史」标签列出本机所有转写记录（标题、时长、语言、时间），可「打开」回看文字稿、「导出MD」或「删除」。
- 历史只保存文字稿 / 分段 / 纪要 / 元信息，**不保存音频本体**；从历史打开仅展示文字，无波形回听。

## 数据与隐私

- 音频与文字稿都不出设备，站点没有后端，音频从不保存或上传；历史只存本机 IndexedDB 的文字稿与元信息。
- 清理浏览器站点数据会清空历史，请在删除前用 TXT / MD / SRT 导出留存。

## 常见问题

- **第一次为什么要加载、还比较慢？** 模型约 40MB，仅首次从本站加载（同源直连，国内网络可用），之后缓存、断网也能用。
- **英文很准，中文为什么一般？** 当前是 Whisper tiny 最小模型，英文近完美、中文准确率有限，重要中文录音请结合时间戳回听人工校对。
- **模型加载失败怎么办？** 切换网络（WiFi / 流量）或稍后点「提前下载模型」重试；极个别企业内网拦截大文件时，换网络加载一次后离线使用。
- **能转视频里的声音吗？** 本期暂不支持直接读视频，需先自行提取音轨。

## 注意事项 / 功能边界

- 模型固定为 Whisper tiny 多语 q8，更大的 base / small 模型、说话人分离、视频提音轨、批量队列等列入后续版本，本期未实现。
- 纪要为抽取式而非生成式，不会编造内容但也不润色；极少数特殊编码音频可能无法解码。
