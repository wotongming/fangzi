# 部署运维指引：离线语音转写与会议纪要

- 对应 architect：architect_004_离线语音转写与会议纪要.md
- 编写日期：2026-10-15

## 部署架构与环境准备

- 部署架构：EdgeOne Pages 静态托管（同 fangzi）；Whisper/Qwen 模型运行时从 Hugging Face 下载（不进部署包）；音频与转写全在本地。
- 环境清单：Node ≥ 20.19（构建机）；EdgeOne Pages 账号（已有）；Hugging Face 免账号。

## 软硬件配置清单

| 项 | 规格 |
| --- | --- |
| 构建机 | Node 20+ |
| 部署 | EdgeOne Pages（免费额度） |
| 客户端 | 桌面浏览器；建议 ≥8GB 内存；麦克风可用（录音场景） |
| 模型 | Whisper tiny/base/small（MIT）+ Qwen2.5（Apache-2.0），运行时下载 |

## 部署步骤

1. `cd fangzi && npm install && npm run build`
2. EdgeOne Pages CLI/Git 推送 dist/
3. 验证：导入音频转写、纪要生成、SRT 导出正常
4. 更新 README 工具清单（登记 local-transcribe 七字段）

## 配置项说明

- 无新增环境变量；模型档位/词库/时长限额在 manifest 与 lib/asr.ts 常量维护。

## 上线/灰度方案

- 内部灰度（base 档全量功能）→ 观察转写耗时与准确率 → 全量；Pro 权益随计费框架发布。

## 平台对接指南

- **EdgeOne Pages**：个人账号即可；部署 CLI/Git；HTTPS 平台提供；版本更新=重新部署。
- **Hugging Face（模型源）**：免注册下载 Whisper（MIT）、Qwen2.5（Apache-2.0）；国内访问不稳可配镜像源；无需 API Key。
- 其余平台：不涉及（PWA 内工具）。

## 运维监控指标与告警

- 指标：工具访问量、转写耗时/失败率（本地打点可选上报）、模型下载失败率；
- 告警：模型源不可用 → 多源切换；转写失败率高 → 检查浏览器/内存。

## 日志管理

- console + error 聚合；**不采集音频内容**（隐私承诺写入工具页）。

## 备份与容灾

- 用户数据本地 IndexedDB；无服务端数据；代码仓 git 备份；建议用户导出重要转写（提供导出）。

## 常见故障排查与回滚预案

- 模型下载失败：检查网络/镜像；断点续传重试；
- 转写慢：提示降档（base→tiny）或 CPU 模式；
- 严重问题：`git revert` + 重部署，仅影响新增工具。
