# PM 评估报告：离线语音转写与会议纪要

- 对应 innovator：innovator_004_离线语音转写与会议纪要.md
- 评估日期：2026-10-15
- 结论：**可集成（新增）**

## 与 fangzi 现有功能去重与整合判定

对照 fangzi README 与 `src/tools/`：现有工具无语音/音频/转录类功能。与 003（本地知识库）无重叠（003 输入是文档文本，004 输入是音频，虽可互为链路——转写结果可导入知识库——但功能对象不同）。

- **判定不重复** → 新增独立工具。

## 需求真伪判断

- 真需求。证据链：端侧 ASR 2026 规模化落地（信通院白皮书 96.2% 准确率）；云端转写「涉密录音上传合规、断网中断、按分钟计费」三大痛点被行业反复论证；StarWhisper/AirgapAI 已实际收费（$10-29/月）；知识工作者平均每周 11-15 场会议，纪要整理耗时是普遍痛点。
- 使用频次：商务/记者/学生人群周级高频。与 fangzi 用户群匹配：fangzi 的「工作」品类用户（批量文本处理、家庭财务等）与会议纪要场景高度重合；隐私优先气质一致。

## 技术可行性

- 完全可行，纯前端实现：
  - ASR：`@huggingface/transformers` / onnxruntime-web 跑 Whisper 系模型（tiny/base/small，MIT 权重），WebGPU/WASM 加速，本地推理（CPU 可达 15 倍实时量级）；
  - 录音：MediaRecorder API；导入：File API/File System Access（mp3/wav/m4a/ogg + 视频提音轨）；
  - 纪要生成：WebLLM/Transformers.js 本地小模型（Qwen2.5，Apache-2.0）摘要/要点/待办；
  - 存储：转写文本存 IndexedDB（复用 indexeddb-kv），波形用 Canvas。
- 技术风险：说话人分离（pyannote 类较重，MVP 先做「分段+时间戳」不做人声分离，或标记为 Pro 能力）；Whisper 中文准确率需小模型实测；模型下载体积（base ~140MB）需进度提示。

## 集成成本与侵入性

- 新增 `src/tools/local-transcribe/`，工具框架自动发现，零核心/路由改动；
- 模型与 ASR 库动态 import，不预缓存；不触碰 SW/manifest；
- 存量影响：无（纯新增）。

## 架构兼容性

- 与 fangzi 零后端纯前端架构兼容；不引入 UI 框架；
- 本地优先 + IndexedDB 复用 + billing 框架接入，符合开发规范。

## 平台合规评估

- EdgeOne Pages：静态托管，运行时下载 Whisper 模型（外部免费源）不进部署包，合规；
- 不进插件商店；内容合规：录音转写属用户本地数据处理；界面需提示「录音需获对方同意」等法律提示（转写工具通用合规义务），无平台风险。

## 资金成本

- 零成本可行：Whisper 权重（MIT）、Transformers.js/onnxruntime-web（Apache-2.0/MIT）、Qwen2.5（Apache-2.0）、Hugging Face 免费下载；全部商用友好授权。

## 时间成本与开发难度

- 复杂度：中高（ASR 集成 + 录音/导入 + 纪要生成）；
- 独立开发者估算：ASR 集成与模型缓存 3-4 天、录音/导入/波形 UI 2-3 天、本地纪要 2-3 天、降级与回归 2 天，合计约 9-12 人日。

## 用户真实价值

- 核心痛点：会议/访谈录音不能上传的合规风险；断网不可用；按分钟持续付费；
- 使用频次：商务/记者/学生周级高频；对 fangzi 价值：新增「会议效率」场景，扩工作品类覆盖面，freemium 付费空间明确（对标 $10-29/月竞品）。

## 市场与竞争

- 竞品：Otter/Fireflies（云端红海，数据上传硬伤）、StarWhisper/AirgapAI（桌面/本地，已验证付费）、讯飞等（云端按分钟收费）；
- 差异化：免费基础 + 浏览器 PWA 免安装 + 工具集合生态 + 本地离线；中文用户平价市场空缺。

## 盈利方式建议

- freemium：免费（每月转写时长限制，如 60 分钟）；Pro（buyout ¥49.90 或订阅 ¥19.90/月）解锁无限制时长、纪要导出、术语词库、批量；后续可出企业内网部署版。

## 结论与依据

- **可集成（新增）**：与现有功能无重复；纯前端零资金可行（Whisper/Qwen 商用友好）、不破坏存量、平台合规；合规+离线+省订阅三重刚需，竞品已收费验证。
