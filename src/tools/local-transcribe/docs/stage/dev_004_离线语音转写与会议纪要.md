## 技术选型落地

- ASR：`@huggingface/transformers`（Apache-2.0）+ Whisper 权重（MIT）；纪要：WebLLM（Apache-2.0）/Qwen2.5（Apache-2.0）；ffmpeg.wasm（MIT+LGPL 组件，文档标注合规）；存储 IndexedDB；全部动态 import；零成本、商用友好。

## 模块设计

见 architect_004 系统架构；input→asr→segment→summarize→store→export；index.vue 分「导入/录音」「转写编辑」「纪要」「历史」四区。

## 关键实现方法

```ts
// 转写（asr.ts）
const pipe = await pipeline('automatic-speech-recognition', 'Xenova/whisper-base', { dtype: 'q8' })
const out = await pipe(audio, { return_timestamps: true, initial_prompt: termPrompt() })
// 分段（segment.ts）
export function toSegments(out: {chunks:{timestamp:[number,number],text:string}[]}) {
  return out.chunks.map(c => ({ start: c.timestamp[0], end: c.timestamp[1], text: c.text.trim() }))
}
// 纪要 prompt（summarize.ts）
export const MEETING_PROMPT = (transcript: string) => `请从以下转写中提取：要点、已做决定、待办事项、一句话摘要。\n\n${transcript}`
```

## 开发步骤与里程碑

- M1（3-4 天）：input + asr（base 档）转写可用；
- M2（2-3 天）：segment + waveform + 编辑/导出；
- M3（2-3 天）：summarize 本地纪要；
- M4（2 天）：批量/降级/Pro 权益/合规提示/回归。

## 代码规范与质量要求

- fangzi 现有风格；重型依赖动态 import；模型不进 SW 预缓存；隐私：音频不出端（工具页承诺）；合规提示必须展示。
