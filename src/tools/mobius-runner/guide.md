# 用户指导：莫比环 MÖBIUS

- 版本：1.0.0（Beta）
- 更新：2026-10-19
- 标签：生活 · 网页工具 · 3D 全屏小游戏

## 这是什么

「莫比环 MÖBIUS」是一款**一指就能玩的 3D 莫比乌斯光带跑酷**。你是一颗沿无限半扭转光带前进的光球：光带每转过一处半扭转，**正反面会真正对调**。点一下屏幕翻到另一面，从闸门挡住的缺口面穿过去，跑得越远、连击越漂亮，分数越高。

- 纯前端、**零后端**：无账号、无联网请求、无广告。
- **离线可玩**：首次打开后，断网也能跑（PWA 可安装到桌面/主屏）。
- 分数、设置只保存在**本机浏览器**（IndexedDB），不上传任何服务器。

## 运行环境

- 需要支持 **WebGL** 的现代浏览器：Chrome / Edge / Safari / Firefox 近年版本均可。
- 手机、平板、电脑都能玩；手机建议在浏览器菜单选择「添加到主屏」，以全屏沉浸方式启动。
- 若设备不支持 WebGL 或关闭了硬件加速，会看到友好提示而不是白屏。

## 怎么玩

1. 打开工具，点 **开始奔跑**（首次会先显示 30 秒教学）。
2. **操作只有一个**：
   - 手机：**点按屏幕任意位置** 翻转一面。
   - 电脑：**点按画面**，或按 **空格 / ↑** 翻转；**Esc** 暂停。
3. 前方闸门只挡住光带的一面，在**亮着的缺口面**穿过去即可；撞在实墙一面即结束。
4. 看到「扭转带 · 准备翻转」提示时，光带即将半扭转——你所在的面会和对面对调，提前看好缺口在哪一面。
5. 计分技巧：
   - 安全过门得分；
   - **贴边擦过（near）/ 临门完美翻转（perfect）** 连击加成更高；
   - 连续有风格通过会提升倍率（最高 ×8）。
6. 途中的**光屑**碰到即收集并加分。

## 暂停与设置

对局中按右上角 ❚❚ 或 Esc 暂停，可切换：

- 静音、震动（移动端）；
- **降低动态**：关闭相机翻滚与大幅震屏，容易晕 3D 时建议打开；
- 特效档位：自动 / 高 / 低（低档位更省电、低端机更流畅）。

## 常见问题

- **画面黑屏/提示不支持 3D？** 更新浏览器、开启硬件加速；或换一台支持 WebGL 的设备。
- **容易晕？** 暂停里打开「降低动态」，并把特效调到「低」。
- **高分不见了？** 分数按浏览器与设备本地保存，清理浏览器数据或换浏览器会重置，属正常现象。
- **要联网吗？** 游玩本身不需要联网；加载页面需首次联网缓存资源。
