# PM 评估报告：莫比环 MÖBIUS（一指翻转 3D 莫比乌斯环带跑酷）

- 对应 innovator：`innovator_008_莫比环3D翻转跑酷.md`
- 评估日期：2026-10-19
- 结论：**可集成（新增独立工具）**

## 与 fangzi 现有功能去重与整合判定

已通过 gitcode-connect 拉取并通读 fangzi 最新代码（远端 main=`3309b91`，27 个工具）。现有娱乐类工具只有 `src/tools/mini-games/`（小游戏合集 v1.3.0，6 款）：

- 经典益智（DOM/2D）：2048、记忆翻牌、数字华容道。
- 炫光 NEON（自研 WebGL2/Canvas2D 引擎）：炫光连消、霓虹脉冲、星轨穿梭。

**判定：不重复，但需刻意隔离引擎。**

- 玩法层：现有 6 款无一是“3D 连续曲面 + 莫比乌斯半扭转换面”的跑酷；维度（真 3D）、核心机制（半扭转周期性交换两面）、视角（贴面跟随翻滚）均为全新，解决的痛点/场景虽同属碎片娱乐，但提供的是不同心流与新鲜感，非同质。
- 技术层：mini-games 的 NEON 系列建立在自研 `NeonEngine`（WebGL2/Canvas2D 两后端）上，与 **Three.js 是两套渲染体系**。若强行把本作作为 mini-games 的第 7 款塞进去，需要在其渲染抽象里硬接第三种“Three.js 后端”，侵入大、污染既有稳定游戏的包与回归面。
- **整合决策：新增独立工具 `src/tools/mobius-runner/`**，独立路由 `#/t/mobius-runner`，Three.js 以**动态 import 独立 chunk** 仅在进入本工具时加载，不进入主包、不影响 mini-games。视觉语言（全屏沉浸 / 霓虹 / WakeLock / 合成音 / 震动 / 秒重开）与 mini-games 保持家族一致，最大化“看起来是一个系列”的体验，但代码与依赖隔离。
- 复用而非照搬：统一计费（`src/core/billing`）、自动注册（`src/core/registry.ts` 的 `import.meta.glob('../tools/*/manifest.ts')`，无需改路由表）、PWA 全屏沉浸外壳（manifest `immersive:true`）、本地存储（`reusable-module/indexeddb-kv`）、异步挂载（`reusable-module/use-lazy-init`）、能力探测（`reusable-module/gpu-detect`）、SEO（`reusable-module/use-seo`）。mini-games 内部的 `FocusStage` / 音频 synth 不是公共模块，**不跨工具私有引用**；沉浸由外壳能力 + 工具内干净画布舞台实现。

## 需求真伪判断

- **真痛点 / 真需求**：碎片时间解压是高频刚需；调研与品类数据支持“单键 + 即时重开 + 不断刷新小纪录”是被市场反复验证的成瘾结构。差异化来自莫比乌斯几何，记忆点强、有分享欲，不是为不同而不同的伪创新——半扭转直接改变“我在哪一面”的判断，是可玩的机制而非纯视觉噱头。
- **使用频次**：高。单日可多次、每次多局，单局 1–3 分钟，随时退出无惩罚。
- **与方子用户群匹配**：mini-games 已上线且有专业版付费，证明存量用户存在娱乐需求与小额付费习惯；本工具可与之互相引流（关键词 / 推荐位）。

## 技术可行性

- 纯前端、无自研后端完全可行：Three.js 负责 WebGL 渲染；环带用参数化曲面 / 管状几何体沿中心线生成，闸门、光屑、角色均为程序化网格，碰撞基于中心线参数（弧长 `u` + 所在面）做一维判定，**不依赖物理引擎、不依赖 3D 拾取/射线**，移动端性能与确定性都可控。
- “可测试性”保障：把**关卡生成、换面状态、半扭转换面、碰撞判定、计分/连击**等纯逻辑下沉为无 DOM / 无 WebGL 的 `game/logic.ts`（种子化可复现），用 node:test 毫秒级单测；Three.js 渲染层做薄。这与 mini-games “logic.ts 纯逻辑 + 组件渲染”的成功模式一致。
- 渲染降级：Three.js 仅依赖 WebGL（市面主流移动/桌面浏览器 90%+ 支持）。用 `gpu-detect` 探测：能力弱→降像素比、关辉光/后处理、减粒子；彻底无 WebGL→显示友好“不支持”兜底，不白屏。无头环境测试强制 WebGL2 软渲染即可截图（遵循 `pipeline-coder/references/gpu-headless-testing.md`）。
- 风险：莫比乌斯扭转相机可能引发眩晕 / 看不懂。缓解：扭转区强预告、相机平滑跟随法线翻滚且角速度受限、提供“减弱动效（减少翻转/景深）”无障碍开关；新手前三局用引导闸门（只放一面、慢速）教学。

## 集成成本与侵入性

- **低-中，且零侵入存量**：新增 `src/tools/mobius-runner/` 一个目录 + 新增 `three`/`@types/three` 依赖；不改 mini-games、不改路由/注册表逻辑（自动发现）、不改 Service Worker 策略（动态 chunk 走产物 glob 预缓存，需在 dev 文档验收点确认其进入预缓存清单）。
- 对主包影响：`three` 经 tree-shaking + 动态 import 后为独立异步 chunk（gzip 约 130–170KB 量级，验收以实际构建产物为准），不增加首屏体积；不玩该工具的用户不会下载。
- 回滚容易：下线只需移除工具目录与依赖，独立、不牵连其它工具。

## 架构兼容性

- 与现有 Vue 3 + Vite + TypeScript + Pinia + vue-router 技术栈一致；Three.js 以 onMounted 内动态加载、`use-lazy-init` 处理“chunk 异步到达后初始化画布”，卸载时释放 renderer/geometry/material/RAF 与事件，避免显存泄漏。
- 不引入物理引擎等重型依赖，不破坏 manifest / SW / 现有路由；`immersive:true` 复用外壳全屏入口，PWA 安装与离线能力保持有效。

## 平台合规评估

- 分发主体为 **PWA（EdgeOne Pages 静态托管）**，不涉及 Chrome/VS Code 等插件商店资质；无个人开发者上架资质障碍。
- 纯静态、无服务端函数，符合 EdgeOne Pages 免费版限制；无外部素材（零版权风险），无账号/UGC/支付合规问题（支付/解锁走方子既有的本地/旁路计费框架，不在站内自建资金通道）。
- 内容合规：休闲反应游戏，无暴力/赌博/不良内容；“随机闸门/光屑”为确定性程序生成、不涉及真钱下注，不构成赌博。

## 资金成本

- 零资金：Three.js 与类型定义均为 **MIT，可商用免费**；无服务器、无素材、无字体/音频采购；EdgeOne Pages 免费额度承载。符合“只用可商用免费资源、禁用 NC”的硬约束。

## 时间成本与开发难度

- 复杂度分级：**H 档**（3D 渲染 + 相机 + 程序化关卡 + 降级与多端验证），但可大量复用 mini-games 已验证的工程范式（纯逻辑下沉、FocusStage 式纯净舞台、合成音/震动/WakeLock、计费钩子、三视口 E2E、限额核查）。
- 建议里程碑：M1=环带/相机/单键翻转/闸门碰撞/死亡重开的可玩垂直切片 + 纯逻辑单测；M2=半扭转区、连击/near-miss/光屑/难度曲线 + 美术 juice；M3=计费/外观成长/设置/降级 + SEO/多端 E2E/文档/推送。无人值守单轮可先交付 M1 可运行 checkpoint，再推进 M2/M3。

## 用户真实价值

- 对用户：高质感、零门槛、无广告、离线的 3D 解压体验与“刷新自己纪录”的长期动机。
- 对方子：填补“真 3D / 强视觉记忆点”品类空缺，提升娱乐板块的停留时长、次日回访与专业版转化；与 mini-games 形成 2D/3D 互补与互引流。

## 市场与竞争

- 红海的是普通换道/闪避跑酷；“单键 × 真 3D 莫比乌斯几何 × 高级霓虹质感 × 零安装 PWA”在大众市场几无成熟竞品（现存仅 Mobius Trip、Ziggy Roll、Soliton Burst 等小众独立原型，定位与操作均不同）。差异化来自**几何机制本身**而非美术堆砌，护城河在于手感、相机与难度曲线的打磨。

## 盈利方式建议

- 沿用方子统一计费：**freemium + 一次性买断专业版**（无广告、无订阅）。
- 永久免费：核心玩法、无限重开、基础拖尾、本地最高分。
- 专业版买断（建议 `priceCents=1290`，即 ¥12.90，低于小游戏合集 ¥19.90——单款游戏客单更低、转化更友好；最终以计费框架配置为准）：多套主题皮肤 / 环带外观、**每局一次“光盾续命”**、专属拖尾与结算徽章、未来新增模式（限时挑战 / 镜像强化）优先解锁。
- 不实现任何强制弹窗、不影响免费完整可玩性；付费钩子只接“便利 + 个性化 + 后续内容”。

## 存量数据与配置保护

本功能为**新增独立工具**，使用独立 IndexedDB 库名（建议 `fz-mobius-runner-v1`）与独立 localStorage 键，**不读写、不迁移任何现有工具数据**，对存量功能数据零影响。自身存储从 v1 起即采用“可选字段 + 默认值回退”的宽松结构，为后续版本兼容留余地。

## 结论与依据

**可集成（新增独立工具 `mobius-runner`）。** 依据：① 需求真实、高频、差异化空白明确；② Three.js(MIT) + fangzi 现有栈可纯前端、零后端、零资金实现；③ 动态 import 独立 chunk + 独立目录，对存量与主包零侵入、易回滚；④ 无平台资质与合规障碍；⑤ 可复用统一计费/存储/全屏/探测/SEO 能力，风险主要在 3D 手感与多端性能，已给出降级、纯逻辑下沉与分里程碑方案。建议进入架构设计。
