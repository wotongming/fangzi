# 部署运维指引：莫比环 MÖBIUS（一指翻转 3D 莫比乌斯环带跑酷）

- 对应 architect：`architect_008_莫比环3D翻转跑酷.md`
- 编写日期：2026-10-19
- 形态：fangzi PWA 内独立网页工具 `mobius-runner`（纯静态、无自研后端、可离线）

## 部署架构与环境准备

- 架构：静态资源（HTML/JS/CSS/wasm）全部由**腾讯云 EdgeOne Pages**托管；游戏为客户端单页，Three.js 运行在用户浏览器，**无应用服务器、无数据库、无服务端函数、无外部 API 密钥**。
- 数据：最高分 / 设置 / 累计光屑 / 解锁仅存用户本机 IndexedDB（库 `fz-mobius-runner-v1`），不产生服务端数据与备份需求。
- 发布链路：本地开发 → 质量门（类型/单测/构建/E2E）→ 推送 GitCode `main` → EdgeOne Pages 连接仓库自动构建部署（沿用方子既有 CI/CD，本工具不新增流水线）。
- 环境：Node + npm（与仓库一致）；新增依赖 `three`(MIT)、`@types/three`(MIT)，版本锁定在 `package.json`/lock。

## 软硬件配置清单

| 项 | 规格/取值 | 说明 |

| 证书/HTTPS | EdgeOne 提供 | PWA、WakeLock、全屏等均要求安全上下文，已满足 |

## 部署步骤

1. **准备依赖**（一次性）：
   ```bash
   npm install            # 安装仓库依赖
   npm i three
   npm i -D @types/three  # 安装前联网核对 three 稳定版与无高危 advisory、与 Vite 兼容
   ```
2. **本地验证（权威验证用生产构建，不用 dev server 结论代替）**：
   ```bash
   npx vue-tsc --noEmit
   npm test
   npm run verify:tools
   npm run build
   npx vite preview --port 4173 --host 127.0.0.1   # 跑 E2E 后再关闭
   node scripts/e2e-mobius-runner-20261019.mjs     # 三视口/计费/降级/兜底
   ```
3. **核对离线预缓存（关键）**：构建后检查产物与 PWA 预缓存清单（Workbox 生成的 SW 清单）中**包含 three 相关 hashed chunk**与本工具 chunk；若默认 glob 未覆盖动态 import chunk，在 `vite-plugin-pwa` 配置中以最小改动把对应 `assets/*-*.js` 纳入 `globPatterns`/`additionalEntries`，**不重写现有 SW 策略**。
4. **限额核查**：统计 `dist/` 总大小、文件数、最大单文件，确认低于 5GiB/20000/25MiB，并记录到 postmortem。
5. **提交推送**（显式列路径，不用 `git add -A`）：
   ```bash
   git fetch origin
   git add package.json package-lock.json README.md \
     src/tools/mobius-runner \
     # 若确有改动：vite.config.ts（SW 预缓存）/ scripts/e2e-mobius-*.mjs / test/mobius-logic.test.ts
   git commit -m "feat(mobius-runner): 新增莫比环 Three.js 3D 翻转跑酷 2026-10-19"
   git push origin main
   ```
6. **上线确认**：EdgeOne 构建成功后，在 https://www.fangzi.asia 打开 `#/t/mobius-runner`，真机验证可玩、全屏、可离线（断网重开仍可进入）、安装到主屏后作为 PWA 启动正常。

## 配置项说明

- 工具无服务端环境变量。前端可控项（存本机、带默认值回退）：
  - `fx: 'auto'|'high'|'low'`（特效档；auto 由 gpu-detect 决定）
  - `muted`、`vibrate`、`reduceMotion`
  - 计费：`manifest.billing`（mode=freemium、currency=CNY、建议 priceCents=1290、features 列表）；运行期一切权益/价格判定走 `src/core/billing`，不在本工具内私建价格逻辑。
- 存档结构（IndexedDB `fz-mobius-runner-v1`）：单例 `{id:'state', best, totalShards, unlockedThemes[], settings?}`，字段全部可选/带默认，保证后续版本向前兼容。

## 上线 / 灰度方案

- 静态站点无传统灰度；采用“随主站发版 + 客户端可控”策略：
  - 先以 `status:'beta'` 发布（沿用方子 beta 标记），入口可见但标注 Beta，便于观察。
  - 依赖 Service Worker 的版本更新机制让用户渐进拿到新版本；新 SW 激活按站点既有提示进行，避免旧缓存长期滞留。
  - 若需快速止血，可在后续版本通过注册表/入口降级（移除目录）或远端静态回滚（见回滚预案）。
- 回滚触发条件：真机出现大面积白屏/无法进入、明显诱导误付费、严重卡顿致主线不可玩。

## 平台对接指南

- **EdgeOne Pages（主分发）**：已完成接入并绑定域名/HTTPS；本工具随 GitCode main 自动发布，无需新注册与资质。注意静态托管限制：不可运行服务端动态函数、单文件 ≤25MiB（three chunk 远小于此）。控制台用于查看部署记录与缓存刷新（必要时手动刷新 CDN 缓存）。
- **PWA / 应用商店**：本功能只以 PWA 分发，通过“添加到主屏幕”获得类原生体验；**不上架** Chrome Web Store / VS Code / JetBrains 等商店，因此无个人开发者资质与审核负担。
- **Three.js 合规**：通过 npm 安装，许可证 MIT，允许商用与再分发；保留 lock 中版本来源。不要改用任何仅非商用的 3D 库/模型/贴图/音效（本作零第三方素材）。
- **支付/账号**：不新增任何支付、登录、第三方 SDK；专业版解锁复用方子既有计费框架，按其既定方式对账，本工具无新增外部对接地址或密钥。

## 运维监控指标与告警

- 无服务端指标。客户端侧在实现期可保留**本地、可开关**的轻量自检（不接第三方统计、不上传）：渲染后端（webgl/降级/不支持）、平均帧率档、是否进入兜底。
- 质量门即主要“监控”：构建失败、vue-tsc/单测/E2E 不通过即阻断发布。
- 线上反馈走方子既有的“系统邮件反馈”入口（收件人 fangziasia@163.com），收集崩溃机型/浏览器与表现问题。

## 日志管理

- 不产生服务端日志。浏览器端仅在开发/调试时用 console，生产代码不打印用户数据；报错兜底界面给出可复制的环境信息（浏览器/是否支持 WebGL/质量档）便于用户随邮件反馈。

## 备份与容灾

- 无服务端数据，无需服务端备份。用户存档在本机 IndexedDB：清除站点数据会清空最高分（在设置/FAQ 中提示）；结构只增不删，升级不做破坏性迁移。
- 容灾：EdgeOne 静态多节点本身高可用；发布产物可由 GitCode 任意历史提交重新构建恢复。

## 常见故障排查与回滚预案

| 现象 | 可能原因 | 排查/处理 |
| --- | --- | --- |
| 进入工具白屏/黑屏 | three 动态 chunk 未加载或 SW 旧缓存 | 查网络面板 chunk 200、SW 清单；强制更新 SW；检查 `use-lazy-init` 异步到达分支 |
| 低端机卡顿/掉帧 | 像素比过高/开了 bloom/粒子过多 | 让 auto 档生效：降 pixelRatio、关 UnrealBloom、减粒子；确认对象池无频繁 new |
| 翻转后“判定跟看到的不一致” | 几何换面与 logic.face 不同步 | 以 `geometry.ts` 同一参数化为唯一真相；跑 logic 单测“过扭转区换面”；固定步长排查 |
| 手机上没声音 | AudioContext 未在用户手势后 resume | 首次点击后 resume；静音开关检查；iOS 需交互解锁音频 |
| 切后台回来直接死亡 | 未在 visibilitychange 暂停 | 失焦即 pause，不计碰撞；回前台显式继续 |
| 断网打不开 | three chunk 未进预缓存 | 核对 Workbox 预缓存清单并补充 glob，重新发版 |
| 无 WebGL 设备 | 环境不支持 | 显示友好“不支持/请用现代浏览器”兜底，不抛错白屏 |

**回滚**：本工具独立目录与独立 chunk，回滚不影响其它功能——
1. 首选：`git revert <发布提交> && git push origin main`，EdgeOne 自动重建即回到旧版（注册表不再发现该工具目录）。
2. 必要时在 EdgeOne 控制台回退到上一成功部署并刷新 CDN 缓存。
3. 回滚不触碰用户其它工具数据；本工具自身 IndexedDB 为独立库，遗留也不会影响站点。
