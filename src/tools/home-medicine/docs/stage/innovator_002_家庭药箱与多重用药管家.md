# 功能建议：家庭药箱与多重用药梳理管家

- 序号：002
- 建议形态：网页应用（PWA，纯前端本地工具，手机优先）

## 使用场景
谁：家有高血压/糖尿病/冠心病等慢病老人的子女、照护者；本人长期多药、服保健品的中老年人。
时机：每 3–6 个月整理药箱；就诊/住院前；新增一种药；每天按时段服药；眼药水等开封后倒计时。
问题：药盒乱、过期药不舍得扔；西药+中成药+保健品成分重复而不自知；服药时段多易漏服/重复服；就诊说不清在用哪些药；开封后的眼药水/糖浆不知还能用多久。

## 功能描述
1. 家庭药箱：录入药品（名称、规格、批号、有效期、剩余量、存放位置、所属成员、处方/OTC/保健品），手动+可选条码；临期/过期分级预警。
2. 开封倒计时：眼药水默认开封 4 周、部分制剂按设定，到期提醒停用。
3. 用药方案与服药计划：按早中晚睡前生成时间表与提醒（Notification+.ics），漏服处理提示（仅说明书层面、不个体化诊疗）。
4. 就诊带药清单：一键导出"在用药/保健品/中成药全清单"（通用名、剂量、频次、起止时间）给医生/药师，支持打印与分享图片。
5. 成分重复与多药风险提示：基于药品通用名/类别内置常见重复成分与高风险组合规则（如对乙酰氨基酚多药叠加、抗凝+NSAID、同类降压），命中即提示并建议咨询药师；**只提示已知规则，不做个体化诊断**。
6. 精简建议清单：标注疑似重复/过期/非必需，供药学门诊复核。

## 目标人群
上亿慢病老年家庭及其成年子女（购买决策者与实际付费者多为子女）。付费意愿：关乎父母安全，情感价值极高，愿为"理药+提醒+就诊清单"付费；使用频次高（每日服药、每季度理药）。

## 建议形态
手机优先 PWA：药名、病史属高度隐私，本地存储不上传；拍照录药、随时查看、就诊现场出示清单，移动场景天然；免安装便于给父母一键打开。

## 落地价值
降低误服过期药、重复用药、漏服风险（健康/情感价值），节省子女反复叮嘱与就诊沟通时间，减少药费浪费。多场景链路：买药入库 → 服药计划提醒 → 临期/成分预警 → 季度梳理 → 就诊清单 → 复诊调整。

## 多场景链路与红海规避判断
- 是否同质化小工具：否（不是单一吃药闹钟，而是药箱+成分规则+梳理+就诊导出的照护链路）。
- 多场景链路：入库→计划→预警→梳理→就医→调整闭环，多家庭成员协作。
- 持续使用频次与付费空间：每日使用、季度梳理，高频高粘性；可按家庭成员数/高级规则/导出订阅或买断。
- 红海规避：通用吃药提醒 App 多但偏个人；面向"家庭多重用药梳理+成分重复规则+就诊清单"、本地隐私且子女视角的产品不足，专业药学服务又难以日常触达。

## 强规则核对
| 强规则 | 是否满足 | 依据 |
| --- | --- | --- |
| 真实价值 | 是 | 降低老人用药安全风险（健康/情感价值），节省子女与就医沟通成本 |
| 购买意愿 | 是 | 子女愿为父母用药安全付费，慢病家庭规模大、频次高 |
| 形态贴合目标人群 | 是 | 隐私数据本地化、手机拍照与随身查看、就诊现场可用 |

> 边界：只做记录、计划、说明书层面的已知规则提示与就诊材料整理，**不诊断、不开药、不替代医生/药师个体化判断**；高风险组合一律建议线下咨询。
