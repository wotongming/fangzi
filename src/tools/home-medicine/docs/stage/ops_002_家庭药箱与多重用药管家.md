# 部署运维指引：家庭药箱与多重用药梳理管家

- 对应 architect：architect_002_家庭药箱与多重用药管家.md
- 编写日期：2026-10-19

## 部署架构与环境准备
纯静态 PWA，无后端；EdgeOne Pages 托管 main 自动部署；数据本地 IndexedDB，照片本地压缩。

## 软硬件配置清单
无服务器；仓库标准构建链。

## 部署步骤
vue-tsc→npm test→build→verify:tools→推送 main→访问 `/#/t/home-medicine` 验证。

## 配置项说明
用药安全规则与开封默认值集中 `lib/rules-cn.ts`（版本化、带来源）；无密钥。

## 上线/灰度
静态全量；预览域名先行；回滚=回退增量目录提交。

## 平台对接指南
EdgeOne Pages 连 GitCode main 自动构建静态站点，免费额度内；无服务端函数、无外部医疗 API、无插件商店。

## 运维监控与告警
无服务端日志；重点关注健康类措辞合规——规则更新须保守可溯源，宁删不臆断；通知不可达（移动后台）以 .ics 兜底，UI 已说明。

## 日志/备份容灾
无服务端数据；提供加密家庭档案导出换机；清浏览器数据会丢失，明示。

## 故障排查与回滚
提醒不触发→检查 Notification 授权/SW；规则误报→以单测定位并收敛规则；严重问题回退该目录提交，不影响其他工具。
