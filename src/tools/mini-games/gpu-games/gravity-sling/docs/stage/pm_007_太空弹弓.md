# PM 评审 · 007 太空弹弓（《挽星弓》）

- 日期：2026-10-22
- 对应 innovator：`innovator_007_太空弹弓.md`
- 评审结论：**可集成（mini-games 合集内新增一个 GPU 子游戏，非独立顶层工具）**

## 一、需求摘要
原创极简太空引力弹弓关卡游戏：按住拖拽反向拉伸 → 力度 + 角度双自由度 → 实时预测轨迹 → 松手发射；多行星反平方引力借力、捕获、收集星、combo 连锁、**50 关**有界饱和难度演进；程序化 Canvas 美术 + WebAudio 音效，零外部素材、零后端、离线可玩。交互刻意区别于被参照作品的 one-tap 时机释放，本作是 pullback slingshot。

## 二、与现有功能去重判定（对照 fangzi 35 个顶层工具与 8 个合集子游戏）

| 对照对象 | 现有玩法 | 与本作本质差异 | 判定 |
| --- | --- | --- | --- |
| `orbit-surge` 星轨穿梭 | 单指**拖动**光体横向跟随，穿越下落粒子障碍，**被动生存闪避**，撞死结束、生存时长计分 | 本作是**主动瞄准—蓄力弹射—引力弹道—命中目标过关**；输入（拖拽反向拉伸 vs 横向跟随）、物理（反平方引力弹道 vs 直线下落障碍）、胜负（命中星门过关 vs 闪避到撞死）、计分（关卡 + combo + 收集星 vs 生存秒数）全部不同 | 不重复，新增 |
| `merge-planet` 合成宇宙 | 顶部滑轨**投放**，同级星球 matter.js 物理**碰撞合成**逐级进化，静态堆叠 | 本作无投放、无同级合并、无静态堆叠；轨迹为引力抛物线/借力弹道，目标是命中移动/固定星门 | 不重复，新增 |
| `glow-match` 炫光连消 | 三消交换连锁 | 品类无关 | 不重复 |
| `neon-pulse` 霓虹脉冲 | 下落节奏点拍 | 品类无关 | 不重复 |
| `mobius-runner` 莫比环跑酷 | 3D 无尽跑酷翻转 | 品类无关 | 不重复 |
| 2048 / memory / klotski | 经典益智 | 品类无关 | 不重复 |
| 其它 27 个顶层工具 | 办公/生活/文件处理 | 无重叠 | 不重复 |

合集内当前**无弹射器、无引力弹道瞄准、无关卡/靶子命中类**游戏，存在品类空位。

## 三、集成形态与工具数口径（重要，向用户解释用）
- 本作作为 `mini-games` 合集的第 9 个子游戏，登记到 `index.vue` 的 NEON 分组；**不新建 `src/tools/<id>/manifest.ts`**。
- `scripts/verify-tools.mjs` 与 `src/core/registry.ts` 均只枚举 `src/tools/*/manifest.ts`（顶层单层 glob），子游戏不计入工具数；因此 `npm run verify:tools` **保持 35**，不会变成 36。
- 不改 registry 自动发现逻辑、不改路由表、不改 ToolRunnerView、不改搜索/示例提问；宿主 mini-games 的 PWA 身份、manifest、SW 策略保持不变。

## 四、技术可行性（纯前端、零新增运行时依赖）
- 渲染：原生 Canvas 2D + DPR 适配 + ResizeObserver；不引入 three.js / matter.js 等重依赖。
- 物理：反平方引力 + 软化半径、固定时间步 + dt clamp ≤50ms + 子步进；纯函数可 node 单测。
- 音频：复用合集 `audio/synth.ts` 的 `NeonAudio` 与 `haptic`，缺的音色在其上扩展，不另起一套 AudioContext。
- 存储：最高分由父级 `lib/storage.ts` 写入既有 IndexedDB `fz-mini-games-v1`，key `gravity-sling:classic`；本游戏自动快照用独立 localStorage 键 `fangzi:gravity-sling:auto-save:v1`，与 merge-planet 的 `fangzi:merge-planet:save:v1` / `auto-save:v1` 物理隔离，互不串键。
- 平台合规：EdgeOne Pages 静态托管可承载；无后端、无账号、无上传；素材 100% 程序化生成，无第三方图片/音频/字体授权风险。

## 五、变现钩子（主方案：freemium，beta 不硬锁）
- 本体免费：50 关主线、基础预测轨迹、最高分与 combo 全部可玩。
- 预留解锁项（复用合集既有 `neon-library` 权益机制，beta 阶段默认放行、不设付费墙）：主题皮肤、常驻预测轨迹线、高级挑战关卡包；不售弹药/无敌/跳关，不做付费碾压。
- 不新增广告 SDK / 网盟；付费入口仍走合集 `useToolBilling` 与 `manifest.billing` 既有 feature。

## 六、侵入性与存量保护
- 增量新增 `gpu-games/gravity-sling/` 目录；`index.vue` 仅追加一条 `GameDef` 与必要的 NEON 分组渲染（模板已有同构循环，无需新组件槽位）。
- 不改动其它子游戏代码、不改动既有 IndexedDB/localStorage 键；合集高分库结构向后兼容，旧用户最高分零迁移。
- SW：游戏 chunk 走 Vite 既有动态分包，不新增大体积素材，不改 SW 预缓存策略。

## 七、风险与缓解
| 风险 | 等级 | 缓解 |
| --- | --- | --- |
| 引力参数手感失衡（力度上限、G、软化半径、捕获半径、combo 窗口） | 中 | 纯函数抽离 + 固定步长，PC/手机反复试玩调参，常数量级与依据写入 postmortem |
| 低端机帧率/粒子压力 | 中 | 粒子数量封顶、预测轨迹限步数、后台暂停由 FocusStage 托管 |
| 50 关可解性 | 中 | 确定性种子生成 + 离线求解器复用同一物理；最小角度窗口 4°、净空 6px；50 关记录解由单测复放，证据写入 `level-evidence.json` |
| 音频自动播放策略 | 低 | 首次 pointerdown 手势内 `ensure()`，静音/失败静默降级 |

## 八、结论
**可集成，纳入本轮编码**；档位 **M**（标准）：单链路关卡游戏、无 Worker/无本地 AI/无大模型，纯 Canvas2D + 本地存储，三视口 E2E + 纯逻辑单测 + 真实截图。
