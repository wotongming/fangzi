# 部署运维指引 · 007 太空弹弓（《挽星弓》gravity-sling）

- 日期：2026-10-22
- 上游：`dev_007_太空弹弓.md`
- 部署形态：fangzi PWA 子游戏，随整站静态发布到腾讯云 EdgeOne Pages；无独立后端、无独立域名、无独立商店上架。

## 一、部署架构
- 运行环境：静态 SPA（Vue 3.5 + Vite + vite-plugin-pwa），宿主 `mini-games` 合集路由 `/#/t/mini-games`，子游戏通过合集 NEON 卡片动态分包进入。
- 存储：浏览器本地——最高分 IndexedDB `fz-mini-games-v1`（父级托管）；自动快照 localStorage `fangzi:gravity-sling:auto-save:v1`。无服务端数据库、无账号体系、无遥测上报。
- 网络：离线可用；不发起任何外部 CDN / 图片 / 音频 / 字体 / 接口请求。

## 二、环境与工具链
- 本地开发：`npm run dev`；构建：`npm run build`；预览：`npx vite preview --port 4173 --host 127.0.0.1`。
- 质量门命令：`npm test`、`npx vue-tsc --noEmit`、`npm run verify:tools`（必须 = 35）、`npm run build`。
- 无新增环境变量、无 `.env`、无密钥配置。

## 三、发布步骤（随 PWA 主线）
1. 确认本地 `git fetch origin` 后工作区干净、无分叉；显式路径 `git add` 本游戏目录、测试、E2E 脚本、README 与文档。
2. 依次跑通质量门：单测全绿、vue-tsc 0、verify:tools=35、build 成功；检查 `dist/` 体积与最大单文件不超 EdgeOne 限额（5 GiB / 20000 文件 / 25 MiB）。
3. push 到 `main`；EdgeOne Pages 按既有 Git 推送流水线自动构建发布；无需在控制台为子游戏新增路由或 MIME 规则。
4. 发布后复核：
   - 访问 `/#/t/mini-games`，NEON 区出现「挽星弓」卡片；
   - 进入游戏可拖拽发射；断网刷新仍可进入；
   - `devtools → Application → Service Workers` 无更新失败；chunk 预缓存清单含本游戏分包。

## 四、缓存与离线策略
- 本游戏零大体积素材，不改变 SW 既有 `runtimeCaching` / 预缓存规则；游戏 chunk 由 Vite 动态分包，随既有 glob 进入预缓存。
- 不新增 public 目录资源；不引入 >5MB 文件。
- 版本更新：当前链 `gravity-sling:levels:50:v2`；旧链 `gravity-sling:levels:13:v1` 可被识别并迁移；后续关卡/规则变更须继续升 `SAVE_VERSION`/`CHAIN_ID`，不兼容旧快照时安全回退，不会污染新局。50 关落地口径见第九节。

## 五、监控与故障排查
| 现象 | 可能原因 | 处置 |
| --- | --- | --- |
| 进入卡片后黑屏/加载失败 | 动态 chunk 404 或 SW 旧缓存 | 确认 build 产物完整；EdgeOne 刷新/预热 CDN 缓存；用户硬刷新触发 SW skipWaiting/claims |
| 无音效 | AudioContext 未在手势内 unlock；系统静音；`muted=true` | 首次 pointerdown 内 `ensure()`；检查合集静音开关；不支持 WebAudio 静默降级不影响玩法 |
| 拖拽画面滚动/选中 | CSS `touch-action/user-select` 未生效 | 核查容器样式；移动端不允许页面纵向滚动穿透 |
| 重载后未弹续玩 | 快照键被清除或校验失败（损坏/版本不符） | 属设计内安全回退，开新局即可；控制台不应抛未捕获异常 |
| 低端机掉帧 | 粒子/预测步数压力 | 沿用合集 particle 档位 `low`；粒子数量封顶；必要时下调尾迹长度与预测步数 |

## 六、数据备份与容灾
- 本地数据无云端备份能力；快照损坏/清除仅影响当前未完成对局，最高分由合集库维护。
- 回滚：revert 本游戏 commit；无数据库 schema 变更、无迁移脚本；回滚后旧 `gravity-sling:auto-save:v1` 键留存在用户浏览器也不影响其它游戏。

## 七、平台合规
- EdgeOne Pages：纯静态、无服务端函数、无第三方外链；资源体积在限额内。
- 素材合规：视觉 100% Canvas 程序化绘制，音频 100% WebAudio 合成；无第三方图片/字体/音频/模型，无授权纠纷。
- 内容合规：休闲弹射玩法，无暴力写实、无广告诱导、无内购碾压；beta 阶段本体免费不硬锁。

## 八、真机待验清单（上线后）
- 手机相册/触控：单指拖拽跟手、橡皮筋与预测线实时刷新、无滚动穿透；
- 低端安卓 WebView / 微信内置浏览器：帧率、音频 unlock、Canvas DPR 清晰；
- 切后台再回前台：FocusStage 自动暂停，回前台手动继续，进度不丢；
- 系统语言/深色模式不影响画布对比度；横竖屏切换不溢出。

## 九、v2.0 运维增补：50 关快照链、缓存与发布复核

### 9.1 本地存储口径
| 用途 | 键 | 版本/链 | 说明 |
| --- | --- | --- | --- |
| 自动快照 | `fangzi:gravity-sling:auto-save:v1` | `SAVE_VERSION=2`；当前链 `gravity-sling:levels:50:v2`；旧链 `gravity-sling:levels:13:v1` | 键名保持不变；旧 v1 快照迁移保留分数/连击/星尘/借力/飞船，关卡号钳制 0–49；损坏或标识不符安全回退 null。 |
| 关卡进度 | `fangzi:gravity-sling:progress:v1` | `version=1`；tool=`gravity-sling` | 只存 `maxReached/bestScore`；非法值回退默认并钳制，不回退已解锁进度。 |
| 合集高分 | IndexedDB `fz-mini-games-v1`，key `gravity-sling:classic` | 父级托管 | 本轮不改库名、key 与写入逻辑；内核不直写该库。 |

- 禁止读写 `fangzi:merge-planet:*`、`fz-mobius-runner-v1` 及其它工具键；故障排查时先按上表隔离是快照、进度还是高分问题。

### 9.2 SW 与离线缓存
- 本游戏零大体积素材，不新增 public 资源、不引入 >5MB 文件；不修改既有 `runtimeCaching` 与预缓存规则。
- 游戏 chunk 由 Vite 动态分包，随既有 glob 进入 SW 预缓存；发布后在 DevTools → Application → Service Workers 确认 `gravity-sling-*.js` 命中预缓存。
- 离线 E2E 顺序：在线进入 → 等 `navigator.serviceWorker.ready` → 在线 reload 取得 `controller` → 断网二次加载；首次加载前直接断网会绕过 SW，不能作为离线失败证据。

### 9.4 故障排查增补
| 现象 | 可能原因 | 处置 |
| --- | --- | --- |
| 旧玩家进入后进度被重置 | 旧快照链不兼容或进度键被误清 | 检查 `validateSave` 是否识别 `LEGACY_CHAIN_ID`；确认 `PROGRESS_KEY` 未被其它流程清除；损坏档按设计回退新局，不应抛未捕获异常。 |
| 后期关预测线卡顿 | 拖拽静止时仍重复积分 150 步 | 检查预测缓存键是否包含关卡、拖拽坐标、力度与时间窗口；确认高密度粒子降级生效。 |
| 后期关弹道飞出/穿模 | 多体近场合力爆炸 | 检查 `MAX_ACCEL` 上限与软化半径；确认预测、运行时、求解器共用同一 `gravityAccel`。 |
| 某关离线可解但真机难打 | 4° 角度窗口在小屏偏窄 | 记录关卡号、截图与操作；只微调该关门径/陨石位置，重新跑生成器、单测与 E2E，不手改 `levels.generated.ts`。 |
| 选关按钮手机点不到 | 缩放后高度 <44px | 检查 `levelButtons()` 世界坐标矩形与 `layout()` 缩放；E2E 手机最小触控高度应 ≥44px。 |

### 9.5 回滚
- 回滚 v2.0 commit 后，旧浏览器中 v2 快照/进度键可能残留；由于键名带版本与 tool 标识，不会影响其它游戏。
- 若需要重新部署旧 13 关版本，旧 `gravity-sling:classic` 高分由合集库保留；自动快照因链标识不符会被安全忽略。
