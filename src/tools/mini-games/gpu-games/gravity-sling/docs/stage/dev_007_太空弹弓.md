## 二、内核 API（`game/sling-core.ts`）

### 2.1 导出类型与常量
```ts
export const WORLD_W = 1000
export const WORLD_H = 1500
export const FIXED_DT = 1 / 120
export const MAX_FRAME_STEPS = 4
export const COMBO_WINDOW_S = 1.5
export const COMBO_MAX_MULT = 4
export const PREDICT_STEPS = 90
export const AUTO_SAVE_KEY = 'fangzi:gravity-sling:auto-save:v1'
export const SAVE_VERSION = 1
export const TOOL_ID = 'gravity-sling'
export const CHAIN_ID = 'gravity-sling:levels:13:v1'

export type Phase = 'intro' | 'aim' | 'fly' | 'win' | 'lose' | 'resume'
export type BodyKind = 'gravity' | 'repel' | 'blackhole' | 'asteroid' | 'collect' | 'portal' | 'moving'
export interface Body { id:number; kind:BodyKind; x:number; y:number; r:number; mass?:number; orbit?:{cx:number;cy:number;rx:number;ry:number;speed:number;phase:number}; collected?:boolean; open?:boolean }
export interface LevelConfig { index:number; title:string; hint:string; shots:number; timeLimit:number; predictAlways:boolean; anchor:{x:number;y:number}; bodies:Body[] }
export interface Ship { x:number; y:number; vx:number; vy:number; angle:number; trail:{x:number;y:number}[]; alive:boolean }
export interface SlingState { level:number; score:number; combo:number; bestCombo:number; comboAt:number; collected:number; shotsLeft:number; timeLeft:number; phase:Phase; ship:Ship; assists:number; assistsChain:number; stars:number[]; levelStars:number; attempt:number; savedAt:number }
```

### 2.2 纯函数（无 DOM，供 node 单测）
- `levelByIdx(i:number): LevelConfig`：返回第 i 关（0..12）；越界回退第 13 关并钳制。
- `gravityAccel(bodies:Body[], x:number, y:number, G:number, soft:number): {ax:number; ay:number}`：遍历引力/推斥/黑洞，反平方 + 软化；repel 取反；黑洞质量 ×3。
- `aimVector(anchor:{x:number;y:number}, drag:{x:number;y:number}): {dx:number; dy:number; len:number; nx:number; ny:number}`：发射方向 = 锚点 − 拖拽点，归一化；len 为拉伸长度。
- `powerFromPull(len:number, maxPull:number): number`：clamp 0..1，二次曲线 `p²`。
- `predictTrajectory(level:LevelConfig, ship:Ship, dir:{nx:number;ny:number}, power:number, G:number, soft:number, steps=PREDICT_STEPS): {x:number;y:number}[]`：从锚点以 `v0=dir·power·V_MAX` 积分，记录点列；命中 portal/实体/出界即停。
- `stepFrame(state:SlingState, level:LevelConfig, dt:number, now:number): FrameEvent[]`：固定步长推进；返回事件 `{type:'assist'|'collect'|'crash'|'blackhole'|'portal'|'out'|'timeout'|'shots', bodyId?:number}`。
- `resolveCombo(combo:number, now:number, lastAt:number, window:number): {combo:number; mult:number}`：窗口内 +1，否则归零；倍率 `min(combo, COMBO_MAX_MULT)`。
- `serializeSave(state:SlingState, level:LevelConfig, savedAt=Date.now()): SavePayload`
- `validateSave(raw:unknown): {ok:boolean; payload:SavePayload|null; dropped:number}`：version/tool/chain/时间戳/坐标有限性严格校验。
- `loadSave(key, storage?): SavePayload|null`、`readSaveMeta(key, storage?)`、`persistSave(payload, key, storage?)`、`clearSave(key, storage?)`：localStorage 适配可注入，异常静默回退。

## 三、关键实现要点

### 3.1 渲染循环
- `mount` 内 `ResizeObserver` 观察 canvas 父级，测量 CSS 尺寸 → 设置 `canvas.width = cssW·dpr`（dpr 上限 2），计算世界→屏幕 `scale = min(cssW/WORLD_W, cssH/WORLD_H)` 与居中偏移。
- rAF 循环：`dt = min((now-last)/1000, 0.05)`；`paused` 或 `phase==='win'|'lose'|'resume'` 时只渲染背景/结算，不推进物理；累加器按 `FIXED_DT` 补步，最多 `MAX_FRAME_STEPS` 步，丢弃积压防螺旋。
- 绘制顺序：星云背景（渐变 + 固定随机星点）→ 力场淡环 → 天体（行星环/推斥红/黑洞吸积盘/小行星/收集星/星门光柱/动目标轨道）→ 预测虚线 → 橡皮筋与锚点 → 飞船 + 尾迹 → 粒子爆发层 → HUD 文字（关卡/分数/combo/剩余发/时间）→ 引导/结算/续玩浮层。

### 3.2 输入
- `pointerdown`：仅在 `phase==='aim'` 且落点在锚点 80px 世界半径内（热区 ≥44px CSS）进入拖拽；`audio.ensure()`；`setPointerCapture`。
- `pointermove`：更新拖拽点，节流（每 16ms）重算 `predictTrajectory`；更新拉伸音高（`tone` 频率随 power 上升）。
- `pointerup`：`power < 0.12` 视为取消回弹；否则按 `aimVector` 给初速度进入 `fly`，发射音 + 尾迹粒子 + `haptic`。
- 结算浮层按钮用画布命中矩形判定：重试本关 / 下一关 / 继续上一局 / 开始新局 / 跳过引导。
- `touch-action:none; user-select:none; -webkit-touch-callout:none` 防滚动与选中。

### 3.3 物理与碰撞（`stepFrame`）
- 每固定步：`a = gravityAccel(...)`；`v += a·dt`；`p += v·dt`；记录尾迹（最多 60 点）。
- 逐天体判定：
  - `collect`：距离 ≤ `r + shipR` → 拾取，加分 × combo 倍率，事件 `collect`。
  - `gravity`：距离 ≤ `assistRadius` 且 > 实体 `r` → 事件 `assist`（仅首次进入触发，标记 `assisted`）；距离 ≤ 实体 `r` → `crash`。
  - `repel`：只产生反向加速度，无碰撞实体；进入近距不判死。
  - `blackhole`：距离 ≤ 视界半径 → `blackhole` 失败；`assistRadius` 内可借力。
  - `asteroid`：距离 ≤ `r + shipR` → `crash`。
  - `portal`（含 `moving` 实时位置）：距离 ≤ `r` → `portal` 过关。
  - 出界（x<0|>W|y<0|>H）→ `out`。
- 限时：`timeLeft -= dt`，归零 `timeout`；限发：发射时 `shotsLeft--`，飞行结束未过关且 `shotsLeft<=0` → `shots` 失败。
- combo：`assist` 事件按 `resolveCombo` 更新；`collect` 复用当前倍率；`comboAt` 记录时间；超时窗口在 `stepFrame` 内归零。

### 3.4 关卡表（13 关，坐标基于 1000×1500）
- 锚点统一 `{x:500, y:1380}`；第 1 关 portal `{x:500, y:300}` 无引力；第 2 关沿中轴布 3 颗收集星；3 关旁侧小恒星；4/5 关遮挡与抬升；6/7 双星/三星接力；8 关 3 发；9 关 portal `open` 周期（`open` 字段由内核按时间窗开关）；10 关 moving 椭圆；11 关 repel；12 关 blackhole + asteroid 带；13 关混合。
- 每关配置必须通过单测：`shots>0`、`portal` 恰好 1 个、坐标在世界内、质量/半径为有限正数。

### 3.5 快照
- 触发：`visibilitychange` hidden（由 wrapper 透传？不——内核在 `pagehide`/hidden 时写一次；FocusStage 已管暂停，内核只在 `phase==='aim'|'fly'` 且非空局面写快照）、`pagehide`、15s 定时器。
- 写入前过滤：无飞船实体、未发射过的空局面不写；`win/lose/reset` 时 `clearSave(AUTO_SAVE_KEY)`。
- 重挂载：`mount` 开头 `loadSave(AUTO_SAVE_KEY)`，有效则 `phase='resume'` 弹层；`resumeAuto()` 还原 `level/score/combo/collected/shotsLeft/timeLeft/ship/assists`；`discardAuto()` 清快照并 `reset()` 到第 1 关。
- 校验失败/损坏 → 清掉坏档，开新局，不抛错。

### 3.6 音频（复用 NeonAudio）
- wrapper/内核持有一个 `NeonAudio`；`setMuted` 透传；`ensure()` 在首次 pointerdown 调用。
- 事件映射：发射 `explode(0.4)` 短噪声 + `tone(220→440)` 上扫；收星 `hit(true)`；借力 `blip(combo)`；命中 `tone` 琶音三连；失败 `tone(110,false)` 低频；combo 升阶 `tone` 五声音阶上行；拖拽拉伸 `tone(180+power·320)` 随力度变化。
- `haptic`：发射短震、命中双震、失败长震；`vibrate=false` 静默。

### 3.7 wrapper（`gravity-sling.vue`）
- props：`paused/muted/vibrate/particle`（与合集契约一致）；emits：`score/combo/gameover`。
- `onMounted`：`mount(canvas, { onScore: v=>emit('score',v), onCombo, onGameover:()=>emit('gameover'), muted, vibrate })`；`window.__gravitySling = handle.debug`（E2E 接缝，不暴露 UI）。
- `watch(paused)` → `handle.setPaused`；`watch(muted)` → `handle.setMuted`；`onBeforeUnmount` → `handle.destroy()`、删除 `window.__gravitySling`。
- 模板仅一个全屏 `<canvas ref>`，无额外 DOM 控件；结算/引导全部由内核画布绘制。
