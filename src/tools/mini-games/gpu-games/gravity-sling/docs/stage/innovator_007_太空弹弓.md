# 功能建议：《挽星弓》——极简太空引力弹弓关卡小游戏

- 序号：007
- 建议形态：纯前端单文件网页小游戏（原生 JS + Canvas 2D + Web Audio API，零依赖、零外部素材，可离线、可作为 PWA 安装）
- 日期：2026-10-22

---

## 需求来源

### 一、被参照作品《Starfling》核心玩法联网核实结论

> 说明：本需求只借鉴"引力弹弓"这一通用物理机制与玩法思想，**不复制《Starfling》任何受版权保护的表达**（名称、美术、音效、关卡、角色、文案、成就等级名均不沿用，详见文末「原创性与防 IP 边界」）。以下为联网核实到的《Starfling》真实机制，作为机制层参照事实记录。

**来源 1**
- 站点：Pizza Edition（网页小游戏聚合站）
- 检索关键词：`Starfling game gameplay slingshot gravity planets`
- 链接：https://pizzaedition.cc/game/starfling
- 核实要点：
  - 球**自动环绕**引力井（gravity well）飞行；**单点点击**（触屏点按 / 鼠标点击 / 空格）在时机正确时，让球沿**轨道切线方向**脱轨弹出；
  - 球飞入下一个引力井的**捕获半径**即被锁定，重新进入环绕状态；循环往复爬升得分；
  - 开局前 5 次弹射显示**点状预测轨迹**辅助瞄准；飞行途中重力向下拉拽，需要瞄得比目标略高；
  - 被捕获后 **1.2 秒内再次释放**触发 combo 加成；连锁等级 2-chain QUICK → 3-chain FAST → 4-chain BLAZING → 5-chain INSANE → 6+ GODLIKE，倍率逐级放大；跳过一颗星可得双倍分；
  - 难度随分数爬升：轨道变快、星体变小、间距拉大、角度范围变宽；
  - 双模式：Classic 一命到底；Party 3 命（上限 5）+ 道具（磁铁扩大下一颗星捕获半径、火箭自动穿越 3 星、爱心续命）；
  - 程序化生成音频与触觉反馈；失败即漂入虚空、本局结束；无尽街机、无体力、无局间冷却。

**来源 2**
- 站点：TMFNK（独立游戏评论/收录站）
- 检索关键词：`Starfling 游戏 玩法 弹弓 引力 行星`、`Starfling: Tap, Release, Sling Between Stars`
- 链接：https://www.tmfnk.com/enjoy/games/starfling/
- 核实要点：
  - 原版为极简单文件 HTML、**零依赖**，浏览器免费游玩，同时上架 iOS / Android，支持原生触觉反馈与离线游玩；2026 年 4 月登上 Hacker News（39 分）；
  - 核心循环：环绕一颗星 → 点按释放 → 落入下一颗星引力井 → 捕获后连锁再环绕 → 分数爬升；错过即漂入虚空；
  - 其衍生作品 *Orbital Tap* 引入**真实引力物理**：引力常数 G、软化半径（softening radius，防止靠近天体时力场奇点爆炸）、不同质量的引力井、捕获半径、轨迹预测；Web Audio API 实时合成音符；最佳成绩存于 localStorage；
  - 评论指出核心概念被三名独立开发者分别朝"极简紧凑 / 物理厚重 / 实验变体"三个方向二次开发，说明该机制本身具备可延展性。

**来源 3**
- 站点：Apple App Store（官方应用商店页）
- 检索关键词：`STARFLING: One-Tap Space Game App Store`
- 链接：https://apps.apple.com/ge/app/starfling-one-tap-space-game/id6762553068
- 核实要点：
  - 官方自述：极简 one-tap 街机太空游戏，在星与星之间弹射；把握释放时机；快速捕获连锁得 combo 奖励；连锁 5 次以上获得更高奖励；每日全球排行榜；飞行轨迹即独一份的生成艺术图；记录最佳局、捕获星数与百分位排名；
  - 一局 30 秒左右，单手操作，专为短时休闲设计；无付费碾压、无体力条、无局间计时；本体免费，**可选一次性内购去除广告（USD 3.99）**；
  - 物理定位：原版街机化抽象（arbitrary arcade slingshot），未做真实轨道力学模拟。

### 二、机制核实后的关键事实校正（供后续阶段注意）

《Starfling》的真实交互是「**自动环绕 + 单点时机释放**（one-tap timing）」，**并非**「按住拖拽、拉伸力度矢量、再松手弹射」的弹弓操作；其物理为街机抽象化，重力仅表现为飞行途中向下的偏折。

本需求在交互模型上与原版做出明确区分：本作采用「**拖拽反向拉伸 → 力度矢量 + 方向双自由度 + 预测轨迹 → 松手发射**」，并引入接近真实的反平方引力模拟与关卡制；只把"引力井 / 捕获半径 / 轨道环绕 / 连锁借力 / combo 节奏 / 预测线 / 难度爬升 / 程序化音画 / 单文件离线"这些**通用机制思想**作为参照。差异对照见文末「原创性与防 IP 边界」。

## 使用场景

- **谁**：18–40 岁、通勤/排队/午休/睡前有 30 秒到 3 分钟空档的轻度休闲玩家；喜欢物理手感、combo 节奏、三星收集类玩法的小玩家；独立开发者/极简游戏爱好者。
- **何时遇到问题**：地铁上、电梯口、排队买饭、会议间隙想打开一个游戏"来一把"，但不想下载几百 MB 的 App、不想看冗长开场、不想被体力条打断；玩重操作游戏时手忙脚乱，想要"上手一秒懂、玩进去有深度"的东西；失败后愿意立刻重开刷更好成绩。
- **现有方案为什么不够用**：
  - 大厂弹弓/物理益智（如愤怒的小鸟系）素材重、叙事重、广告与内购套路多，离线与即开体验差；
  - 网上同类小游戏要么只是"直线弹弓打靶"的原子小工具，缺少连续引力借力的链路与节奏；要么照搬他人作品的美术与文案，缺少原创可商用的干净实现；
  - 纯静态托管环境下（无自研后端）缺少一个可离线、可即点即玩、物理调校有趣的轻量关卡游戏作为产品线内容补充。

## 功能描述

### 1. 产品定名（原创中文候选与选定）

太空 / 弹弓 / 引力主题，全部中文名，不含 `Starfling` 字样或英文近似拼写，不构成商标近似：

| 候选名 | 释义与意象 | 取舍 |
| --- | --- | --- |
| **《挽星弓》**（选定） | "挽"即拉开弓弦；弓弦轻挽、箭走星轨。突出拖拽拉开弹弓、借力航天的动作感与中文诗意，无英文谐音 | **选定**：辨识度高、动作意象贴切、可注册商标方向预留 |
| 《星弦引力》 | 弓弦如琴弦，拨动星与星之间的引力 | 备选：偏柔美，力度感稍弱 |
| 《弹弓巡星记》 | 直白点出弹弓 + 逐星闯关的链路 | 备选：口语化，适合宣传副标题 |
| 《星河弹射舱》 | 偏装置感，适合后续做飞船/座舱皮肤主题 | 备选：与"弓"动作意象略偏 |

**正式产品名：《挽星弓》**；副标题可作："一弓挽星，借力穿空"。

### 2. 单局完整链路（状态机）

1. **触发进入**：用户打开网页（或从 PWA 图标启动）→ 标题页：产品名、历史最佳分、当前关卡进度、"继续 / 选关 / 每日挑战"入口；首局进入第 1 关时弹出**手势教学引导**（半透明动画：在发射锚点按住 → 向后拖拽 → 虚线预测轨迹出现 → 松手发射；三步各停留 2 秒，可点击跳过）。
2. **拖拽瞄准**：
   - 指针在发射锚点按下后可反向拖拽；橡皮筋式牵引距离映射**力度 0–100%**（拉伸越远初速度越大，带力度条与橡皮筋回弹形变视觉）；
   - 发射方向由拖拽矢量的反方向决定，形成"角度 + 力度"双自由度瞄准；
   - 拖拽期间实时跑一遍**预测轨迹步进模拟**（N 步采样的虚线 + 少量预览粒子），随拉力与角度实时更新；前若干教学关永久显示，后续关卡按免费规则（如每关仅前 2 次尝试显示）或付费解锁常驻显示；
   - 拖拽中可松手取消（拉力过短自动回弹归位，不计发射次数）。
3. **松手发射**：
   - 指针抬起，以当前反方向矢量赋予初速度，进入物理飞行模拟；
   - 触发发射音（Web Audio 振荡器频率上扫 + 短噪声摩擦）、弹射粒子尾迹、轻触觉震动（浏览器 `navigator.vibrate` 可选降级）；
   - 画面跟随镜头在小范围内平滑平移/缩放，保持飞行器与关键天体同时可见。
4. **多星引力借力与惯性飞行**：
   - 每个引力天体对飞行器施加反平方引力（含软化半径防止近距力场奇点）；飞行器沿惯性 + 引力叠加的曲线飞行；
   - 飞入选中天体**捕获半径**：进入环绕轨道（可短暂环绕后由玩家再次"切出"借力，或自动切向进入下一段；本作为关卡制，捕获后即完成该段借力并继续惯性飞行）；
   - 连续借助两颗及以上天体完成转向/加速，且两次借力间隔在限定节奏窗口内，累计 **combo 计数与倍率**，伴随音阶上行的合成音效与界面倍率跳字；
   - 途经路径上的**收集星**逐个拾取加分；红色推斥天体按排斥力场处理；黑色黑洞过近被吞噬即失败。
5. **命中目标 / 失败判定**：
   - **成功**：飞行器进入星门 / 靶心捕获区 → 过关结算动画（星门光柱、粒子爆发、命中琶音）；
   - **失败**：撞上天体实体表面、被黑洞吞噬、飞出边界、发射次数耗尽、限时窗口关闭且未命中 → 失败结算（低鸣下行音、淡出重开按钮）。
6. **combo / 评分结算**：结算面板展示：命中时间、收集星数、最高 combo 倍率、剩余发射次数/剩余时间；按规则给 **1–3 星评级**；记录关卡最佳成绩与本地最高分；轨迹剪影可生成为一张可分享的静态图（Canvas 导出 PNG，走剪贴板 / 原生分享，无后端依赖）。
7. **重开 / 下一关**：失败 → "重试本关 / 返回选关"一键重开；过关 → "下一关 / 留在本关刷三星"；关卡进度、三星记录、最高分、已解锁皮肤全部存 localStorage，刷新与离线不丢失。

### 3. 关卡设计：13 关难度演进意图（≥12 关）

| 关卡 | 主题 | 新引入机制 | 教学 / 难度意图 |
| --- | --- | --- | --- |
| 1 | 启程直瞄 | 无引力场；直线拖拽命中静态靶心 | 学会按压力度、方向、松手节奏；建立"拉得越远飞得越快"的直觉 |
| 2 | 沿途收星 | 直线轨迹上布置 2–3 颗收集星 | 理解"飞行路径即得分路径"，学会为收星微调角度 |
| 3 | 引力偏折初体验 | 一颗小恒星位于路径旁侧，轨迹被引力压弯 | 学会提前量与"瞄得比目标高/偏"；首次感受引力干扰 |
| 4 | 单星绕弯借力 | 行星遮挡直线通路，需绕行星半圈后切入星门 | 首次完整 slingshot：靠近 → 被引力拉弯 → 借离心切出 |
| 5 | 反向抬升借力 | 恒星位于路径上方，借引力把轨迹抬升越过障碍 | 理解引力既能拉弯也能"托举改向"，反方向利用力场 |
| 6 | 双星接力 | A 星转向 → B 星再加速 → 星门 | 多星链路雏形；第一段瞄准要为第二段留下合适姿态 |
| 7 | 三连借力链 | 三颗天体连续捕获接力；combo 倍率 ≥3 计为优秀 | 节奏与时机意识；combo 窗口、借力角度链成思考 |
| 8 | 限次数挑战 | 本关仅 3 发，弹尽即失败 | 规划优先；失败次数压力下打磨精准度 |
| 9 | 限时窗口 | 星门周期性开启 / 引力场周期性开关 | 节奏压力：等窗口、卡时点发射；与 combo 节奏叠加 |
| 10 | 动目标 | 靶心沿椭圆轨道缓慢移动 | 预判前置量（lead）；引力 + 动目标双重预判 |
| 11 | 推斥天体登场 | 红色反重力星推开飞行器，与引力星混合布局 | 利用推斥力改向/减速；区分两类天体力场方向 |
| 12 | 黑洞与小行星带 | 黑洞近距吞噬；小行星带障碍穿行；引力/推斥/障碍混合 | 综合避让 + 借力；高压组合考验 |
| 13 | 终局星系 | 限时 + 动目标 + 多收集星混合布局；三星挑战 + 冲最高分 | 收束全部机制；提供长线重玩与分数挑战目标 |

难度曲线原则：前 3 关教学宽容（无限次数、预测轨迹常驻）；4–7 关建立借力链路；8 关起叠加资源约束（次数/时间）；10 关起叠加运动与混合力场；每 3–4 关一个小boss 式综合关，保证"每局有新东西、每关有微突破"。

### 4. 交互与手感关键参数（供后续设计调校方向）

- 力度映射：拉伸距离 → 初速度二次曲线（前端线性、远端递增），力度条颜色由绿转红；
- 引力模型：`F = G·m / (r² + ε²)`（软化半径 ε 防奇点）；捕获半径独立于天体实体半径；
- combo 窗口：两次借力间隔 ≤ 1.5 秒计入连击；倍率 1× → 2× → 3× → 4×，中断后归零重计；
- 失败宽容：飞出边界后短暂回放轨迹并提供"撤回上一发"（每关 1 次，可付费解锁更多），降低挫败感；
- 画面：Canvas 程序化矢量绘制——深蓝紫渐变星云背景、程序化行星环带/纹理、行星力场淡色圆环、飞行器发光核心 + 粒子尾迹、命中光环；**无任何外部图片素材**；
- 音效：全部 Web Audio API 振荡器 + 噪声缓冲实时合成——发射上扫、收星短促叮声、命中琶音、combo 音阶逐级上行、失败低频下行、过关号角；**无任何音频文件**；可一键静音。

## 目标人群

- **画像**：18–40 岁轻度休闲玩家为主，兼顾喜欢物理沙盒、combo 挑战、三星收集的中度玩家；地铁通勤、排队、午休、睡前场景；单手竖屏手机玩家与桌面鼠标玩家兼顾；不追求剧情叙事，要"几秒钟上手、几分钟上头"。
- **规模估计**：网页小游戏 / hyper-casual 玩家为亿级规模长尾群体；独立开发者可通过小游戏聚合站、社区分享、PWA 收藏与后续打包移动 App 触达；本产品先以纯前端网页形态切入，不需要先投入买量。
- **使用频次**：核心玩家每日通勤 1–3 局（每局 1–3 分钟）；关卡制驱动回访：未通关关卡、刷三星、每日挑战三个回访钩子；长线玩家在 13 关通关后继续冲最高分与分享轨迹图。
- **付费意愿**：本体免费、先玩后买；参考被核实作品已验证的"一次性去广告"付费点（USD 3.99），本作品付费理由明确：
  - 玩家认可物理手感与美术风格后，愿意为审美换装与额外关卡内容小额付费；
  - 付费点均为装饰/内容解锁，不做付费碾压（不售弹药、不售无敌、不售关卡强制跳过），保护口碑与平衡性。

## 建议形态

**纯前端单文件 Canvas 网页小游戏**：一个自包含 HTML 文件，原生 JavaScript + Canvas 2D + Web Audio API，**零运行时依赖、零外部素材**（图片、字体、音频文件全部为零，视觉与声音全部代码实时生成）；静态托管即可运行，可注册为 PWA（manifest + Service Worker 离线缓存），手机竖屏触控拖拽为主，桌面鼠标拖拽 + 键盘辅助。

**为什么该形态贴合目标场景**：

- **即点即开**：无需下载安装、无开场加载条、无注册登录，点开即玩，契合 30 秒空档；
- **离线可玩**：单文件 + PWA 缓存，地铁弱网/无网环境照样开一局；
- **碎片时间闭环**：关卡制 + 本地存档，中途退出不丢进度，随时暂停、随时回来；
- **零素材零授权风险**：程序化绘制与合成音画，不存在第三方图片/音乐授权纠纷，适合独立开发者零资金上线；
- **形态可扩展**：后续可把同一套物理核心打包为移动 App、嵌入小游戏平台、或作为网页工具集内的娱乐模块，核心代码一次写成多处复用。

## 落地价值

- **解决什么问题**：填补"即开、离线、物理手感调校有趣、链路完整"的极简休闲游戏空位；给碎片时间一个低成本解压出口，给核心玩家一个可刷分、可收集、可分享的轻量目标。
- **情绪价值（主打）**：解压放松、发射与命中的即时反馈快感、combo 上行的节奏爽感、三星通关的成就反馈、生成轨迹图的分享欲；不主张节省用户时间或金钱，但一局时长可控、随时退出，客观上帮用户管理碎片化注意力。
- **市场空间**：hyper-casual 与物理益智长尾需求长期存在；同类单机休闲游戏在网页与移动商店持续有自然流量；极简单文件形态使独立开发者可以极低边际成本上线与迭代。
- **潜在盈利点**（本体免费 + 小额内购 / 广告混合，详见下节）：去广告一次性买断、主题皮肤包、高级挑战关卡包、常驻预测轨迹线解锁、轨迹分享高级模板。

## 多场景链路与红海规避判断

- **是否同质化小工具**：**否**。不是单一原子动作（如单一换算、单一打靶）的用完即走小工具，而是包含"瞄准—发射—借力—收星—combo—结算—三星—解锁—回访"的完整闭环。
- **多场景链路**：
  - **局内链路**：触发进入 → 手势教学 → 拖拽瞄准 → 松手发射 → 多星借力 / 惯性飞行 → 命中或失败 → combo 评分与星级结算 → 重开或下一关；
  - **跨局长线链路**：通关推进 → 回刷三星 → 收集星星解锁皮肤 → 每日挑战新关卡 → 轨迹图分享炫耀 → 回访冲高分；
  - 一条需求串联"碎片放松、技能成长、收集养成、社交分享"多个场景，具备持续使用频次与明确付费空间。
- **持续使用频次与付费空间**：
  - 频次：每日 1–3 局通勤局 + 通关后不定期刷分；关卡与每日挑战拉动周活；
  - 付费场景与理由：
    1. **去广告一次性买断（¥12–18 量级，参考 USD 3.99 档位）**：被广告打断手感的玩家一次性付费永久免广告，理由是"支持开发者 + 手感连续"；
    2. **主题皮肤包（¥6–12 / 套）**：星云配色、复古像素、霓虹赛博、深空极光等可选主题，改变背景、行星、尾迹、配色；理由是审美换装、个性化分享；
    3. **高级关卡包（¥12–18 / 8–10 关）**：通关主线后购买挑战星系，含黑洞迷宫、双动目标等进阶布局；理由是内容延展与付费支持；
    4. **常驻预测轨迹线（一次性小额）**：免费仅前若干尝试显示，常驻显示面向追求精准度的玩家；
    5. **高级轨迹分享模板**：免费一张基础轨迹卡，付费解锁边框/印章/配色模板，服务分享欲。
  - 广告位：仅在关卡结算页放置不遮挡操作的横幅广告，可被去广告买断移除；不插屏打断对局。
- **红海规避**：
  - 大厂弹弓物理益智（愤怒的小鸟系等）素材重、叙事重、商业模式重，与"极简单文件、离线即开"定位不同赛道；
  - 网页端同类要么是直线打靶原子工具（无连续引力链路），要么直接克隆受版权保护作品；本作差异化在于：**接近真实的反平方引力 + 多星连续接力 combo 节奏 + 13 关教学演进 + 程序化原创音画 + 本地离线零后端**；
  - 竞争门槛：物理手感调校（引力常数、软化半径、捕获半径、combo 窗口的参数平衡）需要反复试玩打磨，形成手感壁垒；玩法思想公开，但手感与关卡布局是原创积累。

## 强规则核对

| 强规则 | 是否满足 | 依据 |
| --- | --- | --- |
| 给用户带来真实价值（节省时间 / 节省资金 / 精神情感价值，至少其一） | **是** | 主打精神情感价值：碎片时间解压、即时命中反馈、combo 节奏爽感、三星成就与分享乐趣；一局时长可控、随时退出，附带注意力管理价值；不主张为用户省钱省时。 |
| 用户有购买意愿（必要条件） | **是** | 目标人群为轻度休闲 + 核心刷分玩家；免费本体先建立手感认同，再以去广告买断、皮肤包、高级关卡包、常驻轨迹线、分享模板小额付费；被参照作品已验证"免费 + 一次性去广告"（USD 3.99）付费模式成立；付费点为装饰与内容解锁，非付费碾压，付费理由可被玩家理解与接受。 |
| 形态贴合目标人群使用场景 | **是** | 单文件零依赖网页/PWA：即点即开、离线可玩、竖屏单手拖拽、局时 1–3 分钟、本地存档随时续玩，完全贴合通勤/排队/午休等碎片场景；桌面端鼠标同样可玩。 |

> 判定：三条强规则全部满足，本建议通过。

## 原创性与防 IP 边界（强制声明）

### 1. 只借鉴机制思想，不复制表达

玩法机制、物理定律、游戏循环思想本身不受著作权保护；受保护的是**具体表达**（名称、画面形象、音乐音效、关卡布局、角色、文案文字、成就等级名称等）。本作只借鉴通用物理与玩法思想：引力井、轨道环绕、捕获半径、切向脱轨、连续借力、combo 节奏、预测辅助线、难度爬升、程序化音画、单文件离线形态；**以下内容一律不复制、不模仿**：

| 类别 | 《Starfling》相关元素 | 本作处理方式 |
| --- | --- | --- |
| 名称 / 商标 | Starfling / Star Fling 及其近似拼写、Logo 字形 | 全程使用中文名《挽星弓》及副标题；不使用任何 `star`+`fling/sling` 组合英文名称；UI 文案全部中文原创 |
| 美术形象 | 其黑白极简抽象球星、配色方案、轨迹线条样式、角色（球/飞船）造型 | 全部 Canvas 程序化原创绘制：深蓝紫渐变星云、描边带环行星、粒子尾迹、独立配色与视觉符号；不临摹其任何画面截图 |
| 音效 | 其合成音色参数、音符序列、触觉反馈节奏 | 全部 Web Audio 实时合成，自定振荡器频率、包络、噪声参数与音阶序列；不采样、不转写其音效文件 |
| 关卡 / 布局 | 其关卡天体排布、道具位置、模式配置 | 13 关布局为本作原创设计；不参照其具体关卡坐标与配置 |
| 角色 / 道具 | 球、飞船造型；Magnet / Rocket / Heart 道具功能组合 | 本作飞行器为原创发光核心 + 粒子尾迹造型；不照搬其三道具体系；后续道具若新增，功能与图标另行原创设计 |

| 数据结构 / 代码 | 其源码实现 | 不复制、不反编译；物理公式采用公开万有引力常识自行实现 |

### 2. 刻意做出的差异化（既提升原创度，又降低混淆可能）

| 维度 | 《Starfling》原版（核实事实） | 本作《挽星弓》 |
| --- | --- | --- |
| 交互模型 | 飞行器自动环绕，单点按按时机释放（one-tap timing） | 按住拖拽、拉伸力度矢量 + 角度双自由度，松手发射（pullback slingshot） |
| 游戏模式 | 无尽街机，漏一颗即本局结束，冲高分 | 关卡制 13 关 + 三星评级 + 选关重玩，另可附加每日挑战 |
| 物理模型 | 街机抽象引力，仅表现为飞行途中向下偏折 | 反平方引力 + 软化半径 + 捕获半径 + 真实轨道环绕，接近轨道力学模拟 |
| 目标结构 | 连续捕获星链、跳星双倍分 | 命中星门/靶心过关 + 沿途收集星 + combo 倍率 + 限时/限次数/动目标混合挑战 |
| 内容广度 | 单一星型 + 两类模式 + 三道具 | 引力星、推斥星、黑洞、小行星带、动目标、周期开关窗口等混合布局 |
| 分发形态 | 单文件 HTML 起家，后上架移动 App | 纯静态网页/PWA 先行，零后端、本地 localStorage 存档，离线运行 |

### 3. 合规与素材干净性

- 视觉 100% Canvas 程序化生成；音频 100% Web Audio 振荡器/噪声合成；无第三方图片、字体、音频、模型文件，**不存在素材授权纠纷**；
- 无自研后端、不上传用户个人数据；成绩、进度、皮肤仅存 localStorage；轨迹分享图在本地 Canvas 导出，不涉及云端存储；
- 后续若引入第三方 AI 辅助生成文案/贴图，须确认输出可商用、留存生成记录；上线前做名称商标检索与美术相似度自查，避免与在先作品名称、画面构成近似；
- 本建议文档仅用于内部流水线评估，不包含任何被参照作品的素材拷贝。
