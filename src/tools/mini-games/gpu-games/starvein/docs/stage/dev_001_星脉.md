# 开发拆解：星脉（starvein）

## 目录
```
src/tools/mini-games/gpu-games/starvein/

  starvein.vue          # 最薄 wrapper
  docs/                 # stage / guide / postmortem / shots
```

## 实现清单
1. **纯函数层**
   - `mulberry32(seed)` PRNG；`generateStarMap(seed, stage)`：核心(500,1380)→出口(500,120)，先贪心通路再邻近补边；内部 `bfsPath` 自检，不可达 seed+101 重生成。
   - `nearestBeatOffsetMs(nowSec,bpm)`、`judge`：窗口内 PERFECT / 否则 GOOD。
   - `addNodeScore`：PERFECT 累加 combo，收益 (100+50)×(1+0.1×combo)。
   - `tideFront(nowSec,spec,boostUntil)`：节点/秒 ×（抬手 1.5s 内 1.3）。
   - `gradeOf(litRatio,perfectRate)`：S ≥0.8/≥0.6；A ≥0.6/≥0.4；B ≥0.35；C。
   - `serializeSave/validateSave`：version=1、tool=starvein、chain=starvein:run:v1；字段不全/类型错/链不符返回 null。
2. **mount 层**
   - DPR + ResizeObserver；世界 1000×1500 等比居中。
   - Pointer：down 起笔（最近已点亮节点），move 折线推点并对未点亮节点做 `distToSegment ≤ 46` 点亮判定；到出口半径内 → `finishRun`（score×1.5、评级、explode、onGameover、清快照）。
   - 潮汐：BFS 深度 ≤ 前沿 → 吞未点亮节点，能量−1；能量 0 → finishRun。
   - 渲染：深空渐变、星尘、边、节点（暗/亮/吞/出口环/核心）、脉冲环、发光光脉、粒子、HUD（分数/能量格/combo）、结算面板。
   - 自动快照：visibilitychange hidden、pagehide、15s 定时器（play 且未结算时）；`resumeAuto/discardAuto/autoSaveNow/forceSave/clearAutoSave/reset`。
3. **wrapper**：转发 props/emit，挂载 `window.__starvein` 调试句柄。
4. **合集登记**：`index.vue` NEON 组加一条 `{id:'starvein', name:'星脉', icon:'🕸️', desc, pro:false, difficulties:['classic'], kind:'gpu', loader}`。
