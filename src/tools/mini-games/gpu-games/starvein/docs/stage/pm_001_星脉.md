# PM 报告：星脉（starvein）

- 序号：001
- 结论：**可集成（新增 mini-games 子游戏，NEON 组第 7 款）**

## 与现有 7 个子游戏逐一去重

| 现有子游戏 | 核心交互 | 与星脉的本质区别 |
| --- | --- | --- |
| 2048 | 滑动合并数字 | 无路线规划、无节奏判定、无时间压力 |
| 记忆翻牌 | 翻牌配对记忆 | 静态棋盘记忆，与画线/节拍无关 |
| 数字华容道 | 滑块复原 | 步数解谜，无潮汐赛跑 |
| 莫比环跑酷 | 自动前进 + 一指翻转 | 被动反射；星脉是主动画路径 + 可收线，无自动前进 |
| 炫光连消 | 交换三消 | 无交换消除；星脉是实时节奏合奏而非棋盘连锁 |
| 霓虹脉冲 | 三轨下落节奏 | 固定谱面点键；星脉是自由路线 + 脉冲窗口判定 |
| 星轨穿梭 | 环绕躲避生存 | 被动躲避；星脉是点亮路线规划 + 潮汐倒计时 |
| 挽星弓 | 拖拽蓄力弹射命中 | 弹道弹射；星脉是一笔画路径 × BPM 卡点，无物理弹射 |
| 合成宇宙 | 投放重力合并 | 重力合并；星脉不产生合并物，是路线×时机双决策 |

三类常见玩法交叉区分：合成大西瓜（重力合并，放下即结束）/跑酷（自动前进，玩家只做瞬时反射）/消消乐（交换消除，静态棋盘）——星脉的双决策是"沿哪条脉络走"×"何时卡点穿过脉冲"，且黑暗潮汐主动蔓延、玩家可主动收线落袋，与三者均不重叠。

## 集成口径

- 新增子游戏**不增加顶层工具数**，`npm run verify:tools` 保持 **35**（与挽星弓、合成宇宙同一口径：合集自动发现只枚举 `src/tools/` 顶层 manifest，子游戏挂在 `mini-games/gpu-games/` 内）。
- 纯前端 Canvas2D + Web Audio，零素材、零新依赖，符合 EdgeOne Pages 静态托管限制。
- 本地存档独立键 `fangzi:starvein:auto-save:v1`，不串任何既有游戏键；最高分沿用合集 `fz-mini-games-v1`（key `starvein:classic`）。
- 变现：本体免费，霓虹主题/去广告一次性买断，复用合集既有 `useToolBilling` 钩子，beta 不硬锁。
