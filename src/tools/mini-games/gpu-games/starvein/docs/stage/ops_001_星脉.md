# 部署运维：星脉（starvein）

## 部署
- PWA 静态托管：腾讯云 EdgeOne Pages，经 GitCode 仓库 `git push origin main` 触发（既有流水线，无新增配置）。
- chunk 走既有 Vite 分包与 SW 预缓存 glob，**不改动 sw.js / manifest.webmanifest / public/icons**。

## 兼容性
- AudioContext 必须在手势（pointerdown/click）内 `ensure()` 解锁，满足浏览器自动播放策略；静音走宿主设置 `setMuted`。
- localStorage 自动快照键 `fangzi:starvein:auto-save:v1`；读取前 `validateSave`，损坏/旧版本安全回退到 intro，不崩。
- 最高分 key `starvein:classic` 写入合集 IndexedDB `fz-mini-games-v1`，与其它游戏隔离。

## 监控与故障
- 无后端、无远程日志；pageerror/console.error 在 E2E 已拦截。
- 若低端机掉帧：合集特效档位 `particle=low` 已支持；本游戏粒子量小（每次 PERFECT 18 粒）。
- 回滚：纯增量子游戏，回滚到上一 commit 即恢复，不影响其它工具与既有存储。

## 限额复核
- 单文件 < 25MiB、总量 < 5GiB、文件数 < 20000（本游戏 chunk 约 80KB 级，不引入 wasm/字体/图片/音频）。
