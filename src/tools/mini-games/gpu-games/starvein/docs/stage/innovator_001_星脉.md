# 功能建议：星脉（StarVein）—— 单指绘制光脉、与黑暗潮汐赛跑的原创 PWA 街机游戏

- 序号：001
- 建议形态：移动端 PWA 网页游戏（纯前端 Canvas2D + Web Audio API，零图片/音频/字体/wasm 外部素材）
- 玩法定名：中文名 **《星脉》**；英文 id **`starvein`**（包名/路由 id 建议 `starvein`；上线前需做商标重名核查，备选名：`星流 / starflow`、`织光 / weave-light`）
- 一句话玩法：**手指按住拖动，在黑暗潮汐吞掉星辰之前，画出一条流光脉络穿亮整片星图；卡点经过脉冲中的星星，会炸开粒子并奏响一个音。**

## 使用场景

- **谁**：18–35 岁移动端休闲玩家，含音游/独立游戏爱好者、通勤族、学生；不要求是"硬核玩家"。
- **何时**：地铁通勤（10–20 分钟、可玩 5–8 局）、排队等位、午休、睡前解压；单手竖持手机即可。
- **遇到什么问题**：
  - 商店首屏全是合成大西瓜换皮、跑酷换皮、消消乐换皮，视觉与玩法高度同质化，3 局即腻；
  - 想玩点"一眼好看、有艺术感"的东西，但原生 APP 要下载、要权限、要等开屏广告；
  - 音游门槛高（要练、要看谱面），这类用户想要"音乐感"但不要"练曲子"的压力。
- **为什么现有方案不够**：merge/runner/match-3 三类的核心交互已被玩烂；纯节奏游戏（落键式）与纯一笔画解谜（固定关卡、解完即走）各自缺另一半——前者没有"路线规划"，后者没有"与时间赛跑的张力"和"爆发爽感"。

## 功能描述（核心玩法与交互，可被后续评估）

### 一句话与定位
《星脉》是一款**竖屏、单指、单局 1–3 分钟**的原创街机游戏：玩家用一根手指在程序化生的"星辰网络"上拖出一条光脉，赶在从核心蔓延的"黑暗潮汐"之前点亮星星，并在星星脉冲的瞬间穿过它来拿 PERFECT。

### 世界与画面（程序化生成，零素材）
- 深空底色 + 3 层视差星尘（Canvas2D `globalCompositeOperation='lighter'` 加法混合）；
- 每局程序生成一张"星图"：N 个发光节点（星星）按邻近连接成稀疏网络（类似地铁线路图/神经网络），节点间有细暗线；
- 一个**核心节点**（局起点），一个**出口门节点**（收线结算点）；
- 所有霓虹辉光、粒子、脉冲环、流光拖尾均由 Canvas2D 实时绘制（径向渐变 + shadowBlur / 粒子系统），无任何图片资源。

### 输入方式（单手、单指）
- 全程只有一种输入：**按住并拖动**（`pointerdown/move/up`）。
- 手指落下后，一道光脉从"核心节点"自动连到手指位置并随手指流动延伸；光脉流经的节点依次被"点亮"。
- 不支持双指、不支持按钮操作；UI 按钮大且居下，适配单手持机拇指热区。

### 核心规则
1. **点亮**：光脉（其中心线一定宽度内）扫过一个暗节点 → 该节点被点亮，计入得分，节点永久点亮（不会再被潮汐吞掉）。
2. **PERFECT 判定（节奏层）**：每个节点按局内节拍（程序化 BPM，默认 100，随难度升至 128）周期性脉冲放大。光脉在**脉冲窗口内**（初期 ±180ms，随难度收窄至 ±120ms）扫过该节点 → PERFECT：节点炸开霓虹粒子环、播放一个五声音阶拨弦音（Web Audio OscillatorNode + 包络）、combo +1；窗口外扫过 → GOOD：节点仍点亮、不播音、combo 不增长但**不中断**（三区判定：perfect/good/无 fail 判定，降低挫败）。
3. **黑暗潮汐（时间压力层）**：黑暗从核心节点沿网络向**未点亮节点**蔓延；每个被黑暗吞掉的节点扣 1 格"能量"（开局 5 格）。已点亮节点免疫。
4. **combo 与得分**：combo = 连续 PERFECT 数；得分 = 点亮节点数 ×（1 + 0.1×combo）× PERFECT 权重；连击越高，环境音层数越多（drone 渐强），画面色相缓慢旋转。
5. **收线结算（出口门）**：玩家可随时把光脉引到"出口门"完成本局：得分 ×1.5 结算奖励，整图点亮的光浪从出口扩散（视觉高潮）。
6. **失败条件**：能量扣到 0 → 黑暗吞没核心，本局结束；得分为已点亮节点累计分。失败不是"卡死"，是"没来得及画完"。
7. **抬起手指**：光脉停止延伸，潮汐速度短暂 +30%（惩罚犹豫）；可再次落下从**最近已点亮节点**继续画线——允许多段画线，但已点亮节点不能重复穿线（"闭合"），形成路线规划深度。

### 单局完整链路
**进入**（冷启动 → 标题屏：流光粒子背景 + "开始"大按钮；首次点击才 `AudioContext.resume()`，满足浏览器自动播放策略）
→ **无感教学**（第 1 局前 10 秒：幽灵手 ghost animation 演示从核心拖出光脉、连亮 3 个节点；第 1 个脉冲节点弹出一行字"在它跳动的瞬间穿过——更亮"；第 4 节点起玩家接管；无独立教程关）
→ **游玩**（拖动画脉 → 点亮/PERFECT 爆发 → combo 与音乐生长 → 潮汐逼近 → 抉择：继续贪路线还是去出口收线）
→ **结算**（半透明霓虹面板：点亮数 / PERFECT 率 / 最高 combo / 评级 S/A/B/C；S 级附加粒子庆祝）
→ **重来**（一键"再来一局"，1 秒内开新程序星图；本地记录最高分与最长 combo，存 LocalStorage）。

### 难度递增曲线
| 局数段 | 节点数 | BPM | PERFECT 窗口 | 潮汐速度 | 新机制 |
|---|---|---|---|---|---|
| 1–2 | ~12，树状稀疏 | 100 | ±180ms | 慢 | 仅点亮/潮汐 |
| 3–5 | ~20，出现分支环 | 110 | ±150ms | 随 combo 加速 | 双脉冲节点（须在脉冲瞬间穿过才亮，否则保持暗） |
| 6+ | ~28，网络更密 | 120–128 | ±120ms | 更快 | 桥接节点密度上升、出口位置更偏远（冒险收线 vs 保守收线的抉择） |

### "永远可进行到底、不存在死局"的设计保证
1. 星图生成时**强制保证**核心→出口存在一条最短路径，且按基础潮汐速度，一名普通玩家沿该路径走必然来得及抵达——路线下限永远存在；
2. 能量 5 格宽容设计，即使前期路线失误吞掉 2–3 个节点也不致立刻失败；
3. 它是**得分攻击（score attack）+ 路线艺术**，不是"唯一解谜题"：任何时刻玩家都能选择"去出口收线"安全落袋，不存在"解错一步整局报废"；
4. 双脉冲节点只是"拿不到 PERFECT"，不会变成死路——普通经过仍点亮，只是无音符无 combo。

### 技术克制说明（供后续架构/开发评估）
- 纯 **Canvas2D 2D 上下文**（不引入 WebGL/Three.js/Phaser 等重型引擎）+ **Web Audio API**（振荡器合成环境音与五声音阶拨弦，无音频文件）；
- 无图片、无字体文件、无 wasm；包体即一个 HTML/JS 模块，适合静态托管；
- PWA 可识别性：标准 manifest + Service Worker 缓存静态资源，离线可玩；
- 分数/设置存 LocalStorage，零后端、零账号、零远程依赖。

- **画像**：18–35 岁、手机重度碎片时间用户；玩过《纪念碑谷》《花语月》《节奏医生》一类"有美术感、有手感"的游戏；学生与一二线城市通勤白领为主。

## 建议形态

**移动端 PWA 网页游戏**，理由：
1. **零下载即点即玩**，贴合碎片场景——用户在地铁上点开链接/主屏图标 1 秒内进游戏，不像原生 APP 要应用商店下载、要权限；
2. **可添加到主屏、可离线**，体验等同 APP，但无商店审核与抽成；
3. **纯 Canvas2D + Web Audio 零素材**，包体极小，天然适合静态托管（EdgeOne Pages），与 fangzi 现有部署形态完全一致；
4. 竖屏单指交互天然是移动端形态，不做桌面端。

## 落地价值

- **解决什么**：给审美疲劳的休闲玩家一个"一眼霓虹、一局 1–3 分钟、想再来一局破纪录"的新鲜出口；给 PWA 提供一个有传播力的"名片级"功能（视听冲击力强，适合截图/短视频自传播）。
- **为什么有意思**：①路线规划（一笔画）× 时机判定（节奏）× 时间压力（潮汐）三层机制叠加，但输入只有"拖"；②玩家的 PERFECT 实时合成音乐——"玩得越好、音乐越丰满"，合奏感是核心情绪价值；③纯程序化画面，每局星图不同，长尾耐玩。
- **市场空间**：休闲品类 220 亿美元大盘、超休闲增速 >100%（Sensor Tower 数据）；交叉"一笔画/节奏/光影"的头部原创稀缺。
- **盈利点**：免费游玩 + 一次性付费解锁霓虹主题/去广告（非订阅、非数值）；后续可加"每日种子星图"（固定 seed，本地排行榜 URL 分享，无需后端）作为社交传播钩子。

## 多场景链路与红海规避判断

- **是否同质化小工具**：否。不是单一原子动作（非换算/编解码），而是完整游戏循环。
- **多场景链路**：触发（碎片时间/解压情绪）→ 处理（单局 1–3 分钟游玩：画线→卡点→抉择收线）→ 产出（得分/评级/最高分纪录）→ 后续动作（破纪录欲驱动下一局、主题收藏、种子图分享给好友比拼）。链路贯穿"开玩→上头→炫耀→回来"。
- **持续使用频次与付费空间**：目标日均 2–5 局、周活留存靠"每日种子图 + 主题收藏"；付费空间在低价皮肤/去广告（一次性），参考超休闲"广告 + 内购皮肤"混合模式。
- **红海规避**：merge/runner/match-3 是红海；本作把"一笔画 + 节奏判定 + 潮汐赛跑"三者交叉，核心交互与反馈循环均与三类不同（见下表），大公司看不上这种小体量原创机制（利基），独立开发者可凭差异化切入。

### 与三类被排除玩法的本质区分（核心交互 × 反馈循环）

| 维度 | 合成大西瓜（merge） | 跑酷（runner） | 消消乐（match-3） | **星脉（本方案）** |
|---|---|---|---|---|
| 核心交互 | 拖拽一颗球落下，靠重力碰撞合并 | 角色自动前进，玩家只做跳跃/转向反应 | 交换相邻棋子，凑 3 个同色消除 | **单指连续拖动画线，光脉沿轨迹扫过网络节点** |
| 玩家决策 | "放下哪颗、放哪个位置"的布局 | "何时跳"的瞬时反射 | "换哪两个、凑哪组"的消除规划 | **"沿哪条脉络走"的路线规划 × "何时卡点穿过脉冲"的时机判断，双决策** |
| 反馈循环 | 合并→变大→合成更稀有→堆满即死 | 躲障→刷新距离纪录→撞死后再来 | 消除→连锁→掉落新棋子→冲关卡目标 | **点亮→PERFECT 粒子+音符→combo 与音乐渐强→潮汐逼近逼抉择→收线结算评级** |
| 时间结构 | 随堆随结束，无赛跑对手 | 角色自动走，玩家被动躲 | 关卡固定步数，静态棋盘 | **黑暗潮汐主动蔓延，玩家与时间赛跑、可主动收线落袋** |
| 音乐关系 | 无 | 弱 | 无 | **PERFECT 实时演奏五声音阶，玩得越好音乐越丰满（合奏感）** |

## 强规则核对

| 强规则 | 是否满足 | 依据 |
| --- | --- | --- |
| 给用户带来真实价值（节省时间/资金/情感价值，至少其一） | 是 | 情感价值为主：1–3 分钟碎片解压、视听合奏的沉浸爽感、破纪录与收藏的持续情绪反馈；不占用整块时间。 |
| 用户有购买意愿（必要条件） | 是 | 目标用户为有审美付费习惯的休闲/独立游戏玩家；付费场景：一次性低价解锁霓虹主题皮肤、去广告；付费理由：收藏欲与去打扰，且不破坏公平（无数值付费）。 |
| 形态贴合目标人群使用场景 | 是 | PWA 即点即玩、可离线可加主屏、竖屏单指，完美匹配通勤/排队/睡前单手碎片场景；零素材包体小，秒开。 |

> 判定：三条强规则全部满足，本建议产出。

## 难度与可玩性补充

- **首局秒懂教学设计**：规则只有一句"按住拖动，画亮星星"；第 1 局幽灵手带玩前 3 节点；节奏概念在第 1 个脉冲节点用一行字 + 一次 PERFECT 爆发让玩家"身体学会"，不讲理论。
- **节奏感**：BPM 程序化恒定、节点脉冲与节拍对齐，玩家随画线自然踩点；Web Audio 时钟与渲染时钟同源，避免音画错位。
- **正反馈**：每 PERFECT = 粒子环 + 音符 + combo 数字跳涨；评级结算 + 本地最高分持续陈列；S 局额外粒子庆祝。
- **"再来一局"钩子**：每日种子星图（同 seed 全网同一图，可分享链接比拼本地纪录）、主题解锁进度、最长 combo 挑战。
- **移动端适配要点**：`touch-action:none` + viewport 禁止缩放；pointer events 统一触屏/鼠标；canvas 按 devicePixelRatio 缩放；按钮居下拇指热区；AudioContext 须用户手势后启动；竖屏竖屏优先（建议锁竖屏提示）。
