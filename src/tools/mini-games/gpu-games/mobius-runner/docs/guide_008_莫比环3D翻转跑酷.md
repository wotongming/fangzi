## 功能简介

「莫比环跑酷」是一款一指就能玩的 **3D 莫比乌斯光带跑酷**。你操控一个卡通小人沿无限半扭转光带奔跑：光带每转过一处半扭转，正反面会真正对调。点一下屏幕翻到另一面，从闸门挡住的缺口面穿过去；贴边擦过、临门翻面对齐打出连击倍率，跑得越远分数越高。

- 纯前端、**零后端、无账号、无联网请求**；
- 首次打开后**可离线游玩**（PWA，可安装到桌面/主屏）；
- 分数与设置只保存在**本机浏览器**（IndexedDB `fz-mobius-runner-v1`）。

## 运行环境要求

- 支持 **WebGL** 的现代浏览器：Chrome / Edge / Safari / Firefox 近年版本。
- 桌面、平板、手机均可；手机建议「添加到主屏」以全屏沉浸方式启动。
- 不支持 WebGL / 关闭硬件加速时，显示友好兜底提示而非白屏。
- 渲染依赖 three.js（MIT，可商用），由工具页**按需懒加载**，不增加首屏负担。

## 安装与启动

- 在线打开 `https://www.fangzi.asia` → 全部工具 → **小游戏合集** → 炫光 NEON → **莫比环跑酷**，点「开始奔跑」即可，无需安装。

## 使用说明

### 1）主菜单与选择角色

打开后看到标题、玩法一句话说明、「当前角色 · 更换」与「开始奔跑」，下方展示本机最高分与已跑局数。点「更换」打开角色网格：**电光小子、棉花兔、薄荷猫**免费可选；**火焰仔、紫影侠**为专业版（带锁），免费态点锁会弹出小游戏专业版买断页。所选角色记在本机，下次自动沿用。

![主菜单（手机）](shots/shot-08-mobile-menu.png)

![主菜单（平板）](shots/shot-06-tablet-menu.png)

### 2）首次教学

第一次进入会先弹出「30 秒上手」：点按翻转、闸门只挡一面、半扭转时两面对调、贴边擦过有倍率。点「开跑」正式开始。

### 3）对局操作（核心）

- 手机：**点按画面任意位置**翻转到另一面；
- 电脑：**点按画面**或按 **空格 / ↑** 翻转，**Esc** 暂停；
- 前方闸门红色实墙挡住一面，在亮着的绿色缺口面穿过即可；
- 撞到实墙即结束，可立即重开。

![对局画面（PC）](shots/shot-01-pc-playing.png)

全屏只保留极简分数与右上角暂停键，无任何与游戏无关的信息；小人翻转时会做一个前空翻。

![对局画面（手机）](shots/shot-09-mobile-playing.png)

### 4）暂停与设置

点右上角 ❚❚ 打开合集统一的暂停浮层：可暂停/继续、重新开始、切换音效与特效档位（自动/高/低，低档更省电）、退出游戏回合集。

![暂停面板（PC）](shots/shot-02-pc-paused.png)

### 5）结算与重开

撞墙后弹出结算：本局分数、历史最高与已跑局数；可「立刻重开」。

## 常见问题（FAQ）

- **黑屏或提示不支持 3D？** 更新浏览器、开启硬件加速，或更换支持 WebGL 的设备。
- **玩起来晕？** 暂停中打开「降低动态」，特效调到「低」。
- **高分丢失？** 分数按浏览器/设备本地保存，清理浏览器数据或换浏览器会重置。
- **要联网吗？** 游玩不需联网；首次加载页面需联网缓存资源。
- **付费后换设备还有吗？** 权益跟随方子统一计费在本地/账号体系记录；核心玩法始终免费。

## 注意事项

- 游戏为固定步长（120Hz 逻辑）+ 插值渲染，不同刷新率下速度一致；切到后台会自动暂停。
- 长时间游玩会请求屏幕常亮（WakeLock）；退出对局自动释放。
- 低端设备可在暂停里把特效设为「低」以保证流畅与省电。
