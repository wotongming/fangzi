# 功能建议：莫比环 MÖBIUS（一指翻转 3D 莫比乌斯环带跑酷）

- 序号：008
- 建议形态：网页应用（纯前端 3D H5 游戏，PWA 内工具，可全屏 / 可添加到主屏 / 离线可玩）

## 需求来源

本需求由用户直接提出：**“设计一款基于 Three.js 的 3D 游戏，要求不落俗套，简单上手，好玩爱玩吸引力强。”** 创意者在不改写该需求（技术栈=Three.js、维度=3D、目标=强吸引力）的前提下，做了需求侧趋势与空白点调研：

- 超休闲（hypercasual）成瘾循环被反复验证：**单键操作、零学习成本、即时反馈、秒级重开、3 分钟一局、不断刷新自己的小纪录**，是“再来一局”冲动的来源。
  - PlayDevZone《Why Hyper Casual Games Attract Millions》：快速小胜 + 难度平滑爬坡 + 即时反馈，形成 “just one more round”。https://www.playdevzone.com/hyper-casual-game-development/hyper-casual-games-attract/
  - EXSCAPE《Hyper-Casual Games: Trends, Psychology & Business in 2025》：极致简单，常只有一次点击/滑动，无教程、打开即玩。https://exscape.com/what-are-hyper-casual-games-trends-psychology-business-in-2025/
  - BR Softech《Key Elements Behind Hyper-Casual Game Success》：Tap-to-Jump/单指机制鼓励即时重开、适合极短重复局。https://www.brsoftech.com/blog/key-elements-of-hyper-casual-games/
  - MakeGamesWithAI《Build a Hit Hyper Casual Game》：“如果需要超过一根手指，那它可能太复杂了”。https://makegameswithai.com/blog/hyper-casual-game/
- **Three.js 是浏览器 3D 内容事实标准、且 2025 年“氛围/氛围编码 3D 小游戏”正成为热门趋势**：大量开发者用 Three.js 快速做出极具视觉冲击的可玩 3D 场景。
  - 智源社区《0 行代码打造 3D 游戏，氛围编码席卷全网》：Three.js 内置能力 + AI 让 3D 可玩内容爆发。https://hub.baai.ac.cn/view/44185
  - three.js Forum Showcase（Savanna Sam、Hiss Highness 等）：Three.js 已能支撑完整商业级 3D 玩法与卡通渲染、程序化动画。https://discourse.threejs.org/t/3d-action-browser-game-made-with-three-js-savanna-sam/81902
- **“莫比乌斯环带”几何玩法存在空白点**：以莫比乌斯拓扑为核心的游戏目前几乎都是小众独立原型，且都不是“单键 + 3D 连续扭转曲面 + 大众超休闲”定位：
  - Mobius Trip（itch.io）：把场景做成莫比乌斯拓扑的 micro-metroidvania，偏探索解谜、非单键竞速。https://cosmologicon.itch.io/mobius-trip
  - Ziggy Roll（s&box）：一键切换方向的生存跑酷，但核心是“换向”而非莫比乌斯半扭转换面。https://sbox.game/mobiusforge/ziggyroll
  - Soliton Burst（Steam）：在环面/莫比乌斯等曲面上战斗，重度、付费下载。https://store.steampowered.com/app/4730300/
- 检索关键词：`Three.js 3D 小游戏 创意 爆款 2025`、`hypercasual one-tap addictive mechanic 2025`、`Möbius strip endless runner novel indie 3D`。

**结论**：把“已被验证的单键超休闲循环”嫁接到“几乎没人做好的莫比乌斯 3D 几何”上，用 Three.js 呈现连续扭转光带，是一个既有大众上手门槛、又有明显视觉与机制新鲜感的空白切入点。

## 使用场景

- 谁：通勤/排队/午休有 1–5 分钟碎片时间、不想下载游戏 App、不想被广告和联网绑架的人；被炫酷 3D 视觉吸引、愿意反复挑战自己最高分的轻度玩家。
- 时机：地铁公交上单手竖握手机、等人、课间、工作间隙想“放空一下大脑又想有点爽感”。
- 遇到的问题：
  - 现有跑酷/闪避小游戏多为 2D 或“伪 3D”，画面廉价、玩法千篇一律（躲障碍、三车道换道），玩两天就腻。
  - 真正有意思的 3D/几何独立游戏往往操作复杂、要学习、要下载、要付费或联网，不适合碎片时间“点开就爽”。
  - 大多数同类一上来就是熟悉的配方，缺少“这游戏没见过、想截图发朋友”的第一眼记忆点。

## 功能描述

**一句话**：你是一道光，在一条无限延伸、自带周期性半扭转的**莫比乌斯光带**上自动奔跑；每道闸门只挡住环带的“一面”，**点一下屏幕，光就翻转到环带另一面**穿过缺口；环带每转过一圈，“上 / 下”两面会因半扭转而对调——几何本身在和你的空间直觉开玩笑。

核心玩法与关键交互：

1. **单输入**：点击屏幕任意位置 / 空格 / 鼠标点击 = 「翻转」到环带另一面（角色沿一道平滑弧线越过环带边缘），支持单手拇指。无虚拟摇杆、无多按键。
2. **闸门（核心决策）**：前方闸门一面是会撞死的光墙、另一面是发光缺口；玩家必须在撞上之前翻到“缺口那一面”。贴边擦过光墙（near-miss）给予额外加分、慢动作与冲击反馈。
3. **莫比乌斯半扭转（差异点）**：环带每隔一段进入“扭转区”，在一段弧线内完成 180° 半扭转，两面平滑交换；相机贴面跟随翻滚。扭转有明确预告（环带边缘刻度、颜色渐变开始旋转、音效上扬、轻微震动），穿过扭转区后“你所在的是哪一面”在数学上被对调——玩家必须用视觉而非记忆判断，形成独特的空间反应挑战。
4. **连续完美翻转 = 连击倍率**：连续在最佳时机翻转 / 连续贴边擦过，倍率递增，配合粒子爆发、鼓点与震屏，越打越爽。
5. **收集与风险**：光带两面会随机出现“光屑”，为吃到对面的光屑需要主动翻转，承担节奏风险；光屑用于局外解锁纯外观拖尾颜色（免费成长线）。
6. **死亡与秒开**：撞到光墙 → 角色霓虹碎裂、强烈音效与震动 → **一次点击 1 秒内重开**，无加载、无广告弹窗。
7. **难度曲线**：随距离提升速度与闸门密度；中段出现“扭转区紧贴闸门”的组合考；后期出现缓慢横移的闸门。每个 biome（视觉主题）随距离切换，保持新鲜感。
8. **沉浸表现**：全程纯净全屏，画面只保留游戏、极简分数与一个暂停钮；进入游戏自动屏幕常亮；程序化霓虹粒子 / 拖尾 / 景深 / 辉光 + Web Audio 合成音效与手机震动，**无任何外部图片 / 音频 / 模型素材**。
9. **纯本地、无后端、可离线**：几何与特效全部代码实时生成；最高分、设置、累计光屑仅存本机 IndexedDB；首包加载后可离线玩。
10. **设备适配**：以 Three.js WebGL 渲染；高帧率设备开辉光 / 高像素比，低端或不支持设备自动降像素比 / 关后处理 / 简化材质，极少数无 WebGL 环境给出友好提示（不白屏）。

## 目标人群

- 画像：18–40 岁、有碎片娱乐需求的学生与上班族；对“炫、酷、几何美学 / 赛博霓虹”敏感、爱分享新奇小游戏的人群；方子（fangzi）现有工具的存量用户（顺手点开）。
- 规模估计：超休闲是用户基数最大的游戏品类之一（移动浏览器内置、无需下载使其触达门槛甚至低于原生 App）；方子内置分发 + 关键词检索（3D 游戏 / 跑酷 / 反应力 / 炫酷 / 莫比乌斯）可持续获客。
- 付费意愿：本体免费即可无限玩，降低门槛；愿为“更炫的主题皮肤 / 拖尾、每局一次续命、未来新模式”支付一次小额买断（与方子其它专业版一致的低客单、买断、无广告无订阅，符合用户对付费偏贵敏感、偏好一次性低价的特征）。

## 建议形态

**纯前端 3D H5，作为方子 PWA 内一个独立网页工具（独立路由、可全屏、可离线、可“添加到首页”像原生 App 一样启动）。**

选择理由：
- 目标场景是“碎片时间、单手、点开即玩、不想装 App”，H5/PWA 的零安装、全屏沉浸、离线缓存最贴合；Three.js 天然运行于浏览器 WebGL。
- 独立工具（而非塞进现有 2D 小游戏合集）便于把 Three.js 作为独立懒加载 chunk，与现有自研 WebGL2 引擎隔离，互不影响包体与稳定性；后续可独立迭代主题与模式。
- 可复用方子已有的全屏沉浸、统一计费、本地存储、SEO/检索、PWA 外壳能力，不必自建分发与账号体系。

## 落地价值

- 解决什么：提供一个“第一眼没见过、上手只要一下、死了立刻再来、还能持续刷自己纪录”的高质量 3D 解压体验，替代廉价广告小游戏与无意识刷视频。
- 节省时间 / 情绪价值：单局 1–3 分钟，随时退出无惩罚；强反馈（连击、慢动作、震屏、鼓点）提供即时掌控感与解压情绪价值；新奇几何美学带来“想分享”的社交货币。
- 多场景链路（触发→处理→产出→后续）：**碎片时间触发 → 选“开始”即刻进入全屏 3D 心流 → 局内得分/连击/收集光屑 → 局后看最高分与距离、用累计光屑解锁外观、点一次重开或把成绩/画面分享出去 → 养成反复回访刷新纪录的习惯**。链路完整、天然高频（每日多次、单次多局），不是用完即走的原子小工具。
- 市场空间与盈利点：方子内以 freemium 引流、小额买断专业版（皮肤包 + 续命 + 专属拖尾/徽章 + 未来新模式）变现；无广告、无服务器成本，几乎零边际成本，可持续叠加主题/模式做长线留存。

## 多场景链路与红海规避判断

- 是否同质化小工具：**否**。虽含“躲障碍”的 familiar 元素，但承载形态是真正的 3D 莫比乌斯连续扭转曲面，核心挑战是“半扭转导致两面周期性对调”的空间认知，且具备外观成长、连击深度、主题迭代与可持续回访，不是单一原子动作。
- 多场景链路：见上“落地价值”，贯穿触发—游玩—结算—成长—回访/分享全链路。
- 持续使用频次与付费空间：高频（单日可多次、每次多局）；付费点为低门槛一次性买断的外观 + 便利（续命）+ 未来内容，符合超休闲“免费大盘 + 少量付费个性化/便利”的成熟模型。
- 红海规避：普通 2D 换道 / 闪避跑酷是红海，但“单键 × 真 3D 莫比乌斯几何 × 高端霓虹质感 × 零安装 PWA”的组合在大众市场基本空白（现存仅小众独立原型），差异化与记忆点明确。

## 强规则核对

| 强规则 | 是否满足 | 依据 |
| --- | --- | --- |
| 给用户带来真实价值（节省时间/资金/情感价值，至少其一） | 是 | 主要提供解压 / 掌控 / 新奇审美的**情绪价值**；单局极短、无广告、免安装，节省被广告与下载浪费的时间；PWA 免费本体也省钱。 |

| 形态贴合目标人群使用场景 | 是 | 单手、点开即玩、全屏、离线的 PWA H5 正是碎片时间 / 通勤 / 不想装 App 场景的合理承载；Three.js 是浏览器 3D 的标准选择。 |
