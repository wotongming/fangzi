## 技术选型落地

- Vue 3.5 + `<script setup lang="ts">` + Vite（rolldown）+ Pinia/vue-router（沿用）；新增 **three（MIT，编码前锁定最新稳定且无高危 advisory 的版本，核对与当前 Vite 版本兼容）**、`@types/three`。
- 不引物理引擎：碰撞=弧长+面的一维判定；不引状态/动画重型库。
- 渲染与规则分离：`game/*` 不 import three，可在 node 直接测；`three/*` 只消费 `GameState` 快照。
- 与现有代码风格一致：组合式函数、kebab 文件、语义化 class、CSS 变量（`--brand` 等）、2 空格、无裸 any（必要时窄类型）。

## 模块设计（关键接口约定）

```ts
// game/types.ts
export type Face = 0 | 1
export type RunStatus = 'ready' | 'running' | 'dead' | 'paused'
export interface Gate { u: number; wallFace: Face; kind: 'solid'|'moving'; }
export interface Shard { u: number; face: Face; taken: boolean }
export interface GameState {
  seed:number; distance:number; speed:number; face:Face;
  gates:Gate[]; shards:Shard[]; score:number; combo:number; multiplier:number;
  status:RunStatus; twistAhead:number | null; shardsRun:number; reviveUsed:boolean;
}
export interface Settings { muted:boolean; vibrate:boolean; fx:'auto'|'high'|'low'; reduceMotion:boolean }
```
- `createRun(seed): GameState`；`step(s, dt): GameState`（固定 1/120）；`flip(s): GameState`（在判定窗内结算）；`revive(s): GameState | null`（专业版、每局限一次、清掉致死闸门并给 1.2s 无敌）。
- 渲染器：`new MobiusRenderer(canvas, opts)`；`render(s, alpha)`（alpha=累加器插值）；`dispose()`。

## 关键实现方法（流程 / 伪代码）

固定步长主循环：
```
acc += clamp(realDt, 0, 0.1)
while acc >= STEP { state = step(state, STEP); acc -= STEP }
renderer.render(state, acc / STEP)
```
半扭转换面（纯逻辑，与几何一致）：
```
扭转区间 [u0,u1]：θ(u)=π * smoothstep((u-u0)/(u1-u0))
玩家穿过 u1 后：state.face = state.face ^ 1   // 莫比乌斯：两面周期性对调
设 twistAhead 供相机/音效/UI 预告
```
碰撞：
```
for g in state.gates（|g.u - playerU| <= 半厚度）:
  if state.face === g.wallFace && !invincible: status='dead'; break
  else if 贴边距<=nearWindow: nearMiss++（慢动作+倍率+粒子）
```
对象池回收：当 `gate.u < playerU - recycleBehind` 时摘除并在前方 `playerU+lookahead` 按 difficulty/rng 生成新闸门，保证同屏数量恒定。

## 开发环境与工具链

- Node（仓库现用）+ npm；`npm i three` + `npm i -D @types/three`（锁定版本写入 package-lock）。
- 调试用 dev server 热更新；只在交付前跑一次生产 `build` + `vite preview`。
- 复用 `/opt/vm/preinstall/.../playwright` 与 `/usr/local/bin/chromium`；公共 GPU context `scripts/_gpu-ctx.mjs`。
- 调试期用小 lookahead/少闸门，最终做一次长距离（≥5 分钟）性能与内存观察。

## 开发步骤与里程碑

- **M1 垂直切片（可运行 checkpoint）**：R2/R3/R4/R5 + 单测；R7/R8 基础环带相机；R10 单键翻转与碰撞；R14 基础 HUD + 死亡/秒重开；R6 最高分。交付即可玩、可构建、可 E2E 主流程。

## 代码规范与质量要求

- 遵循仓库 ESLint/TS 严格度与命名；`game/*` 零 DOM/零 three 依赖以便单测；所有 GPU 异步带超时与 try/catch 降级；能力探测只到 adapter，不提前 destroy device（沿用 gpu-detect 铁律）；释放资源防泄漏；金额/权益一律走 billing 与 `priceCents`，不在组件内硬编码价格做判定。
