# 部署运维指引：轻量网页小游戏合集（打发碎片化时间）

- 对应 architect：architect_001_网页小游戏合集.md
- 编写日期：2026-10-17

## 部署架构与环境准备

```
本地开发（Vue3+Vite）→ git push → GitCode（gitcode.com/m0_45688211/fangzi）→ EdgeOne Pages 自动构建发布（静态托管）
```

- 环境：Node >= 20.19（推荐 22 LTS）、npm、git（GitCode SSH/PAT 已配置）。
- 部署目标：EdgeOne Pages（腾讯云，静态托管，免费额度；项目已有发布链路，无需新开服务）。
- 游戏功能为纯前端静态资源，随 fangzi 单仓发布，无独立服务、无数据库、无第三方 API。

## 软硬件配置清单

| 项 | 配置 |
|---|---|
| 构建机 | 本地或 CI（Node 22 LTS，npm） |
| 托管 | EdgeOne Pages 静态托管（现网域名，免费额度） |
| 存储 | 无服务端存储；游戏进度存用户浏览器 IndexedDB |
| 资源体积 | 单款游戏 < 200KB，`dist/` 总包 < 25MiB（EdgeOne 上限，构建后有 postbuild 校验） |

## 部署步骤

1. 代码合入：`git add` / `git commit` / `git push origin main`（GitCode 仓库）。
2. EdgeOne Pages 检测推送自动构建：`npm ci && npm run build`（含 vue-tsc 类型检查 + vite build + postbuild 体积校验）。
3. 发布：构建产物 `dist/` 部署至现网域名；Workbox 自动生成新版本 SW 缓存，用户下次访问自动更新（后台静默 + 提示刷新）。
4. 验证：访问现网工具入口「小游戏合集」，搜索「小游戏/打发时间」可直达；断网（离线模式）打开可玩；最高分可恢复。

## 配置项说明

- 环境变量：无新增（游戏不依赖服务端密钥/接口）；沿用 fangzi 现有 `.env.example` 配置项。
- 计费配置：在方子计费模块中注册「小游戏会员」项（Freemium：基础免费/会员解锁完整库、去广告、皮肤），价格与权益由产品确认后配置。

## 上线/灰度方案

- 首版全量发布（功能为增量目录，风险低）。
- 如需灰度：EdgeOne Pages 支持版本切换——先在分叉分支构建预览环境验证，再合入 main 触发生产发布；异常时回滚到上一版本（见下）。

## 平台对接指南

- **EdgeOne Pages**：注册与资质：腾讯云账号 + EdgeOne 开通（现有项目已开通）；部署流程：Git 仓库关联自动构建（现有流程）；自定义域名/HTTPS：现网域名沿用；版本更新机制：推送触发构建，Workbox 缓存版本自动管理。
- 本功能不涉及 Chrome Web Store / VS Code Marketplace / JetBrains Marketplace 等插件商店（PWA 内嵌功能）。

## 运维监控指标与告警

- 核心指标：EdgeOne 控制台——访问量、请求错误率（4xx/5xx）、带宽；游戏工具 UV/回访（如接入统计）。
- 告警：构建失败（EdgeOne 构建日志）、发布后错误率突增、`dist/` 体积超限（postbuild 校验失败会阻断构建，天然告警）。
- 通知渠道：EdgeOne 构建通知 + 仓库 CI 状态。

## 日志管理

- 前端错误：沿用 fangzi 现有前端错误上报机制（如有）；游戏无服务端日志。
- 构建日志：EdgeOne Pages 构建记录 / GitCode CI 记录，保留最近 N 次。

## 备份与容灾

- 代码备份：GitCode 仓库即代码备份（多副本）；发布版本由 EdgeOne 保留历史版本，可回退。
- 用户数据：游戏进度在用户浏览器 IndexedDB，服务端无数据可丢；SW 更新不影响 IndexedDB（键名稳定即可）。

## 常见故障排查与回滚预案

| 故障 | 排查 | 处理 |
|---|---|---|
| 构建失败（类型/体积超限） | 查看构建日志；本地复跑 `npm run build` | 修复后重新推送 |
| 游戏入口搜不到 | 检查 manifest 关键词与 `verify:tools`；确认已纳入检索索引 | 补关键词重新构建 |
| 离线打不开 | 检查预缓存是否收录 games 目录资源 | 调整 globPatterns/资源体积后重发 |
| 存量工具异常 | 确认未改动核心模块；比对发布差异 | 回滚上一版本 |
| 用户进度丢失 | 检查 IndexedDB 键名是否变更 | 保持 storage 键名稳定；必要时做迁移 |

- 回滚：EdgeOne Pages 控制台回退到上一发布版本（或 Git 回滚 + 重新推送）；游戏为增量目录，回滚不影响其他 19 个工具。
