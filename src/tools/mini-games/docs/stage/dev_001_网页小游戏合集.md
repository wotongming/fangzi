## 技术选型落地

- 语言/框架：TypeScript + Vue 3（与 fangzi 完全一致）；无新增 npm 依赖。
- 渲染：原生 Canvas 2D + requestAnimationFrame；音效 Web Audio API（默认静音）。
- 存储：IndexedDB（浏览器原生）；计费：复用 fangzi 现有计费模块。
- 托管：EdgeOne Pages（现有发布链路）；许可证全部 MIT/Apache-2.0 商用友好，无新增非商用资源。

## 模块设计

- 数据流：GameShell 选择游戏 → 游戏组件启动 engine/loop → 输入 → 更新逻辑（纯函数）→ 绘制 → 得分/结束 → GameShell 写 IndexedDB 并展示最高分。
- 接口约定：游戏组件暴露 `start(difficulty)` / `pause()` / `resume()` / `reset()` / 事件 `onScore` / `onGameOver`；engine/loop 提供 `register(update, draw)`。

## 关键实现方法

```ts
// engine/loop.ts 伪代码
start(): 记录 last=performance.now(); 绑定输入
tick(now):
  dt = min((now-last)/1000, 0.05)      // 防大帧跳变
  if (!paused) { update(dt); draw(); } // 状态机驱动
  raf(tick)

// games/2048-core.ts 伪代码
move(board, dir): 按方向压缩+合并（如 2 2 → 4），返回 {board, score, moved}
  // 纯函数，单测覆盖 4 方向与 2048 合成
gameOver(board): 无可移动格子且未满 2048 空格 → true
```
