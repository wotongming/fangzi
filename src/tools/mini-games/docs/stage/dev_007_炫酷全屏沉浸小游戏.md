## 技术选型落地

- 语言/框架：TypeScript(strict) + Vue3 `<script setup>` + Vite，与仓库一致；类型用已有 devDependency `@webgpu/types`。
- 渲染：原生 WebGPU/WGSL → WebGL2/GLSL → Canvas2D 三后端，自研零运行时依赖；图形不走第三方库。
- 音频/触感/全屏：Web Audio、Vibration、Fullscreen、（可选）Screen Wake Lock，全部浏览器原生。
- 存储：复用 `reusable-module/indexeddb-kv`（`fz-mini-games-v1`）。
- GPU 探测/懒初始化：复用 `reusable-module/gpu-detect`（只到 adapter）、`reusable-module/use-lazy-init`。
- 计费：`@/composables/useToolBilling`；全屏：`@/composables/useImmersive`。
- 零资金、零新增 npm 运行时依赖、无 NC 资源、零素材文件。

## 模块设计与数据流

- `index.vue` 持有 `selected: {kind:'dom'|'gpu', id, difficulty} | null`；选中（手势）→ 动态 `import()` 对应组件（GPU 同时拉起 engine chunk）→ 渲染 `<FocusStage :title :kind @exit @score>`；退出置 null 并恢复。
- `FocusStage` 负责全屏生命周期与 HUD/浮层；游戏组件通过 props/emit（沿用 `:difficulty`、`@score`、`@gameover`）与外层通信，内部持有 engine。
- 分数写回沿用 `onScore/onGameOver → saveBest/persistState`，gameId 使用新前缀，键空间独立。
- 设置：`loadState()` 返回 `{best, settings?}`；`updateSettings(patch)` 合并落库；engine/audio/振动在初始化与变更时读取。

## 关键实现方法（流程/伪代码）

后端选择（严格遵守探测纪律）：

```ts
const cap = await detectGpu(4000)            // 只到 adapter
let renderer: Renderer
if (cap.preferred === 'webgpu') {
  try { renderer = await withTimeout(new WebGpuRenderer().init(canvas), 8000, 'gpu-device') }
  catch { renderer = new WebGl2Renderer() } // 失败降级，绝不 destroy 探测用 device
}
else if (cap.webgl2) renderer = new WebGl2Renderer()
else renderer = new Canvas2dRenderer()
await renderer.init(canvas).catch(() => new Canvas2dRenderer().init(canvas))
canvas.addEventListener('webglcontextlost', (e) => { e.preventDefault(); engine.fallbackNext() })
```

固定步长 + 后台暂停 + 自适应降档：

```ts
let last = performance.now(), acc = 0
function frame(now:number){
  if (document.hidden) return                  // visibilitychange 停 RAF
  const dt = Math.min(now-last, 50); last=now; acc+=dt
  while(acc>=STEP){ fx.step(STEP/1000); acc-=STEP }
  renderer.render(dt/1000, audio.bgBeat)
  fps.addSample(dt); if(fps.lowSustained()) quality.stepDown()  // DPR→粒子→bloom
  raf=requestAnimationFrame(frame)
}
```

FocusStage 进退（手势内）：

```ts
async function enterStage(){ await immersive.enter(); showOverlay(false); await nextTick(); initCanvas() }
onBeforeUnmount(async()=>{ engine.dispose(); audio.suspend(); await immersive.exit() })
// 轻触中央切换浮层；浮层出现 2.5s 无操作自动隐藏；游戏进行中默认仅左上分数/连击
```
