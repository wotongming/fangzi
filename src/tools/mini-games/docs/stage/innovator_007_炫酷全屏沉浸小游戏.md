# 功能建议：炫酷全屏沉浸小游戏（WebGPU 炫光游戏系列）

- 序号：007
- 建议形态：PWA / 网页应用（移动端单指触控优先，兼顾 PC 鼠标/键盘），内嵌于现有工具型 PWA 的「打开即玩」小游戏模块

## 需求来源

用户明确提出的具体需求（本次为「具体需求」分支，仅深化该需求，不额外发散）：

> 「利用最近新的技术（包括但不限于 WebGPU 等），设计一些炫酷的小游戏。一定要注重玩游戏时的沉浸感，全屏体验，与游戏无关的信息一定不要展示在屏幕，白白浪费空间。」

支撑该需求的技术与趋势依据（联网调研，2025–2026）：

- **WebGPU 已在所有主流浏览器正式可用**：Chrome / Edge / Firefox / Safari 均已支持，面向浏览器的高性能 3D 与 GPU 通用计算进入普及期。来源：web.dev《WebGPU is now supported in major browsers》，https://web.developers.google.cn/blog/webgpu-supported-major-browsers?hl=en （检索词：WebGPU major browsers 2025）
- **GPU 粒子/计算着色器在浏览器已能做到海量、高帧率、强视觉**：WebGPU compute shader 可在 1ms 内更新约 100 万粒子；社区已有粒子生命、银河模拟、水母软体、体积雪花球等成熟炫技案例。来源：Three.js Roadmap《Interactive Galaxy with WebGPU Compute Shaders》，https://threejsroadmap.com/blog/galaxy-simulation-webgpu-compute-shaders ；lisyarus《Particle Life simulation in browser using WebGPU》，https://lisyarus.github.io/blog/posts/particle-life-simulation-in-browser-using-webgpu.html ；WebGL/WebGPU Community Showcase，https://www.webgpu.com/showcase/medusae/ （检索词：WebGPU particle compute shader game 2025）
- **「霓虹 + 粒子爆炸 + 辉光 + 屏幕震动 + 音频反应」是当下最受欢迎的炫酷休闲游戏语言**：例如 GlowGrid（霓虹四消，5000+ 粒子爆炸、Bloom 辉光、屏幕震动、随节拍呼吸的赛博朋克网格背景、色盲模式）；多款霓虹节奏游戏以「点击/长按/滑动」单指操作 + Web Audio 实时合成音效为核心。来源：itch.io GlowGrid devlog，https://ethan218.itch.io/glowgrid/devlog/1490049/introducing-glowgrid-a-neon-match-4-puzzle ；Chrome Web Store《MauRhythm 3D》，https://chromewebstore.google.com/detail/maurhythm-3d-mouse-rhythm/bcajbopefpkbgaenmcjfoenceecebjdd （检索词：neon match particle bloom audio-reactive web game 2025）
- **移动端 WebGPU 已可实现高帧率炫酷画面**，现代 API 直接映射 Vulkan / Metal / D3D12，明显降低 CPU 提交开销导致的卡顿。来源：DYG《WebGPU: 60FPS on Mobile》，https://www.dyg-games.com/webgpu-mobile-4k-60fps/ （检索词：WebGPU mobile 60fps）
- **即时打开即玩的浏览器游戏是明确大盘**：CrazyGames 等平台已有 4500+ 即点即玩作品，WebGPU 被视为浏览器游戏画质跃迁的关键。来源：Oreate《How CrazyGames Became the Leading Hub for Instant Browser Play》，https://learn.oreate.ai/articles/how-crazygames-became-the-leading-hub-for-instant-browser-play （检索词：instant browser play WebGPU trend 2025）

## 使用场景

- **谁**：通勤、排队、午休有 3–10 分钟碎片时间的上班族与学生；已经在用该工具型 PWA、希望顺手获得高质量放松体验的存量用户；手机性能不错、对「画面够炫、手感够爽」敏感、但不愿为一个小游戏下载安装注册独立游戏 App 的人。
- **什么时机/情境**：
  - 地铁公交上戴耳机单手游玩，希望一点进去画面立刻铺满整块屏幕、没有任何标题栏/菜单/广告分散注意；
  - 工作间隙想快速获得强正反馈（消除爆炸、节拍命中、连击）来解压，几十秒到几分钟一局；
  - 想向朋友「秀一下」手机里这个不用装、却有近乎原生级炫酷画面与流畅度的网页小游戏。
- **现有方案为什么不够**：
  - 独立游戏 App：要下载、占存储、要登录、开屏广告/插屏广告/诱导内购多，退出成本高；
  - 网页小游戏站：广告与追踪脚本泛滥、铺满与全屏体验差、HUD 与站点导航挤占游戏画面、多数还强制联网、离线不可用；
  - 工具 PWA 内现有轻量益智小游戏（纯 DOM/CSS 的 2048、翻牌、华容道、三消）：**干净、离线、无广告，但视觉是「朴素色块」，没有 GPU 级粒子/光影/音频冲击，且游戏区上方仍常驻游戏切换标签、本局/最高分栏、说明文案等，做不到「进入后整块屏幕只有游戏」的绝对沉浸**。

## 功能描述

在现有 PWA 小游戏模块内新增一个**「炫光 / NEON」GPU 游戏系列**，并把整个小游戏模块改造为**两层结构：选游戏页（常规）→ 游戏内纯净全屏专注态**。核心要点：

1. **GPU 实时炫酷渲染（WebGPU 优先，自动降级）**
   - 优先用 WebGPU + WGSL（计算着色器驱动海量粒子、实例化渲染、多通道 Bloom 辉光），设备/浏览器不支持时**自动逐级降级 WebGL2 → Canvas2D**，并按后端与帧率动态调节粒子数量与分辨率，任何环境都能玩、不白屏。
   - 视觉语言：霓虹描边、加法混合发光、粒子爆炸与拖尾、击中涟漪、屏幕轻微震动、随连击/节拍变色与呼吸的动态背景。
2. **首批 3 款单局几分钟、单指可玩的炫光游戏**
   - **炫光连消（Glow Match）**：交换相邻霓虹块，连消/连锁触发数千粒子爆炸 + 辉光 + 屏幕震动 + 五声音阶音效，连击越高世界越「燃」。
   - **霓虹脉冲（Neon Pulse）**：节奏判定，光点沿光轨飞入判定圈，在正确时机点按/长按/滑动；背景网格 shader 随节拍呼吸，完美判定触发粒子爆发。
   - **星轨穿梭（Orbit Surge）**：拖动（或重力感应可选）引导一道光在 GPU 粒子星场中穿行、收集/躲避，强速度感与拖尾沉浸，偏「半观赏半操作」。
3. **绝对纯净的全屏沉浸（本需求最高优先级）**
   - 用户点选某款游戏（一次手势）即进入**游戏内专注态**：画布铺满整个安全区（避让刘海/Home 条），应用顶栏、底部主导航、游戏切换标签、说明文案、分数栏等**与当前操作无关的元素全部不常驻**；支持处叠加系统全屏（Fullscreen API），不支持则应用内全屏保底。
   - 游戏进行中屏幕上仅保留**极简化发光 HUD**（如左上角小号当前分/连击，直接叠在画面上且不抢视线）；暂停/重开/退出通过**轻触屏幕中央短暂唤出半透明浮层**、无操作数秒自动隐去；只有在暂停或结算时才显示完整菜单。
   - 现有 4 款朴素益智游戏也纳入同一个专注全屏容器（玩法不变，进入后同样无干扰），并可选用 GPU 炫光皮肤。
4. **程序化音效与触感**：Web Audio API 实时合成音效/节拍（零音频文件），首次点按后启动；可一键静音并记忆；支持设备振动（navigator.vibrator）作为命中反馈（可关）。
5. **零下载、零素材、零广告、可离线**：图形与音效全部程序化生成，无图片/音频/字体素材文件；进入后 Service Worker 缓存，断网可玩；最高分与设置仅存本机。

## 目标人群

- **画像**：18–40 岁、手机中高端、对画面与手感敏感的休闲玩家；工具 PWA 的存量用户（顺手玩）；讨厌广告与下载安装、追求「干净 + 高质感」的效率型用户；碎片时间高频的通勤族/学生。
- **规模估计**：浏览器即点即玩休闲游戏是亿级大盘（CrazyGames 单平台 4500+ 游戏、海量月活可佐证需求广泛）；本功能面向的是其中「不愿装 App、厌恶广告、已在使用本工具」的高重合子集，作为工具集合的**留存与口碑门面**，潜在覆盖全部 PWA 用户。
- **付费意愿**：休闲游戏直接付费意愿中等、且红海，故**不依赖游戏本身强收费**；定位为 freemium 引流与留存资产——基础 1–2 款炫光游戏免费畅玩（让所有用户被画质「惊艳到」、建立对整个平台技术力与品质的信任，带动其它专业工具的转化），专业版/买断解锁完整炫光游戏库（全部 3 款 + 进阶难度/主题皮肤/更高粒子规格/色盲模式等）。付费理由：一次低价买断换「无广告、离线、持续更新的高质量炫光游戏库 + 已在用工具的专业权益」。

## 建议形态

选择 **PWA 网页（内嵌现有工具型 PWA 的小游戏模块）**，而非独立游戏 App / 小程序：

- 目标人群已在该 PWA 内，「顺手点开即玩」路径最短，无需下载注册，正好切中独立 App 的痛点；
- WebGPU/WebGL/Web Audio/全屏/振动均为浏览器原生能力，现代移动端浏览器已具备，PWA 安装到主屏后体验接近原生、可离线；
- 单指触控 + 竖屏优先，最贴合通勤单手场景；PC 上同一份代码支持鼠标/键盘与横屏。

## 落地价值

- **解决什么问题**：把「干净无广告的轻量游戏」升级为「干净无广告 **且画面顶级、全屏零干扰**」的游戏，给碎片时间提供高质感、强正反馈、即开即走的放松方式。
- **节省时间/资金/情绪价值**：
  - 省资金：无需购买/下载任何游戏、无广告与诱导内耗；
  - 省时间：即点即玩、退出无包袱，不用在广告站和 App 间折腾；
  - **情绪价值（本需求最突出）**：炫光、粒子、节奏与连击带来强即时正反馈与沉浸「心流」，是明确的解压/愉悦体验。
- **市场空间与对平台的战略价值**：单看游戏直接收入空间有限（红海），但它是工具集合里**最能体现技术力、最易被自发分享（「网页居然能做到这样」）的拉新与留存门面**；免费炫光游戏把用户「惊艳」转化为对平台其它专业工具的信任与专业版转化，同时延长整体使用时长与回访频次。
- **多场景链路**：触发（碎片时间/想放松/想炫耀）→ 处理（选游戏 → 一键纯净全屏 → GPU 高画质单局，支持降级与离线）→ 产出（分数/连击/纪录、即时正反馈）→ 后续动作（刷新最高分、换游戏/换难度/换主题、分享、继续使用平台其它工具、解锁完整游戏库）。贯穿「发现—游玩—成就—回访—转化」完整链路，非单一原子小工具。
- **潜在盈利点**：freemium 买断/订阅解锁完整炫光游戏库、进阶难度、主题皮肤与高粒子规格；同时作为平台专业版的展示型权益包，间接带动整体付费。

## 多场景链路与红海规避判断

- **是否同质化小工具：否**。不是单一原子功能，而是多游戏、GPU 渲染管线、全屏沉浸、音效/触感/成就/主题共同构成的可持续内容平台，具备内容持续更新（后续追加新炫光游戏）的扩展性。
- **多场景链路**：如上「发现—游玩—成就—回访—分享—转化」，贯穿触发到后续决策。
- **持续使用频次与付费空间**：碎片时间高频（通勤/排队/午休日均可多次）；付费以「完整游戏库 + 专业版组合权益」承接，直接游戏付费克制、主要靠引流与留存间接变现。
- **红海规避（诚实评估）**：休闲/网页游戏本身是**红海**（CrazyGames 等 4500+），差异化**不在玩法原创性**，而在产品形态与体验组合：① 依托已在用的工具 PWA，**零下载零注册零广告零追踪、可离线**；② **WebGPU 顶级炫光画质但零素材、包体极小、低端机可降级**的工程克制；③ **绝对纯净的全屏专注态**（游戏中不显示任何无关信息），这恰是广告型游戏站和大多数合集做不到的；④ 与工具箱其它能力互相导流。风险：玩法层面壁垒不高，需靠视觉手感打磨、纯净体验与持续上新维持吸引力。
