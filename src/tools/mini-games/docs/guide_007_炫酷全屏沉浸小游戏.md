# 用户使用指导书：炫酷全屏沉浸小游戏（炫光 NEON 系列）

- 对应 dev：`dev_007_炫酷全屏沉浸小游戏.md`
- 所属工具：小游戏合集 `mini-games`（对原工具的重构升级，非新增并列工具）
- 日期：2026-10-19
- 版本：v1.1.0（M1 里程碑）

## 功能简介

在原有「2048 / 记忆翻牌 / 数字华容道 / 三消」之上，小游戏合集新增 **炫光 NEON** 系列：用 GPU 实时渲染霓虹粒子、辉光、震屏，并配合程序化合成音效与触感振动，带来**全屏、零干扰**的游戏沉浸感。点进任意游戏即进入专注全屏，画面里**只保留游戏本身 + 极简分数与一个控制钮**，不展示任何与游戏无关的信息。设备不支持高端渲染时自动、无感地逐级降级（WebGL2 → Canvas2D），低端机也能流畅可玩。

M1 先上线系列第一款免费引流游戏 **炫光连消（Glow Match）**；「霓虹脉冲」「星轨穿梭」以"即将上线"占位，后续里程碑放出。

## 运行环境要求

- 任意现代浏览器：Chrome / Edge / Firefox / Safari（桌面与移动端均可）。
- 推荐支持 WebGL2 的设备获得完整辉光；不支持时自动降级 Canvas2D，玩法与计分不受影响。
- 无需联网即可游玩（炫光游戏代码已进入 PWA 预缓存）；音效与振动为设备本地能力。
- 已安装为 PWA 后，游戏内可请求系统全屏（由点击手势触发，被浏览器拒绝时仍保留应用内全屏沉浸）。

## 安装与启动

1. 打开方子 → 全部工具 → 生活 → **小游戏合集**（路由 `#/t/mini-games`）。
2. 在「炫光 NEON · GPU 粒子全屏」分区点击 **炫光连消**（免费）即自动进入全屏。
3. 无需安装任何素材：粒子与音效全部由代码实时生成，零图片/音频文件。

## 使用说明

### 1. 选游戏页

顶部仍是熟悉的工具页，分为「经典益智」与「炫光 NEON」两区。炫光连消卡片带"免费"角标；霓虹脉冲、星轨穿梭显示"即将上线"且不可进入。

![选游戏页（PC）](shots/shot-01-pc-picker.png)

### 2. 进入全屏沉浸

点击炫光连消后进入 **FocusStage 专注层**：纯黑底铺满整屏（含移动端安全区避让），屏幕上只有：

- 左上角：当前分数（连锁时出现"×N 连击"）；
- 右上角：一个半透明小控制钮 ❚❚；
- 中央：8×8 霓虹棋盘与下层全屏粒子画布。

应用顶栏、底部 Tab、返回条、说明文字等全部隐藏，不占游戏空间。

![炫光连消全屏（PC）](shots/shot-05-pc-glow-fresh.png)

![炫光连消全屏（手机，220 分 ×2 连击，左侧粒子）](shots/shot-08-mobile-glow.png)

### 3. 玩法

- **滑动 / 拖拽**一个宝石到相邻格：若形成横/竖三连及以上则消除并下落补充，得分 = 消除数 × 20，连锁波次加权；在被消除的格位上爆发对应色相的霓虹粒子，连锁越高震屏与音效越强。
- 不构成三连的交换会原地弹回，不扣分。
- 无解时自动洗牌，无需手动操作。
- **轻点**棋盘空白（按下后未拖动）唤出/收起控制浮层，避免与滑动手势冲突。

### 4. 控制浮层（暂停 / 继续 / 重开 / 音效 / 退出）

点右上角 ❚❚（或轻点棋盘）唤出居中浮层，可暂停、继续、重新开始、开关音效、退出游戏。暂停浮层常驻，非暂停状态下无操作约 2.5 秒自动隐去。

![暂停控制浮层（PC）](shots/shot-04-pc-sheet-paused.png)

退出后回到选游戏页，最高分会自动保存到本机（IndexedDB），并在选游戏卡片上显示。

### 5. 专业版游戏与付费墙

免费即可玩 2048、记忆翻牌、炫光连消。点击数字华容道、三消等专业版游戏时弹出买断付费墙（¥19.90，与既有定价一致，本次未调价）；已购专业版后可直接进入。

![专业版付费墙（PC）](shots/shot-02-pc-paywall.png)

已购后进入专业版 DOM 游戏（如三消）时同样全屏沉浸，但不会重复显示 GPU 分数 HUD，避免与游戏自带记分重复。

![已购进入专业版三消（PC）](shots/shot-06-pc-dom-pro.png)

## 常见问题（FAQ）

- **为什么没有粒子辉光、画面更朴素？** 设备浏览器未提供 WebGL2 或其初始化失败，引擎自动降级到 Canvas2D 兼容渲染，玩法、计分、音效完全一致，属于预期保护。
- **进入游戏没有声音？** 浏览器要求先有用户手势才允许出声，在棋盘上点一下/滑一次即可解锁；也可用控制浮层的音效开关检查是否被静音（偏好会被记住）。
- **会很耗电 / 卡顿吗？** 引擎会按设备核数、内存、DPR 选择粒子规模，并在连续低帧率（低于约 45fps）时自动按"辉光 → 分辨率 → 粒子数"逐级降档；切到后台自动暂停 RAF，不耗电。
- **分数会丢吗？** 不会。沿用原小游戏库 `fz-mini-games-v1`，本次仅新增可选设置字段，历史最高分零迁移保留。
- **需要联网吗？** 不需要。代码已离线预缓存；全程无任何网络请求与后端。

## 注意事项

- M1 尚未启用 WebGPU/WGSL 原生后端：即使设备支持 WebGPU，当前也先落 WebGL2（视觉完整），WebGPU 后端在后续里程碑接入。
- 「霓虹脉冲」「星轨穿梭」为占位，暂不可玩；主题切换、色盲模式、屏幕常亮（Wake Lock）等设置项在后续里程碑开放（本版仅在本地存储预留字段）。
- 系统全屏由点击手势触发，个别浏览器可能不授予，属正常策略，不影响应用内全屏沉浸与游玩。
