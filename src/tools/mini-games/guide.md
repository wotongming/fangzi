## 操作方式

- **2048**：电脑用方向键或 `W/A/S/D`，也可点屏幕方向键；手机在棋盘上**上下左右滑动**。
- **记忆翻牌 / 华容道 / 三消**：直接用鼠标或手指**点击**操作，手机端体验一致。
- 顶部可查看「本局」分数与该游戏该难度的「最高」分；点「重新开始」立即开新局。

## 计分与最高分

- **2048**：分数为合并产生的数字之和。
- **记忆翻牌 / 华容道**：在基础分上按步数、用时扣减——步数越少、越快完成，分数越高。
- **三消**：每消除一块得分，连续自动消除（连锁）倍数更高；没有可走的步时会自动洗牌。
- 最高分按「游戏 + 难度」分别记录，仅保存在本机浏览器（IndexedDB），不上传；清空浏览器站点数据会一并清除。

## 常见问题

- **打不开 / 黑屏？** 请使用较新的 Chrome、Edge、Safari 等浏览器；游戏为纯网页，无需安装。
- **最高分没了？** 最高分跟随浏览器本地存储，换浏览器、换设备或清理站点数据后不会同步。
- **离线能玩吗？** 方子安装为 PWA 并加载过一次后，游戏可离线打开。
