# 小游戏合集 · 用户指导

在方子首页搜索「小游戏 / 打发时间 / 摸鱼 / 2048 / 翻牌 / 华容道 / 连消 / 节奏 / 闪避」即可打开本工具。全部游戏**纯本机运行、离线可玩、无广告、无服务器后端**，不下载素材、不联网、不上传任何数据；最高分自动保存在当前设备。点进任意游戏即进入**全屏沉浸**：画面里只保留游戏、极简分数和右上角一个控制钮，应用顶栏与底部导航全部隐藏。

## 操作方式

- **2048**：电脑用方向键或 `W/A/S/D`，也可点屏幕方向键；手机在棋盘上**上下左右滑动**。
- **记忆翻牌 / 数字华容道**：直接用鼠标或手指**点击**操作；多难度游戏在卡片上点「简单 / 普通」等小标签进入对应难度。
- **炫光连消**：① **点选**——点第一颗宝石高亮，再点相邻一颗交换；点同一颗或空白处取消，点非相邻格改为改选。② **短滑**——在宝石上按住朝上下左右轻滑即可交换。轻点/滑动都是游戏操作，**不会**误弹菜单。
- **霓虹脉冲**：在三条轨道区域点击/触摸对应轨道击打音符；正中为「完美」，稍偏为「良好」，空点不扣分。
- **星轨穿梭**：在屏幕任意位置**按住并左右拖动**，光体横向跟随手指；松开也会停在原位。
- **莫比环跑酷**：点按画面任意处（电脑按空格或 ↑）让小人翻到光带另一面，对准闸门缺口穿过即可；第一次进入会有「30 秒上手」教学。在主菜单点「当前角色 · 更换」可挑选角色。
- **合成大星球**：待投球固定在**顶部安全区窄滑轨**上，手指在顶部横条（或屏幕任意处）水平拖动改瞄准 X，半透明引导线标出落点列，松手即投；**左右可贴墙全宽投放**（左上分数以半透明衬底胶囊浮于上层，不缩减可投范围）。电脑鼠标横向移动瞄准、点击或空格投放，`←/→` 微调瞄准；`A/D`（或 `Q/E`）模拟倾斜。两颗同级星球接触即合成上一级（共 19 级，顶部只投陨石~地球前 5 级、高级只能合成），连锁有连击加分；星球越过红色警戒线并持续约 1.75 秒才判负（瞬时擦过不算），合成终极宇宙（19）即通关。完整 19 天体图鉴见《用户使用手册》合成大星球章节。
  - **重力感应（移动端）**：开启后左右倾斜手机（`gamma`）给世界一个横向重力分量，落底星球向低侧缓慢滚动，回正后停下。iOS 13+ 首次需点右上角「重力感应」按钮在手势内授权；拒绝 / 不支持 / 非 HTTPS 静默回退垂直重力，游戏照常可玩，右上角开关可随时关闭。电脑无传感器，用 `A/D` 键产生同样的横向倾斜。
- **暂停菜单**：只能由右上角的 ❚❚ 按钮打开，可暂停/继续、重新开始、开关音效、切换特效档位、退出游戏。

## 计分与最高分

- **2048**：分数为合并产生的数字之和。
- **记忆翻牌 / 数字华容道**：在基础分上按步数、用时扣减——步数越少、越快完成，分数越高。
- **炫光连消**：每消除一块得 20 分（单次消除越多、连锁波次越高加分越多），不构成三连的交换原地弹回不扣分；无解时自动洗牌。
- **霓虹脉冲**：完美 100 分、良好 60 分，连击越高每击加分越多；漏掉 3 个音符本局结束。
- **星轨穿梭**：生存每秒 100 分，障碍速度随时间提升，撞到光障本局结束。
- **莫比环跑酷**：随奔跑距离稳定得分，穿过闸门与收集光屑加分；贴边擦过（near）、临门翻面对齐缺口（perfect）会累积连击倍率（最高 ×8），倍率越高闸门得分越多，撞墙本局结束。
- **合成大星球**：合成出的等级越高基础分按平方/指数越高（陨石 10 → 宇宙 18000，高级跃迁分差拉大），短时间内连续合成触发连锁，连击 ×1.3 递增；合成终极宇宙（19）通关大爆发，星球越过警戒线持续约 1.75 秒判负。最高分沿用同一本机存档 key，扩链不清档、旧高分直接保留。
- 最高分按「游戏 + 难度」分别记录，仅保存在本机浏览器（IndexedDB），不上传；清空浏览器站点数据会一并清除。莫比环跑酷沿用独立存档库，即便它从单独工具并入合集，历史最高分也会自动保留。

## 画面、音效与电量

- 不支持 WebGL2 的设备会自动改用 Canvas2D 兼容渲染，画面更朴素但玩法、计分、音效完全一致。
- 浏览器要求先有一次点击才允许出声，进入游戏后点一下/滑一次即可解锁音效；可在暂停菜单里静音，偏好会被记住。
- 游戏进行中会请求**屏幕常亮**，避免玩到一半自动锁屏；暂停、退出或切到后台时自动恢复系统锁屏，不支持的浏览器会静默跳过。
- 觉得耗电或卡顿，可在暂停菜单把「特效」切到**低（省电）**；引擎也会在持续低帧率时自动降档，切到后台自动停止渲染、不耗电。

## 常见问题

- **游戏需要联网或后端吗？** 不需要。所有游戏全程本机运算与渲染，没有任何网络请求、没有服务器；文档里的“渲染后端”仅指本机的 WebGL2 / Canvas2D 图形引擎。
- **打不开 / 黑屏？** 请使用较新的 Chrome、Edge、Safari、Firefox 等浏览器；游戏为纯网页，无需安装。
- **玩炫光连消一点屏幕就弹暂停？** 该问题已修复：轻点是选中宝石、滑动是交换，暂停只能点右上角 ❚❚；若仍是旧表现，刷新页面或等 PWA 更新到最新版即可。
- **莫比环跑酷画面为什么会翻转 / 人怎么控制？** 这是核心玩法：光带本身是半扭转的莫比乌斯环，跑到扭转处空间会翻滚、你所在的面与对面对调；只需在闸门到来前点按屏幕把小人翻到缺口那一面即可。
- **莫比环打不开提示不支持 3D？** 它需要浏览器支持 WebGL，请用较新的 Chrome / Edge / Safari 并开启硬件加速；其余游戏不受影响。
- **最高分没了？** 最高分跟随浏览器本地存储，换浏览器、换设备或清理站点数据后不会同步。
- **离线能玩吗？** 方子安装为 PWA 并加载过一次后，所有游戏都可离线打开。
