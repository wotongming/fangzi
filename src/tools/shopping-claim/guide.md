# 网购三包·退换货维权管家 · 使用指导

> 版本 1.0.0 · 更新于 2026-10-18

## 这个工具能做什么

把一次网购售后从「凭感觉、靠回忆」变成「有时效、有证据、有说法」：

- **时效看板**：按签收日期和商品类别，自动算出 **7 天无理由退货、15 日内换货（三包）、保修期内免费修理、价保** 各自的起止日期、还剩几天、今天能做什么，每条都标注规则来源。
- **证据柜**：订单、支付、聊天、物流、商品瑕疵照片随拍随存，本地自动压缩、案件内连续编号并固化录入时刻，可一键导出带证据清单的 ZIP。
- **维权文书**：按情形（质量瑕疵 / 发错货 / 仅不想要 / 过了 7 日在三包期 / 价保）生成**协商话术、平台介入说明、12315 投诉文本**草稿，可自行编辑、复制。
- **进度跟踪**：待取证 → 与商家协商 → 平台介入 → 12315 → 完成，可前进可回退，记录实际挽回金额与时间线。

**重要边界**：本工具只做时效参考、证据整理与文书草稿，**不代为投诉、不抓取任何平台数据、不联系商家**；文书需你自行核对事实与诉求后提交。时效与规则为常见情形整理，**具体以最新法律法规、平台规则及三包凭证/保修卡为准，不替代律师意见或 12315、市场监管部门的正式认定**。

## 快速开始

1. 打开工具，点「＋ 新建维权案件」。
2. 填写商品名称、购买渠道、订单号、成交金额、**商品类别**、**签收日期**（发现问题日期可后补），按需设置价保天数、是否定作商品。
3. 保存后进入案件，顶部五个分段页签：**时效 / 证据 / 文书 / 进度 / 规则**。

> 免费版可跟踪 2 个商品；专业版支持不限案件数、全套文书、证据包与日历提醒导出。所有数据只存在本机 IndexedDB，不上传。

## 时效怎么看

- 「时效」页每个窗口显示 **还剩 N 天 / 今天到期 / 已过 N 天 / 不适用**，以及今天可采取的动作和法规依据。
- **质量问题不受 7 天无理由期限限制**：即使无理由窗口已过，属于质量问题仍可依法主张修、换、退。
- 手机浏览器关闭应用后**无法保证**后台通知，建议点「导出日历提醒（.ics）」导入手机系统日历，由系统在到期日提醒。
- 保修月数为常见值（多为 12 个月），实际以三包凭证、保修卡承诺为准；价保天数是平台规则（非全国统一法定期限），以订单页为准。

## 如何固化证据

1. 在「证据」页选择证据类型（订单截图 / 支付凭证 / 聊天记录 / 物流签收 / 商品瑕疵 / 其它），可写备注。
2. 点「＋ 拍照 / 选择图片」，可多选；图片在本地压缩（长边 1600、JPEG）、去除拍摄元数据后保存，自动连续编号，文件名形如 `01_order_20261018-103015.jpg`。
3. 建议顺序：先存订单与支付，争议发生时存聊天记录，收货存物流与开箱，发现问题立刻拍商品/瑕疵。
4. 点「导出证据包 ZIP」得到图片 + `证据清单.txt`（含商品信息、时效窗口、每项证据的类型/固化时间/原文件名/备注）；也可选择「证据包 + 当前文书」一起打包，提交给平台或 12315。

## 如何生成维权文本

1. 在「文书」页选择你的**情形**和**用途**（协商 / 平台介入 / 12315）。
2. 点「生成文本」，系统把商品、渠道、订单、金额、日期与诉求填入模板。
3. 在文本框里按实际情况修改，再「复制文本」粘贴到客服窗口、平台申诉框或 12315；也可并入证据包导出。
4. 12315 文本末尾的姓名、电话、日期需要你自行补全后提交。

## 进度与结果

在「进度」页点「推进到下一步 / 回退一步」更新状态并可写备注；在「处理结果」里记录实际挽回金额，方便复盘。

## 常见问题（FAQ）

- **拆封了还能退吗？** 「拆封」不等于「不完好」，商家不能仅以已拆封为由拒绝无理由退货；但商品应保持完好、配件齐全。定作、鲜活易腐等法定例外除外。
- **过了 7 天商家就不理怎么办？** 如果是质量问题，修换退不受七日无理由期限限制，可继续主张三包/保修，并保留证据。
- **数据会上传吗？** 不会。案件与证据图片全部存在本机浏览器，清理浏览器数据会删除，请及时导出证据包备份。
- **换手机怎么办？** 用「导出证据包 ZIP」留存；卸载或清理浏览器数据前务必先导出。
