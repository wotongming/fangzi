# JSON 格式化校验器 · 用户指导

## 解决什么问题
把挤成一团的接口 JSON 一键美化/压缩，在 JSON 有语法错误时**定位到具体行列**，所有处理仅在本地浏览器完成。

## 怎么用
1. 把 JSON 粘贴到输入框。
2. 点击：
   - **美化**：带 2 空格缩进，便于阅读；
   - **压缩**：去掉空白，便于传输；
   - **转义**：把整段 JSON 变成可嵌入代码的字符串字面量；
   - **去转义**：把带 `\"`、`\n` 的字符串还原。
3. 结果区可一键复制。

## 报错怎么看
- 出现「JSON 语法错误」时，会显示第几个字符、第几行第几列，并给出附近片段，按提示检查逗号、引号、括号即可。
- 常见原因：尾逗号、用了单引号、注释、键名没加引号（JSON 不允许这些 JS 写法）。

## 隐私
数据不离开浏览器，可放心粘贴含敏感字段的内容。
