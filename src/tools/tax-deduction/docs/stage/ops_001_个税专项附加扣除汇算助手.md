# 部署运维指引：个税专项附加扣除·年度汇算助手

- 对应 architect：architect_001_个税专项附加扣除汇算助手.md
- 编写日期：2026-10-19

## 部署架构与环境准备
纯静态 PWA，无后端/数据库/服务器；构建产物 `dist/` 托管腾讯云 EdgeOne Pages，main 推送自动部署。数据仅在用户浏览器 IndexedDB/Web Crypto。

## 软硬件配置清单
无服务器；构建用仓库既有 Node/npm 工具链。

## 部署步骤
本地 `npm ci`→`npx vue-tsc --noEmit`→`npm test`→`npm run build`→`npm run verify:tools`；GitCode 推送 main，EdgeOne Pages 自动发布；上线访问 `/#/t/tax-deduction` 验证。

## 配置项说明
规则常量集中 `lib/rules-cn.ts`（含 RULE_VERSION）；无环境变量/密钥。

## 上线/灰度方案
随主站全量静态发布；如需灰度可先在预览域名验证；回滚=在 EdgeOne/GitCode 回退到上一提交（纯增量目录）。

## 平台对接指南
- EdgeOne Pages：连接 GitCode 仓库 main 分支自动构建，静态输出，免费额度内（5GiB/20000文件/25MiB）；无需服务端函数。
- 无插件商店/支付对接（计费为方子统一前端框架）。

## 运维监控指标与告警
无后端无服务端日志；依赖 EdgeOne 自带访问/错误统计；关注前端报错（可由主站统一上报，如有）。规则过期风险：每年税季后核对官媒口径更新 RULE_VERSION。

## 日志管理/备份与容灾
无服务端数据；用户数据本地，提供导出/加密备份；浏览器清数据会丢失，UI 明示。

## 常见故障排查与回滚预案
规则显示异常→清缓存/检查 SW 更新；时间/金额错误→以单测定位纯函数；严重问题直接回退该工具目录提交，不影响方子其他工具（自动发现、零耦合）。
