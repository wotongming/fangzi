## 技术选型落地
Vue3+TS+Vite、IndexedDB、Web Crypto；零新增依赖；现栈一致。

## 模块设计
models/rules-cn/validator/split-plan/estimate/store/docs/notify/manifest/index.vue；数据 profiles/items/docs。

## 关键实现方法
规则表 `RULE_VERSION=cn-2026-10`，每项含 amountCents/条件/可分摊比例/留存材料；validator 输入家庭+年度输出 `{level,code,msg}[]`；金额一律整数分。

## 文件清单
新建 `src/tools/tax-deduction/`（manifest.ts、index.vue、guide.md、lib/*）、`test/tax-deduction.test.ts`、E2E 脚本。

## 开发环境与工具链
node/npm、vue-tsc、tsx 单测、Playwright+Chromium（/usr/local/bin/chromium）。

## 开发步骤与里程碑
规则+校验单测 → UI → 资料/提醒 → E2E/文档。

## 代码规范与质量要求
与 fangzi 风格一致；纯逻辑可测；计费走 useToolBilling；工具内不做 fixed 底栏。

## 验收标准
vue-tsc 0 错、新增单测全过、build/verify:tools 通过、三视口零溢出、免责声明常驻、存量功能回归无影响。
