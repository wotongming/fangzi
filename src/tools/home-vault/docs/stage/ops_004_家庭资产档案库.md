# 部署运维指引：家庭资产与重要证件档案库（家庭资产档案库）

- 对应 architect：architect_004_家庭资产档案库.md
- 编写日期：2026-10-20
- 工具位置：`src/tools/home-vault/`，随 fangzi 主站整体静态部署

## 部署架构与环境准备

无后端、无服务端数据库、无插件商店、无第三方云同步：本工具全部数据（资产卡片、凭证照片、箱单、到期项）存用户浏览器 IndexedDB（`fangzi-home-vault`），导出包（加密 JSON / 理赔 ZIP）走用户本机文件下载。部署形态 = fangzi 静态站（腾讯云 EdgeOne Pages 免费版）整体发布。

```
Git main push → EdgeOne Pages 自动构建（npm ci && npm run build）→ dist 静态发布 → CDN
用户浏览器 → SW 预缓存外壳 → 搬家现场断网仍可打开档案/箱单/扫码手输录入
```

## 软硬件配置清单

| 项 | 配置 |
| --- | --- |
| 构建机 | EdgeOne Pages 托管构建（Node ≥20.19，平台提供） |
| 运行依赖 | 用户浏览器近 2 年版本；IndexedDB；照片约每张 ≤300KB（压缩后） |
| 限额自查 | 本工具主 chunk 预估 100–180KB gz；QR 库懒 chunk ~15KB；照片不进静态包；站级 dist 约 131MiB/130+ 文件/最大单文件 22.9MiB，均在 5GiB / 20000 文件 / 25MiB 内 |

## 部署步骤

1. 本地质量门全过（npm test / vue-tsc / verify:tools / npm run build）；确认 `qrcode-generator` 已写入 package.json 且 install 成功。
2. 合入 main → EdgeOne Pages 自动构建发布。
3. 线上冒烟：搜索"家庭档案/保修卡"命中工具页；跑一遍 建资产→拍照→导出 zip 主流程。
4. OCR 模型（若开启）：运行时 hf-mirror 懒加载，无需运维；故障自动降级手动录入。

## 配置项说明

无环境变量、无密钥、无服务端配置。计费默认 LocalMockProvider；配置 `VITE_BILLING_ENDPOINT` 后自动切真实支付，代码零改动。加密备份口令由用户自设，**服务端与开发者均不接触、也无法恢复口令**（guide 中必须提示用户牢记口令，遗忘=备份包不可解）。

## 上线/灰度方案

静态站全量即灰度；观察期反馈邮箱（fangziasia@163.com）与线上冒烟。回滚：`git revert` 合入提交 → 重推 main → 工具目录消失即下架，其它工具与主站不受影响；用户本机数据保留，重新上线后仍在。

## 平台对接指南

- **EdgeOne Pages**：仓库绑定、构建命令 `npm run build`、输出 `dist`、HTTPS 平台默认签发。本工具无任何额外对接。
- **无插件商店、无支付平台对接、无云存储对接**（刻意不做实时云同步；双人协作=导出包微信互传导入）。

## 运维监控指标与告警

同 003：CI 中 verify:tools 计数、EdgeOne 构建失败通知、反馈邮箱周扫。隐私工具额外关注：来信中若出现"照片打不开/导入合并错乱"，优先按 IndexedDB 容量（照片占空间）排查。

## 日志管理

无服务端日志。guide 指引：隐私模式不持久化；定期（如每季度）导出一次加密备份 JSON 存微信文件传输助手或其它本地介质。

## 备份与容灾

- 用户侧：加密备份 JSON（口令）+ 理赔 ZIP 按需导出；换机流程 = 新机打开工具 → 导入备份包 → 自动合并。
- 项目侧：代码随 GitCode 版本管理。
- 数据不出端是本工具核心卖点，无云端容灾可言；容量风险提示写进 guide（照片类工具建议 ≤500 张压缩照片，超出可定期导出归档后删除本机记录）。

## 常见故障排查与回滚预案

| 故障 | 排查 | 处理 |
| --- | --- | --- |
| 工具页白屏 | 控制台报错；疑 QR 懒 chunk 404 | build 后 preview 复现；紧急 revert 下架 |
| 拍照后照片丢失 | 隐私模式/浏览器清理 IndexedDB | guide 提示定期备份；非代码 bug |
| 扫码无反应 | 当前浏览器不支持 BarcodeDetector（Safari/iOS） | 预期行为：自动隐藏扫码按钮走手输点选；不得当作缺陷回滚 |
| 加密备份导回打不开 | 口令错误或包损坏 | 解密抛错即提示"口令错误或文件损坏"；重试原口令 |
| 理赔 zip 解压异常 | Blob→Uint8Array 转换边界 | 单测覆盖空凭证/大文件；修后重发 |
| 上线后需快速撤下 | 删除目录即自动下架 | revert 对应提交重推 main，不影响主站 |
