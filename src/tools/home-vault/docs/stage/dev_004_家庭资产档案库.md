## 模块设计

### IndexedDB 数据模型（dbName: `fangzi-home-vault`，version 1）

```ts
// store: assets  keyPath='id'  索引:['category','category'],['location','location']
interface Asset {
  id: string; project?: string; // 无项目概念，全家庭单库
  name: string;                 // "西门子冰箱"
  category: string;              // 家电/数码/家具/证件/保单/车辆/其它
  location: string;             // "厨房-冰箱位"
  purchaseDate?: string;        // YYYY-MM-DD
  priceCents?: number;          // 整数分
  brandModel?: string; serialNo?: string;
  warrantyEnd?: string;        // 保修截止 → 入到期日历
  notes?: string;
  boxId?: string;               // 搬家后归属箱
  createdAt: number; updatedAt: number;
}

// store: docs  keyPath='id'  索引:['assetId','assetId']
interface Doc {
  id: string; assetId: string;
  kind: 'invoice'|'warranty'|'manual'|'repair'|'other';
  photoBlob: Blob;             // image-redraw 压缩后
  note?: string; createdAt: number;
}

// store: boxes  keyPath='id'
interface Box { id: string; code: string; destRoom: string; note?: string; createdAt: number }

// store: boxItems  keyPath='id'  索引:['boxId','boxId'],['assetId','assetId']
interface BoxItem { id: string; boxId: string; assetId: string; ts: number }

// 到期日历为派生视图：assets.warrantyEnd + 手动登记的 ExpiryItem（存 assets 同表 notes 类型项或独立轻量 JSON LocalStorage）
interface ExpiryItem { id: string; title: string; dueDate: string; kind: 'warranty'|'license'|'insurance'|'inspection'; assetId?: string }
```

### 数据流

```
拍照 → photos 压缩 → docs(assetId) → 详情页凭证链
expiry() 实时聚合 assets.warrantyEnd + ExpiryItem → 分级看板 / .ics
建箱 → qrcode 生成 fz-box:<id> → 扫码/手输 → boxItems 关联 → 搜索反查
导出 → claim-pack 遍历勾选 assets+docs Blob → fflate zip → 下载
备份 → 全库 JSON → crypto.exportEncrypted(口令) → 下载；导入 → 解密 → merge upsert
```

## 关键实现方法

### QR 生成（lib/qrcode.ts）

```ts
// 动态懒加载，不进首包
import('qrcode-generator').then(({ default: qrcode }) => {
  const qr = qrcode(0, 'M');                 // 自动类型、纠错 M
  qr.addData(`fz-box:${boxId}`);
  qr.make();
  el.innerHTML = qr.createSvgTag({ scalable: true });  // 矢量 SVG 打印不糊
});
// 扫码：const det = ('BarcodeDetector' in window) ? new BarcodeDetector({formats:['qr_code']}) : null
// 扫到 → det.detect(stream) → 解析 fz-box: 前缀 → 跳转；异常 → UI 隐藏扫码按钮走手输点选
```

### 加密备份信封（lib/crypto.ts，复用 home-medicine 同款）

```ts
// exportEncrypted(data, password): PBKDF2-SHA256(iter=100000, salt=16B) → AES-GCM-256(iv=12B)

```

### 理赔包结构（claim-pack.ts）

```
理赔资料包_20261020.zip
├── manifest.json        {version, exportedAt, assets:[{id,name,category,priceCents,docs:[docId...]}]}
```

## 验收标准

1. E2E 主流程：建资产 → 拍照挂凭证 → 保修临期 5 天内出现橙色 → 建箱生成 QR → 手输箱号录物 → 搜物品显示箱号 → 勾选导出 zip → 加密导出 → 改数据后导入合并取新。
2. 免费层：第 51 张卡拦截；购买后全部解锁。
3. 三视口零横向溢出；iOS Safari 无 BarcodeDetector 时扫码按钮隐藏、手输可用。
4. **存量回归**：全量单测绿、verify:tools=28、build 成功；断网 preview 下档案/箱单可查。
5. 隐私：照片无 EXIF、备份包无口令打不开、"清空全库"按钮二次确认后才执行。
