# 家庭资产档案库 · 用户指导

版本 1.0.0 · 更新于 2026-10-20

## 这是什么 / 能做什么

把家里的家电、数码、家具、证件、保单、车辆等贵重 / 关键物品录成一张档案卡，发票、保修卡、说明书、维修记录拍照挂到卡片上；保修 / 证件 / 保险 / 年检到期自动分级提醒并可导出系统日历；搬家时给纸箱生成 QR 标签，扫码或搜索即知物品在几号箱；勾选资产一键导出理赔资料包 ZIP；全库可口令加密备份、换机导入合并。所有数据只存在这台设备的浏览器里，不上云、不注册账号。

**重要边界**：本工具只管理你本人录入的物品与本人拍摄的凭证，不参与保险定损，赔付以保险公司核定为准。

## 快速开始

1. 打开工具，在「档案」页点「＋ 录一件」，填名称（必填）、类别、存放位置、购入日期、购入价、品牌型号、序列号、保修截止日、备注，可拍照挂凭证。
2. 到「到期」页查看保修 / 证件 / 保险 / 年检的分级提醒，点「导出 .ics」导入系统日历。
3. 搬家时在「搬家箱单」页「＋ 建箱」，生成 QR 标签贴到纸箱并把物品挂入箱。
4. 理赔用「理赔」页勾选资产导出 ZIP；换机用「备份」页加密导出、对口令导入合并（后两者为专业版）。

## 分步用法

### 1. 录一件资产（档案页）

- 名称必填；类别、存放位置、购入日期、购入价（元）、品牌型号、序列号、保修截止日、备注选填。
- 可直接拍照或从相册选图作为发票 / 保修卡等凭证，自动压缩、剥离 EXIF / GPS；保存后卡片显示凭证缩略图，可单独删除。
- 免费版最多 50 张资产卡片。

### 2. 到期看板与系统日历提醒（到期页）

- 资产的「保修截止」自动进入看板：逾期红色、7 天内橙色、30 天内黄色。
- 证件 / 保险 / 年检等非保修项，点「＋ 登记到期项」手动录入。
- 点「导出 .ics」把全部到期项导入手机 / 电脑系统日历，每项含提前 30 天与 7 天两条提醒。手机浏览器关闭应用后收不到后台通知，建议用 .ics 由系统长期提醒。

### 3. 搬家箱单与 QR 标签（搬家箱单页）

- 点「＋ 建箱」填箱号与目的地房间（如「1 号箱 · 卧室区」），自动生成矢量 QR 标签，可打印标签贴到纸箱。
- 浏览器支持原生扫码时可扫码直接进该箱；不支持（如 Safari/iOS）会自动隐藏扫码按钮，走「选择物品 + 选择箱号」点选降级路径，功能不受影响。
- 挂入物品后，在档案页搜索物品名即可看到「在 N 号箱 · 目的地」。

### 4. 理赔资料包（专业版 · 理赔页）

- 勾选要理赔的资产，点「导出理赔 ZIP」，得到 `manifest.json`、可直接打印 / 另存 PDF 的 `清单.html`，以及按资产 / 凭证分目录的全部照片，可直接发给保险公司；也可先预览 / 打印清单。

### 5. 加密备份与导入合并（专业版 · 备份页）

- 导出：设置备份口令，导出 `home-vault-backup-YYYYMMDD.json`（PBKDF2 10 万次 + AES-GCM-256 加密，照片以 base64 内联）。
- 导入：换机 / 家人互传后选文件、输入口令；按 id 合并，同 id 取更新时间晚者，反馈「新增 X 条，更新 Y 条」，照片不丢。
- 清空全库需二次确认，不可恢复，请先导出备份。
- 拍照文字识别（OCR）为实验能力，当前未默认启用，手动录入完全可用。

## 数据与隐私

- 照片压缩后只存本机 IndexedDB，工具无后端、无云同步；导出备份也是在本机加密成文件由你自己保管。
- 定期（如每季度）导出一次加密备份存到本地介质；清理浏览器站点数据会删除本机档案。隐私 / 无痕窗口不持久化，请勿在其中长期使用。

## 常见问题

- **照片会不会被上传？** 不会，压缩后只存本机，无云同步。
- **换手机怎么办？** 旧机导出加密备份 JSON → 新机备份页输入口令导入，自动合并。
- **扫码用不了？** Safari/iOS 不支持原生 BarcodeDetector 属预期，用「点选箱号」即可。
- **忘记备份口令？** 口令由你本人设置、本地派生，无法找回，遗忘则备份包不可解，请牢记。

## 注意事项 / 功能边界

- 每张照片已压到约 300KB 内，本机 IndexedDB 容量有限，超量可先导出归档再删除本机记录。
- 本工具不参与保险定损，也不替代官方保修登记；到期日以发票 / 保修卡 / 保单原文为准。
