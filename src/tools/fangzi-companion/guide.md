# 方子助手浏览器插件 · 使用手册

> 版本 0.1.0 · 适用 Chrome / Edge / Brave 等 Chromium 内核浏览器（102 及以上）

在任意网页**划词右键**，直接把问题丢给方子搜索对症工具，省去「复制 → 打开方子 → 粘贴」的来回切换。

---

## 一、功能说明

| 功能 | 是否免费 | 说明 |
| --- | --- | --- |
| 划词右键「用方子搜索」 | 免费 | 把选中文字作为问题，新开标签页搜索方子工具 |
| 工具栏弹窗快速打开方子 | 免费 | 点击插件图标即可配置与跳转 |
| 划词「方子 AI 解读」 | 高级（Freemium） | 携带授权码调用 AI 解读选中文本 |

## 二、安装步骤（Chrome / Edge）

本插件以 zip 形式分发，按「加载已解压的扩展程序」方式安装：

1. 在本页下载压缩包 `fangzi-companion-chrome-0.1.0.zip`。
2. **校验完整性（推荐）**：下载后用方子的「文件哈希校验器」或系统命令核对 SHA256，应与下载页显示的值一致：

```text
b7451dd8f826cf8d793803646447ababed07074834811f7a52636e8293614e4b
```

3. 把 zip **解压**为一个文件夹（确保解压后文件夹根目录能直接看到 `manifest.json`）。
4. 打开浏览器扩展管理页：
   - Chrome：地址栏输入 `chrome://extensions`
   - Edge：地址栏输入 `edge://extensions`
5. 打开右上角「**开发者模式**」。
6. 点击「**加载已解压的扩展程序**」，选择第 3 步解压出的文件夹。
7. 列表中出现「方子助手」即安装成功，建议点「固定」把图标放到工具栏。

> 升级时：下载新版 zip 解压覆盖，再到扩展管理页点击该插件的「刷新/重新加载」按钮。

## 三、配置站点地址

安装后首次使用需要告诉插件「方子」部署在哪里：

1. 点击工具栏的「方子」图标，或在扩展页点击「详情 → 扩展程序选项」。
2. 在「方子站点地址」填写你部署的方子站点，例如 `https://fangzi.example.com`（会自动补全 `https://` 与末尾斜杠）。
3. 高级用户可在「高级版授权码」填入购买 AI 解读后获得的授权码。
4. 点击「保存」。

未配置站点地址时使用右键菜单，会自动打开设置页引导配置。

## 四、日常使用

1. 在任意网页用鼠标选中一段文字（报错信息、问题描述、术语等）。
2. 右键 → 选择「**用方子搜索“……”**」。
3. 浏览器新开方子标签页，搜索框已自动填入该问题并展示对症工具，点击即可使用。

## 五、高级功能与授权

- 「方子 AI 解读」为**免费增值（Freemium）**功能：划词搜索免费，AI 解读需在方子内一次性解锁（示例 9.9 元）。
- 解锁后把授权码填入插件设置；插件在 AI 跳转时携带授权码，由方子站点侧校验权益。
- 授权校验遵循方子站点的计费策略，插件本身不接触支付密钥。

## 六、权限与隐私说明

插件仅申请以下最小权限：

- `contextMenus`：创建划词右键菜单；
- `storage`：用 `chrome.storage.sync` 保存站点地址与授权码；
- `tabs`：新开标签页打开方子。

插件**不读取、不上传**你浏览的网页内容；只有当你主动选中文字并点击右键菜单时，才会把「你选中的那段文字」拼接到方子站点地址中打开。

## 七、常见问题

- **右键看不到菜单**：确认是在选中文字后右键；部分浏览器内置页面（如扩展管理页、chrome:// 页面）禁止扩展菜单，属正常限制。
- **打开的方子地址不对**：点插件图标检查「方子站点地址」是否填写正确并已保存。
- **提示下载文件校验不一致**：压缩包可能损坏或被篡改，请重新下载并核对 SHA256，一致前不要加载。
- **如何卸载**：在扩展管理页点击「移除」即可；保存在 `storage.sync` 的设置会随之清除。

## 八、文件清单

压缩包解压后包含：`manifest.json`、`background.js`（服务工作线程）、`popup.html/js/css`（弹窗）、`options.html`（设置页）、`_locales/zh_CN/messages.json`（中文文案）、`icons/`（图标）。
