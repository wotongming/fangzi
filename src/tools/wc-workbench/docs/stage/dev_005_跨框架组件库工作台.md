## 技术选型落地

- 生成目标：Lit（BSD-3）；编辑器 CodeMirror 6（MIT）；打包 fflate（MIT）；全部动态 import；零成本、商用友好；不引 Monaco 等重型编辑器。

## 模块设计

见 architect_005 系统架构；model 为单一事实源；generate/preview/docs/manifest-gen/export 五路消费；index.vue 三栏布局（左表单/中预览/右代码文档导出）。

## 关键实现方法

```ts
// Lit 生成模板（generate/lit.ts，示意）
export function litSource(m: ComponentModel): string {
  return `import { LitElement, html, css } from 'lit'
import { customElement, property } from 'lit/decorators.js'

@customElement('${m.tagName}')
export class ${m.className} extends LitElement {
  static styles = css\`${m.cssVars.map(v=>`:host{--${v.name}:${v.def}}`).join('\n')}\`
${m.properties.map(p=>`  @property() ${p.name}${p.type==='string'?' = ""':''}`).join('\n')}
  render() { return html\`${m.template}\` }
}`
}
// 预览通信（preview.ts）
iframe.contentWindow?.postMessage({ type:'set-props', props }, '*')
```
