# 部署运维指引：跨框架组件库工作台

- 对应 architect：architect_005_跨框架组件库工作台.md
- 编写日期：2026-10-15

## 部署架构与环境准备

- 部署架构：EdgeOne Pages 静态托管（同 fangzi）；纯前端工具，无服务端；生成代码由用户自行分发。
- 环境清单：Node ≥ 20.19（构建机）；EdgeOne Pages 账号（已有）。

## 软硬件配置清单

| 项 | 规格 |
| --- | --- |
| 构建机 | Node 20+ |
| 部署 | EdgeOne Pages（免费额度） |
| 客户端 | 现代浏览器（iframe 沙箱 + ES Module 支持） |
| 产物 | 用户生成的组件代码/zip（本地导出） |

## 部署步骤

1. `cd fangzi && npm install && npm run build`
2. EdgeOne Pages CLI/Git 推送 dist/
3. 验证：组件定义→生成→预览→导出全流程可用
4. 更新 README 工具清单（登记 wc-workbench 七字段）

## 配置项说明

- 无新增环境变量；模板与 wrapper 目标在 lib 常量维护。

## 上线/灰度方案

- 内部灰度（全功能）→ 观察预览沙箱稳定性 → 全量；Pro 权益随计费框架发布。

## 平台对接指南

- **EdgeOne Pages**：个人账号即可；部署 CLI/Git；HTTPS 平台提供；版本更新=重新部署。
- 其余平台：不涉及（工具在浏览器内生成代码，用户自行选择分发渠道）。

## 运维监控指标与告警

- 指标：工具访问量、生成/导出成功率（本地打点可选上报）；
- 告警：预览沙箱错误率异常 → 检查 iframe CSP/浏览器兼容。

## 日志管理

- console + error 聚合；不采集用户组件代码。

## 备份与容灾

- 无服务端数据；代码仓 git 备份；提示用户导出保存组件定义（模型可序列化导出）。

## 常见故障排查与回滚预案

- 预览空白：检查 iframe sandbox 属性与 blob URL 策略；
- 生成代码报错：定位模板缺陷，快照单测回归；
- 严重问题：`git revert` + 重部署，仅影响新增工具。
