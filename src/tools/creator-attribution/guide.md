# 创作归因台 · 用户指导

版本 1.0.0 · 更新于 2026-10-20

## 这是什么 / 能做什么

同时运营抖音、小红书、B站、公众号等多个账号的独立创作者，把每周逐平台手抄的阅读量、收益、投入工时录成一份**只存在本机**的内容台账。工具按**主题 / 形式 / 平台 / 发布时段**四个维度自动归因单位收益与时薪 ROI，帮你判断下周该把时间押在哪类内容；另附品牌商单记录与近 30 天报价参考区间、可导出的月度经营报告。

**重要边界**：本工具不接任何平台 API、不抓包、不内嵌平台网页，所有数据由你手动录入或用自己导出的 CSV 导入；它只做基于你本机历史数据的保守复盘，不承诺任何收益。

## 快速开始

1. 打开工具，默认在「台账」页，点「＋ 账号」，选择平台（抖音 / 小红书 / B站 / 公众号 / 知乎 / 播客等）并填昵称，例如「抖音@老王美食号」。
2. 点「＋ 录内容」，选择所属账号，填写标题、主题标签（逗号分隔，如 `美食,探店`）、形式（图文 / 视频 / 播客）、发布时间、投入工时（小时，可填 0.5）。
3. 每条内容发布 7 天 / 30 天后，点该条的「回收数据」补录阅读量、涨粉、本期收益（元）与备注。
4. 需要复盘时切到「归因」「商单」「报告」页（后三者为专业版）。

## 分步用法

### 1. 建账号与录内容台账

- 一个账号对应一个平台昵称；删除账号会**级联删除**其全部内容、数据快照与商单，不可恢复，请谨慎。
- 录内容时标题、发布时间为关键项；主题标签用于后续按主题归因，形式与发布时段分别用于另外两个维度。
- 金额一律按「元」填写，程序内部按整数分存储，避免浮点误差。

### 2. 回收数据（一条内容可录多次快照）

- 每条内容下方点「回收数据」展开，记录发布后 7 天、30 天等节点的阅读 / 播放量、涨粉、本期收益（元）、备注并保存。
- 同一条内容可录多次快照，累计阅读与收益自动汇总，后录的快照不会覆盖前一次。

### 3. CSV 批量导入历史台账（专业版）

- 点「CSV 导入」选择本地 CSV（UTF-8 或 GBK 编码均可）。
- 工具模糊识别中文列名（标题 / 平台 / 发布时间 / 标签 / 阅读量 / 收益元 / 工时），先弹出预览「解析到 N 条、跳过 M 条（缺标题 / 日期）」，确认后**追加**写入，不覆盖已有数据。
- CSV 表头示例：

```
标题,平台,发布时间,标签,阅读量,收益元,工时
周末探店老面馆,抖音,2026-10-08,美食 探店,12000,35.5,2
```

- 缺「标题」或「发布时间」必需列时整批不写入并提示；个别行缺标题 / 日期会被跳过并计数。CSV 内容会挂到第一个账号下，建议先在台账建好账号。

### 4. 四维归因看板（专业版）

- 切到「归因」页，在主题 / 形式 / 平台 / 发布时段之间切换，柱状图按收益展示，下方表格列出每一类的条数、阅读、收益、元 / 条、时薪（元 / 小时）。
- 时薪 ROI = 该维度收益合计 ÷ 工时合计；某类别工时记为 0 时无法相除，时薪显示「—（工时0）」，补录工时后自动算出。

### 5. 商单台账与报价参考（专业版）

- 切到「商单」页，点「记一条商单」填品牌、金额（元）、结果（已结 / 在谈 / 黄了）。
- 顶部自动给出**近 30 天已结商单的最低–最高报价区间**，下次品牌来问价时作为自己历史成交价的参照。

### 6. 月度经营报告（专业版）

- 切到「报告」页，用月份选择器选月份，预览「本月概览 / 收入构成 / TOP3 内容 / 下月策略（按 ROI Top2 主题）/ 商单汇总」，点「导出 .md」保存 Markdown 文件。
- 「下月策略」仅基于本机历史数据给出保守参考，不构成收益承诺。

- 专业版（一次买断 ¥19.90）：账号与内容条数不限、CSV 批量导入历史台账、主题 / 形式 / 平台 / 时段四维归因看板、品牌商单记录与近 30 天报价参考区间、月度经营报告 Markdown 导出。无论是否付费，数据都只保存在本机。

## 数据与隐私

- 全部账号、内容、快照、商单与报告只保存在当前浏览器 IndexedDB，不上传、不同步、不接平台接口。
- 换机或重装浏览器数据不自动跟随；可定期用 CSV / Markdown 导出留存。清理浏览器站点数据会删除全部台账，请先导出备份。

## 常见问题

- **会自动抓取抖音 / 小红书后台数据吗？** 不会。本工具不接平台 API、不抓包，所有数字由你手动录入或通过自己导出的 CSV 导入。
- **免费版能用到什么程度？** 3 个账号、30 条内容与手动数据回收免费；CSV 导入、四维归因看板、商单台账、月度报告为专业版。
- **为什么某一类时薪显示「—」？** 该类别工时记为 0，无法计算时薪，补录工时后自动显示。
- **换手机数据还在吗？** 存在当前浏览器，换机不跟随，请先导出 CSV / Markdown 留存。

## 注意事项 / 功能边界

- 本工具是个人复盘记账工具，不提供任何平台后台数据接口，也不保证归因结论适用于未来；平台算法与流量变化会影响历史规律的参考价值。
- 删除账号为级联删除且不可恢复；CSV 导入为追加模式，重复导入同一份文件会产生重复条目，请按需核对。
