# PM 评估报告：独立创作者跨平台内容复盘与收益归因台

- 对应 innovator：innovator_002_创作归因台.md
- 评估日期：2026-10-20
- 结论：**可集成（新增）**

## 与 fangzi 现有功能去重与整合判定

遍历 `src/tools/` 全部 27 个工具，无任何工具面向"内容创作者多平台数据复盘与收益归因"。最接近的是：
- `household-finance`（家庭财务管家）：家庭收支记账/预算/报表，但**没有内容条目维度、没有平台/主题/形式标签、没有商单记录、没有 ROI 归因**。
- `subscription-audit`（账单订阅盘点）：导入微信/支付宝账单 CSV 识别自动续费，是"省钱"视角，不是"内容经营"视角。
- `gpu-data-viz`：通用数据可视化，不是业务工具。

**判定：不重复**。本工具是 fangzi 生活/工作工具矩阵中完全空白的"创作者经营"赛道，新开独立工具 `src/tools/creator-attribution/`。

## 需求真伪判断

真实。掘金 2025-10 引《2023自媒体运营数据管理白皮书》：管理 3 个以上平台的创作者 73% 每天花 1–3 小时手动同步数据，18% 因数据错漏导致策略误判；搜狐 2025-09 调研超 65% 自媒体人月收入低于 5000 元；agcstudio 2025-12 研究明确指出"目前没有任何工具能跨平台追踪内容归因"。新榜矩阵通、蚁小二等企业级工具年费数千元且重"分发"，面向粉丝 5 千–50 万独立小创作者的"本地优先、手动轻录入、聚焦归因决策"工具是空白。

## 技术可行性

纯前端可跑通，无后端：
- 发布台账、数据回收、商单记录全部用 IndexedDB（复用 `reusable-module/indexeddb-kv`）；
- CSV 导入：fangzi 已有 `fflate`、`mammoth`，CSV 解析用 PapaParse 或轻量手写（<100 行），不引重型依赖；
- 归因看板（按主题/形式/平台/时段四个维度的单位收益与 ROI）：纯 JS 聚合 + CSS/SVG 柱状图/折线图（复用 gpu-data-viz 的轻量图表经验，不引 ECharts 重型包）；
- 月度经营报告导出 Markdown（复用现有 export 模式）+ 可选 CSV；
- **不做自动 API 拉取**：小创作者拿不到抖音/小红书/B站开放平台 API 权限（需企业资质 + 审核），innovator 也明确"不强制 API 权限，手动/截图 OCR/CSV 导入"。这一点是纯前端降级的关键——完全不依赖云端。
- 截图 OCR：作为可选高级功能，首次按需从 hf-mirror 懒加载 TrOCR（Apache-2.0）或更轻的 ONNX 手写数字/文字模型，不打进主包；免费版降级为"手动录入 + CSV 导入"。

## 集成成本与侵入性

低。新开 `src/tools/creator-attribution/` 目录，按 fangzi 工具模板（manifest.ts + index.vue + lib/*.ts）实现；在工具注册表追加一项即可。不改现有任何工具、不改 Service Worker 全局配置、不改根路由。

## 架构兼容性

完全兼容 Vue3.5 + Pinia + vue-router。无新重型依赖。PWA 离线可用（台账录入与看板查看全部本地）。

## 平台合规评估

- EdgeOne Pages 免费版：纯静态，新增 chunk 约 80–150KB gz，单文件远小于 25MiB，总量合规。
- 不涉及插件商店、小程序、支付资质。创作者数据本地存储，无内容合规风险。
- **不做自动分发、不做平台 API 对接**，规避了抖音/小红书/B站开放平台的企业资质门槛与合规风险。

## 资金成本

零资金。纯前端本地实现；无第三方 API 费用。OCR 模型用 Apache-2.0 可商用开源模型（如 TrOCR-base 或更轻量的 ONNX 手写识别模型），从 hf-mirror 懒加载，不进主包。严禁 NC 授权模型。

## 时间成本与开发难度

预估独立开发者工时：**5–7 个工作日**。拆解：台账 CRUD + 多平台/主题/形式标签 1.5d；CSV 导入与数据对齐 1d；四维归因聚合 + 看板视图 2d；商单记录与报价参考 1d；月度报告导出 + 回归 1d。

## 用户真实价值

高。把每周 1–3 小时手动制表压缩到 20 分钟，归因看板直接导向"下周主攻什么主题、哪个平台值得投入、商单报多少"。对 fangzi 是新增高频人群（创作者），周使用频次高，带动订阅。

## 市场与竞争

企业矩阵工具（新榜/蚁小二）贵且重；剪映/千川是生产/投流工具，不做归因决策。独立小创作者本地优先归因台是空白。差异化：免费 + 隐私本地 + 聚焦"决策"而非"分发"。

## 盈利方式建议

freemium + 订阅，与 fangzi 现有工具档位对齐（99 元/年 ≈ 990 cents）。免费版：3 个账号 / 30 条内容 + 基础台账；专业版：无限账号 + 四维归因报表 + 商单报价库 + 月度报告导出 + CSV 批量导入。

## 结论与依据

**可集成（新增）**。无重复、纯前端 IndexedDB + CSV 可跑通、零资金、低侵入、EdgeOne 合规。补全 fangzi 在"创作者经营"赛道的空白。

## 实现规模与无人值守可行性初判

- **档位：M**（多场景链路、IndexedDB 多 store、CSV 解析、多维聚合；无 WebGPU/无 WASM/无本地大模型权重）。
- 是否依赖大权重：**否**（OCR 为可选懒加载，非主流程必需）。
- 预估工时：5–7 个工作日。
- 是否适合"一次性端到端做完"：**是**。主流程（台账→归因→报告）纯 CRUD + 聚合，无外部阻塞，适合无人值守端到端跑完；OCR 可作为二期可选。
