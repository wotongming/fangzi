# 功能建议：独立创作者跨平台内容复盘与收益归因台（发布台账→数据回收→归因→选题/商单决策）

- 序号：002
- 建议形态：网页应用（PWA，本地优先，数据存浏览器 IndexedDB；支持 CSV/手动录入导入）

## 使用场景
一个粉丝 1 万-50 万的**独立小创作者**（小红书博主、B站 UP、公众号作者、播客主、短视频素人），同时运营 3-5 个平台，靠流量分成 + 商单 + 带货变现。典型情境：
1. **触发**：每周复盘时，他要逐个打开抖音创作者中心、小红书专业号、B站后台、公众号后台、知乎后台，手抄/截图阅读量、播放量、收益金额，凑齐一张 Excel 表。
2. **处理**：5 个平台 5 套数据格式，收益规则还各不相同（抖音按播放分成、小红书按商单报价、公众号按流量主），手动整理一次周报复盘要 1-3 小时（掘金白皮书数据）；新榜/矩阵通这类企业级矩阵工具年费数千元，且重"分发"轻"小创作者的归因决策"，用不上也用不起。
3. **产出缺口**：他回答不了三个关键问题——"我哪类主题真正赚钱？""哪个平台的粉丝最值钱、最该重点经营？""下个月该接什么报价的商单？"。等发现某类内容收益下降时，已经错过调整窗口。
4. **后果**：65% 创作者月收入低于 5000 元，大量精力耗在手动制表而非内容本身。

## 功能描述
一个本地优先的"个人内容经营驾驶舱"：
1. **发布台账（内容资产库）**：每发一条内容，30 秒记录一条：平台、标题、主题标签、形式（图文/视频/播客）、发布时间、投入工时；支持批量 CSV 导入历史内容。
2. **数据回收轻录入**：各平台后台数据手动/截图 OCR 录入或 CSV 导入（阅读、播放、涨粉、分成收益、商单收入），自动按"内容条目"对齐，不强制要求 API 权限（小创作者拿不到平台 API）。
3. **收益归因看板**：自动算出"按主题 / 按形式 / 按平台 / 按发布时段"四个维度的单位收益与 ROI，回答"哪类内容真正赚钱"；标注一条内容在多平台的累计表现。
4. **选题与商单决策助手**：基于历史归因，给出"下周建议主攻的主题方向""各平台投入精力分配建议""近 30 天商单报价参考区间"；记录每条商单的金额、转化、复购率。
5. **月度经营报告**：一键导出"本月收入构成 +  TOP3 赚钱内容 + 下月策略"Markdown/图片，用于自己复盘或接商单时向品牌方展示数据。
6. **隐私本地存储**：账号经营数据存 IndexedDB，支持导出备份。

## 目标人群
- **画像**：粉丝 5 千-50 万的独立内容创作者、自由职业博主、小型 MCN 一人团队；年龄 20-35 岁，副业或全职做内容，月收入几百到几万不等，对"多赚 2000 元/月"高度敏感。
- **规模估计**：国内创作者经济参与者超 1 亿（微信公众号、抖音、小红书、B站、知乎、播客等），其中跨 3 平台以上运营的中腰部创作者数百万级；英文侧同样庞大。
- **付费意愿**：创作者为"直接带来收入的工具"付费意愿最强（千川投流、剪映会员、数据分析 SaaS 都是成熟消费）。本工具 15-25 元/月或 99 元/年，付费点：免费记 3 个账号/30 条内容，付费解锁无限账号、多维度归因报表、商单报价库、月度报告导出。

## 建议形态
网页应用 / PWA（手机录入 + 浏览器大屏看报表）。理由：
- 创作者复盘是"手机随时记 + 周末大屏整理"双场景，PWA 完美覆盖；
- 本地优先免注册，创作者最反感把账号数据交给陌生 SaaS；
- 不做自动分发（分发是新榜/蚁小二等红海且需平台权限），聚焦"复盘归因决策"这一空白环节。

## 落地价值
- **省时间**：把每周 1-3 小时手动制表压缩到 20 分钟，且减少数据错漏导致的误判（18% 因错漏策略误判）。
- **直接增收**：归因看板让创作者把精力从"不赚钱的平台/主题"转移到高 ROI 方向——来源案例中正确判断内容潜力可直接避免 5000 元无效投流。
- **市场空间**：企业级矩阵工具（新榜矩阵通、蚁小二）贵且重，面向小创作者的"本地优先、手动轻录入、聚焦归因决策"工具是空白；英文侧 agcstudio 研究也证实"无跨平台归因工具"。
- **多场景链路与付费空间**：触发（发布内容/周末复盘/接商单前）→ 处理（录台账、收数据、对齐条目）→ 产出（归因看板、主题/平台 ROI、月度经营报告）→ 后续决策（下周选题方向、精力分配、商单报价、是否加大某平台投入）。贯穿"创作—发布—回收—决策—再创作"完整经营闭环，周高频使用；延伸付费点：商单报价库订阅、品牌方数据报告模板、多成员小团队共享（未来）。

## 多场景链路与红海规避判断
- 是否同质化小工具：**否**。它不是"一键多平台分发器"或"单一数据表格"，而是贯穿"发布台账→数据回收→归因分析→选题/商单决策"的经营闭环。
- 多场景链路：发内容随手记台账（触发）→ 各平台数据轻录入对齐（处理）→ 输出主题/平台/时段 ROI 与月度报告（产出）→ 调整下周选题、平台精力分配、商单报价（后续决策）。
- 持续使用频次与付费空间：每周至少 1 次复盘、发布日天天录入，周高频；99 元/年相对月增收数千元的工具价值，付费转化顺理成章。
- 红海规避：自动分发（蚁小二/易媒）是红海且需平台 API 权限；企业矩阵（新榜）贵且面向公司。本工具定位"独立小创作者本地优先的归因决策台"，避开正面竞争。
