# 文件哈希校验器 · 用户指导

## 解决什么问题
下载安装包、插件压缩包后，通过对比 **MD5 / SHA-1 / SHA256 等指纹**，确认文件没有被篡改、也没有在传输中损坏。

## 怎么用
1. 点击选择文件，或直接把文件拖入虚线框。
2. 等待本机计算完成（大文件需要读入内存，请耐心等待）。
3. 得到 MD5、SHA-1、SHA-256、SHA-384、SHA-512 五个值，可逐个复制。
4. 把官网提供的校验值粘贴到「校验官方值」输入框：
   - 显示「校验一致」→ 文件完整可信；
   - 显示「不一致」→ **不要运行该文件**，请重新从官方渠道下载。

## 安全提示
- 只粘贴前 8 位以上哈希时按前缀匹配提示，最稳妥仍建议完整比对。
- 整个文件只在本机读取计算，不会上传。
- SHA-256 及以上使用浏览器 WebCrypto 加速；MD5 为内置兼容实现（仅用于校验，不用于安全加密）。
