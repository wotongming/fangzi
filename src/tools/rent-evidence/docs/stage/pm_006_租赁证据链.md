# PM 报告：2026-11-02 七项逐结论

## 逐项目结论

| # | 项目 | 结论 | 与现有工具去重 |
| --- | --- | --- | --- |
| 001 | 长辈用药协同台 | 可集成（重构升级 `home-medicine` 家庭药箱） | 现有 home-medicine 已做用药提醒/药箱；子女端微信级告警跨设备推送需后端，本轮仅作增强方向，不单独落地 |
| 002 | 隐形扣费退订管家 | 可集成（重构升级 `subscription-audit` 订阅审计） | 与 subscription-audit 高度重叠；账单自动归集/联网抓协议条款需后端与支付渠道授权，本轮不单独落地 |
| 003 | 多 Agent 导演台 | **不可集成** | 需监听本机并行编码 Agent CLI/跨进程 socket/聚合收件箱，纯前端 PWA 无法访问本机其它进程与文件系统，无后端不可行 |
| 004 | 长辈远程陪机 | **不可集成** | 需老人端守护 App 截屏上报、跨端实时通道、系统级转账页拦截；纯前端无后端不可行 |
| 005 | 毛孩子健康档案本 | 可集成（重构升级 `pet-health` 宠物健康） | 与 pet-health 重叠；OCR 化验单/跨院摘要可在其上增强，本轮不单独落地 |
| 006 | 小房东租赁证据链 | **✅ 可集成（新增独立顶层工具 rent-evidence，本轮编码）** | 现有 35 工具无租赁/押金/交接留痕类；receipt-vault 是收据 OCR、home-vault 是家庭档案、payment-chaser 是追款，均不重叠，真空白 |
| 007 | 家庭听说教练 | 不可集成 | 核心是儿童发音音素级打分，纯前端无 ASR 模型不可做；TTS 可做但打分闭环缺失 |

## 本轮自主选择

选 **006 小房东租赁证据链**：①与现有 35 工具 + 全部 mini-games 子游戏零重复；②纯浏览器本地可跑（拍照压缩、时间戳水印、IndexedDB、pdf-lib 导出均已在仓库验证过同类能力）；③M 档一次可做完；④移动端拍照/台账高频刚需。

## 集成口径
- 新增独立顶层工具 `rent-evidence`，verify:tools **35 → 36**（真独立，非硬凑子游戏）。
- 独立 IndexedDB 库 `fz-rent-evidence-v1`，不串任何既有存储键。
- 零新运行时依赖（pdf-lib 已在依赖中，MIT）。
