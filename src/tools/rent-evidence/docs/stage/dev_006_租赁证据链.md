# 开发拆解：租赁证据链（rent-evidence）

```
src/tools/rent-evidence/
  manifest.ts
  index.vue
  lib/model.ts      # 纯函数：责任初判/时间戳/证据汇总
  lib/store.ts      # IndexedDB fz-rent-evidence-v1
```

## 实现清单
1. model.ts 纯函数（node:test 覆盖）：classifyResponsibility 关键词初判、formatStamp 补零、summarizeEvidence 四段汇总（入住/退租/工单/台账）、CHECKLIST_ITEMS 预置项。
2. watermark.ts：最长边 960 缩放、底部 7% 黑条白字烧入 `yyyy-MM-dd HH:mm` + 截断备注。
3. index.vue 四 Tab：照片（入住/退租选择+清单位置+备注+capture 拍照）、工单（标题/描述/费用/多图，提交时自动 classify）、台账（押金/租金/维修/中介费）、导出（统计+下载 PDF）。
4. store.ts 三表 CRUD，删除前 confirm。
