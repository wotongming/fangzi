## 部署
EdgeOne Pages 经 GitCode push 触发既有流水线；chunk 走既有分包，不改 sw.js/manifest/webmanifest。

## 兼容性与数据
- 数据全部存 IndexedDB `fz-rent-evidence-v1`（photos/tickets/ledger 三表），删站/清站点数据会丢证据——README 与 UI 提示用户定期导出 PDF 备份。
- 照片以最长边 960px JPEG 0.82 存 dataURL，单条约 100–300KB；百张级仍远低于 5GiB 限额。
- 时间戳水印在拍照瞬间烧入，事后无法改图改时间（证据链可信的关键）。
