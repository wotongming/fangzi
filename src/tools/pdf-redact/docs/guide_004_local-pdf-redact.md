# PDF 真脱敏 使用指南

发合同、简历、账单前，把敏感信息（银行账号、身份证、薪资、手机号）抹掉。**真删文字层，不是画黑框**——导出后复制、搜索都拿不到原文。文件全程在你浏览器本地处理，绝不上传，原文件不会被修改。

## 用法
1. 选择一个 PDF。
2. 在页面预览上**拖拽框选**要抹掉的区域（点红块可移除）。
3. 点「导出真脱敏 PDF」，得到 `原文件名-redacted.pdf`。

## 真删 vs 涂黑框
Mac 预览/系统自带涂黑只是视觉遮罩，文字层仍在，对方另存/搜索能看到原文。本工具对**含遮罩的页做整页处理**，文字层随处理彻底删除，pdf.js 提取不到。

## 扫描件提示
若某页本就是扫描图片（无文字层），框选即按区域抹除像素，效果相同。

## 隐私
无后端、文件不离开设备；导出时 Author/Title/Creator/Producer 等元数据一并清空。
