# PM 评审 · 005 作业照片成册打印

**结论：可集成（干净新增，与 image-converter 区分），M 档，本轮仅设计、待点名编码。**

## 去重判定
image-converter 是通用图片格式转换/电商规格；本项是垂直链路"群里随手拍的作业照片→透视纠偏去影→A4 成册双面排版→按学科/日期归档→错题本"，场景与产出物不同，不重叠。

## 痛点真实性
央媒 2025-12 集中报道"老师拍照发群、家长连夜打印"，双职工家长每晚整理几十页是高频真实痛点。

## 政策逆风（如实评估）
教育部门正整治"电子作业让家长打印"。若严格落地，"打印作业"需求会被压缩；但短期（2025–2026）痛点仍高频，且即便政策落地，"整理/归档照片、错题本、成长记录"长尾需求仍在。定位上应**弱化"代打印作业"、强调"作业/试卷照片整理与错题归档"**，避免与政策正面冲撞，也更可持续。

## 技术
Canvas 本地透视纠偏/去阴影/增强（可复用 image-redraw），A4 成册排版后用浏览器打印或导 PDF；错题归档按学科/孩子分桶。纯前端、本地隐私。

## 变现
客单价低、靠量：免费清洗 10 张/月，买断 ¥15 解锁无限册/错题本/多孩子。
