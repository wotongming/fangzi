# 作业照片成册打印 · 使用指南（005）

把群里随手拍的作业、试卷照片整理成一册 A4：批量导入、旋转排好、选好每页几张和边距，本地预览分页后直接打印，或导出成 PDF 存档。**照片只在你本机浏览器处理，不上传、无账号、离线可用。**

## 它能做什么
1. **批量导入**：从相册一次选多张，或直接拍照；自动校正手机照片方向、压缩到适合打印的尺寸，不保留原始元数据。
2. **整理排序**：每张可顺时针旋转、左右调换顺序、加备注（学科/日期/错题）、删除。
3. **A4 排版**：纵向/横向、每页列数×行数、页边距、图间距、页眉标题，实时预览一共几页。
4. **打印成册**：走浏览器系统打印对话框，按预览分页输出；也可导出 150 DPI 成册 PDF 留存。
5. **本地保存**：本次导入的照片与排版配置存在本机 IndexedDB，关掉页面再打开仍在。

## 怎么用
1. 点「相册选择多张」选照片，或「拍照」现场拍。
2. 在「照片列表」里把方向歪的点「旋转」，顺序不对用 ← → 调换，不要的点「删除」，需要备注填学科/日期。
3. 在「排版设置」选方向、每页几张（列×行）、边距、间距，需要页眉就填标题。
4. 看「打印预览」确认页数和留白；点「打印成册」调系统打印，或「导出 PDF」存文件。

## 隐私与提示
- 照片全程本地处理，不经过任何服务器；导出的 PDF 由你自己决定发给谁。
- 本工具定位是「作业/试卷照片整理与归档」，不替代学校作业安排。
- 大图会自动降采样到最长边 1800px 以控制内存与文件体积；需要超高清原图请另存原件。

## 常见问题
- **打印出来方向反了**：在列表里点「旋转」到正确方向，预览确认后再打印。
- **想一页放更多张**：调大每页列数/行数；图片按比例缩放，不会被裁剪变形。
- **换浏览器照片还在吗**：本机 IndexedDB 按浏览器保存，换浏览器/清缓存会清空，重要内容请先导出 PDF。
