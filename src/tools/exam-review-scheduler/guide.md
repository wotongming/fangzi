# 备考错题调度 · 用户指导

版本 1.0.0 · 更新于 2026-10-20

## 这是什么 / 能做什么

一个纯本地、无后端的错题本 + 艾宾浩斯间隔复习调度工具。把考证 / 考研 / 考公中做错的题记进来（可拍照作为附件），根据你每天「记得 / 模糊 / 已忘」的自评，自动算出每道题下次该哪天复习，并按逾期紧急程度排成「今日复习队列」；同时用弱项热力图标出正确率最低的考点，用模考曲线追踪分数与目标分的差距。所有数据只存在你自己的浏览器里，不上传、不联网搜答案。

**重要边界**：本工具只管理你自录的错题，不联网搜答案、不内置任何机构题库或版权教材；报考 / 保弃决策看板只是固定模板文案，不构成报考建议。

## 快速开始

1. 首次进入为空态，点「建立第一个考试项目」，填写项目名（如「CPA-会计」）、考试日期、目标分数，点「建立项目」。
2. 进入「错题本」标签，点「＋ 录错题」，按 科目 → 章节 → 考点 三级填到最末级，填写题干，保存。
3. 到「今日」标签，对到期的题点「记得 / 模糊 / 已忘」自评，系统自动排下一次复习时间。
4. 用「弱项」看正确率最低的考点，用「模考」记录每次计时分数看曲线。

## 分步用法

### 1. 建立考试项目

- 免费版可建 **1 个项目**；新建第二个项目会触发专业版升级门。
- 项目名、考试日期、目标分数用于模考曲线的目标分虚线对照。

### 2. 录入错题（错题本）

- 三级标签（必选末级考点）：科目 → 章节 → 考点，三级都要填才能保存（如 会计 / 总论 / 存货）；标签会自动记忆，下次输入可下拉选择。
- 题干必填；错因 / 正解 / 来源选填，帮助复盘。
- 可拍照作为附件：图片自动压缩为长边 1600px 的 JPEG 并去除 EXIF / GPS 信息，免费版也可用。
- 免费版最多录 **50 道题**；第 51 道会触发专业版升级门。
- 拍照文字识别（OCR）为实验能力、暂未开放，当前拍照后请手动录入题干。

### 3. 今日复习队列与三键自评

- 新题默认明天到期；到「今日」标签，到期的题按**逾期越久越靠前**排列。
- **记得**（绿）：连续答对次数 +1，间隔按艾宾浩斯序列递进（1→2→4→7→15 天，之后按难度系数滚动增长）。
- **模糊**（黄）：间隔小幅推进。
- **已忘**（红）：连续答对归零，间隔回到 1 天，明天重背。

### 4. 弱项热力图

- 进入「弱项」标签，按考点聚合正确率：红色 = 正确率低于 50% 重点补；黄色 = 50%–70%；绿色 = 高于 70% 已掌握。

### 5. 模考记录与分数曲线

- 进入「模考」标签，录入每次模考的日期、科目、得分、满分；曲线画出分数走势，并用目标分虚线标出与目标的差距。
- 「报考 / 保弃决策看板」为专业版，提供固定模板文案与免责声明，不替你决定是否报考。

### 6. 提醒、日历与备份

- 今日待复习题数显示在标签角标上。
- 系统通知：授权后可在到期时收到浏览器通知，但仅在应用打开期间生效。
- 「导出到系统日历（.ics）」：把今日复习计划导入手机 / 电脑系统日历，作为长期可靠提醒的兜底。
- 全库导出 / 导入 JSON 备份为专业版：换机 / 重装时导入，按 id 去重合并，不覆盖本机更新数据。

## 数据与隐私

- 错题、复习记录、模考成绩与照片全部保存在本机 IndexedDB，不上传、不联网；照片去除拍摄位置等元数据。
- 清理浏览器站点数据会删除全部记录，请定期在「我的」导出 JSON 备份；换浏览器 / 设备需用导出导入迁移。

## 常见问题

- **录的题会丢吗？** 数据存在浏览器 IndexedDB，断网刷新仍在；但清理站点数据会删除，请定期导出备份。
- **为什么新录的题今天没出现在「今日」？** 新题默认明天到期，由调度引擎自动排期。
- **拍照会泄露我的位置吗？** 不会，照片经 Canvas 重绘为 JPEG，EXIF（含 GPS）被丢弃。
- **能帮我搜这道题的答案吗？** 不能，本工具不联网搜答案、不内置题库。

## 注意事项 / 功能边界

- 本工具不提供搜答案，不内置 / 抓取任何机构题库、教材或出版社版权内容，只管理用户自录错题。
- 报考 / 保弃看板为固定模板文案，不构成报考或弃考建议，一切以官方招生简章与你自己的判断为准。
- 间隔节奏基于艾宾浩斯序列的通用参数，个人记忆规律不同，请结合自评灵活使用。
