## 模块设计

### IndexedDB 数据模型（dbName: `fangzi-exam-review`，version 1）

```ts
// store: projects  keyPath='id'
interface Project {
  id: string;            // crypto.randomUUID()
  name: string;          // 如 "CPA-会计 2026"
  examDate: string;      // 'YYYY-MM-DD'，决策看板用
  targetScore: number;   // 百分制目标分
  createdAt: number;
  tags: TagNode[];       // 三级标签树
}
interface TagNode { subject: string; chapters: { name: string; points: string[] }[] }

// store: questions  keyPath='id'  索引: ['projectId','projectId'],['nextReview','nextReview']
interface Question {
  id: string;
  projectId: string;
  stem: string;          // 题干（用户自录）
  wrongCause: string;    // 错因
  answer: string;        // 正解
  source: string;        // 来源（纸质书/PDF/网课，自由文本，不抓取机构题库）
  pointPath: { subject: string; chapter: string; point: string };
  photoBlob?: Blob;      // image-redraw 压缩后
  // 调度状态（SM-2）
  ease: number;          // 初始 2.5
  intervalDays: number;  // 当前间隔，起步 1
  reps: number;          // 连续答对次数
  nextReview: string;    // 'YYYY-MM-DD'（本地日历日）
  createdAt: number;
}

// store: reviews  keyPath='id'  索引: ['questionId','questionId'],['ts','ts']
interface ReviewLog { id: string; questionId: string; ts: number; grade: 1|3|5; intervalAfter: number }

// store: mockExams  keyPath='id'  索引: ['projectId','projectId'],['date','date']
interface MockExam {
  id: string; projectId: string; date: string;
  subject: string; score: number; fullScore: number; minutes: number; note?: string;
}
```

### 数据流

```
录入 → store.put(question, 调度初值) → 打开队列 → queue() 筛 nextReview<=today
 → 自评 grade → scheduler.next(nextReview, ease, interval, grade) → 更新 question
 → weakness()/curve() 每次视图进入时从 questions+reviews+mockExams 纯计算（不落库派生表）
```

## 关键实现方法

### SM-2 变体调度引擎（lib/scheduler.ts 核心伪代码）

```ts
const STEPS = [1, 2, 4, 7, 15]            // 艾宾浩斯基准间隔（天）
export function scheduleNext(q: Question, grade: 1 | 3 | 5, today: string): string {
  if (grade < 3) {                          // 已忘：回到第 1 天
    q.reps = 0; q.intervalDays = 1; q.ease = Math.max(1.3, q.ease - 0.2);
  } else {
    q.reps += 1;
    if (q.reps === 1) q.intervalDays = STEPS[0];
    else if (q.reps === 2) q.intervalDays = STEPS[1];
    else if (q.reps === 3) q.intervalDays = STEPS[2];
    else if (q.reps === 4) q.intervalDays = STEPS[3];
    else q.intervalDays = Math.round((q.reps <= 5 ? STEPS[4] : q.intervalDays) * q.ease * (grade === 5 ? 1.3 : 1.0));
    q.ease = Math.max(1.3, q.ease + (grade === 5 ? 0.15 : -0.1));
  }
  return addDays(today, q.intervalDays);    // 本地日历日 + 整数天差（避免时区漂移）
}
```

### 今日队列

```ts
export function dueToday(qs: Question[], today: string): Question[] {
  return qs.filter(q => q.nextReview <= today)
           .sort((a, b) => dayDiff(a.nextReview, today) - dayDiff(b.nextReview, today)); // 逾期越久越靠前
}
```

### 弱项聚合 / 模考曲线 / .ics

- weakness：Map<pointKey, {total, hits, wrongCount}>，正确率 = hits/(hits+wrong)；空考点不展示。
- curve：SVG 折线把 N 个点映射到 viewBox 800×300；目标分画水平虚线。
- .ics：`BEGIN:VCALENDAR…VEVENT;DTSTART=20261021T090000;VALARM TRIGGER:-P1D…END:VCALENDAR` 手写字符串（复用 home-medicine/lib/notify.ts 同款）。
