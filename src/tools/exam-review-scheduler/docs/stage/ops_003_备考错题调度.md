# 部署运维指引：在职备考个人错题与弱项调度系统（备考错题调度）

- 对应 architect：architect_003_备考错题调度.md
- 编写日期：2026-10-20
- 工具位置：`src/tools/exam-review-scheduler/`，随 fangzi 主站整体静态部署

## 部署架构与环境准备

无后端、无数据库服务、无插件商店：本工具是 fangzi PWA 内一个自动发现的静态工具模块，全部计算与数据在用户浏览器本地完成（IndexedDB `fangzi-exam-review`）。部署形态 = fangzi 站点本身的静态托管（腾讯云 EdgeOne Pages 免费版），本工具不产生任何独立服务端进程、环境变量或密钥。

```
Git main 分支 push → EdgeOne Pages 自动构建（npm ci && npm run build）→ dist/ 静态发布 → CDN
用户浏览器 → 加载应用外壳（SW 预缓存）→ 离线后仍可打开本工具与历史数据
```

## 软硬件配置清单

| 项 | 配置 |
| --- | --- |
| 构建机 | EdgeOne Pages 托管构建环境（Node ≥20.19，平台提供，无需自备） |
| 运行依赖 | 用户浏览器（Chrome/Edge/Firefox/Safari 近 2 年版本）；IndexedDB 可用 |
| 存储 | 用户本机浏览器 IndexedDB（容量随浏览器策略，通常 ≥50% 磁盘配额） |
| 限额自查 | 本工具新增 chunk 预估 60–120KB gz、零大资产；站级 dist 约 131MiB/130+ 文件/最大单文件 22.9MiB，均在 EdgeOne 免费版限额（5GiB / 20000 文件 / 25MiB）内 |

## 部署步骤

1. 开发者本地完成质量门（`npm test` / `vue-tsc --noEmit` / `verify:tools` / `npm run build`）。
2. MR 合入 `main`（GitCode `git@gitcode.com:m0_45688211/fangzi.git`）。
3. EdgeOne Pages 绑定仓库后监听 main 推送自动构建发布；首次/变更后人工访问线上地址，搜索"错题"命中工具页，跑一遍主流程冒烟。
4. OCR 模型不在构建产物内：首次用户点击"拍照识别"时从 hf-mirror 懒加载，由 SW 缓存——无需运维介入；若 hf-mirror 故障，降级手动录入，不阻塞主流程。

## 配置项说明

无环境变量、无密钥、无服务端配置。计费沿用框架默认 `LocalMockProvider`；若未来配置 `VITE_BILLING_ENDPOINT`，本工具自动切换真实支付，无需改动代码。

## 上线/灰度方案

- 静态站天然"全量即灰度"：上线后观察 1–2 周用户反馈邮箱（fangziasia@163.com）与线上冒烟结果即可。
- 回滚触发条件：工具页 JS 报错、搜索命中异常、构建后站级 chunk 体积异常增长。
- 回滚操作：`git revert <本工具合入 commit>` → 重推 main → EdgeOne 重新构建。因工具目录随 revert 消失、自动发现机制不再注册路由，工具即整体下架，其它 27 个工具不受任何影响；用户本地已录数据存于 IndexedDB，工具下架后数据不被删除（重新上线后仍在）。

## 平台对接指南

- **EdgeOne Pages**：仅需将 fangzi 仓库绑定为 Pages 项目、构建命令 `npm run build`、输出目录 `dist`；HTTPS 由平台默认签发；自定义域名在 Pages 控制台一键配置（非必需）。本工具不涉及任何额外对接。
- **无插件商店、无应用市场、无支付平台对接**（LocalMockProvider 阶段前端不接触支付密钥）。

## 运维监控指标与告警

无服务端可监控。需人工/半自动关注的三项：

1. `npm run verify:tools` 工具计数（应随新工具正确变化，CI 失败即告警）。
2. 反馈邮箱来信中本工具相关条目（每周扫一次）。
3. EdgeOne Pages 构建失败通知（平台邮件/控制台）。

## 日志管理

无服务端日志。用户端问题排查指引写进 `guide.md`：硬刷新、检查浏览器隐私模式是否禁用 IndexedDB（隐私模式下数据不持久）、导出备份 JSON 路径。

## 备份与容灾

- **用户侧**：工具内"导出备份"（全库 JSON 下载）建议用户换机/清缓存前执行；导入按 id 去重合并。
- **项目侧**：代码与文档随 GitCode 仓库版本管理，天然有历史。
- 无云端数据需备份——这是本工具的隐私设计（数据不出端）。

## 常见故障排查与回滚预案

| 故障 | 排查 | 处理 |
| --- | --- | --- |
| 工具页打开白屏 | 控制台报错堆栈；多半是某 chunk 引用错误 | 本地 `build+preview` 复现，修后重推；紧急则 revert 下架 |
| 刷新后数据丢失 | 用户是否用隐私模式；IndexedDB 是否被浏览器自动清理 | guide 提示导出备份；代码无需改 |
| 今日队列不更新 | 日期边界（nextReview 用本地日历日） | 单测补边界用例后重发 |
| OCR 下载失败 | hf-mirror 网络/大小文件超时 | 提示手动录入；模型源切换列 V1.1 |
| 上线后想快速撤下 | 自动发现机制：删除目录即下架 | revert 对应提交重推 main，不影响主站与其它工具 |
