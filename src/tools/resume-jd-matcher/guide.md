# 简历×JD本地匹配与定向优化器 · 用户指导

版本 1.0.0 · 更新于 2026-10-16

## 这是什么 / 能做什么

投简历前，把你的简历和招聘 JD 都留在本机：自动抽取技能并核对学历 / 年限 / 地点 / 证书硬门槛，给出 0–100 匹配分、命中与缺失清单；专业版提供只基于你本人真实经历的可溯源改写建议、中英文求职信草稿，并管理本地投递看板。全程离线解析、不上传任何内容，支持 Markdown / PDF / CSV 导出。

**重要边界**：打分与建议基于关键词 / 同义词规则（离线确定性算法），结果仅供参考，不作录用承诺；工具不会为你没有的经历编造内容。

## 快速开始

1. 进入「我的简历」，导入 PDF / Word / TXT 简历，或直接粘贴简历全文；可点「保存为简历版本」多版并存。
2. 切到「匹配诊断」，填公司 / 岗位名（选填），粘贴 JD 原文，点「开始本地匹配」。
3. 查看综合匹配分、硬门槛核对、命中与待补强清单。
4. 专业版可查看改写建议、生成求职信、把岗位加入投递看板。

## 分步用法

### 1. 准备并保存简历

- 导入 PDF（文字版）/ DOCX / TXT / MD，单文件 ≤15MB；也可直接把简历全文粘贴到大文本框（建议包含教育经历、工作年限、期望城市、技能清单与项目 / 工作经历，识别更准）。
- 可点「保存为简历版本」，把多版简历存在本机随时切换；下方显示从简历识别到的技能。
- 扫描件 / 纯图片 PDF 无法提取文字，请改用文字版 PDF 或直接粘贴；旧版 `.doc` 请另存为 `.docx`。

### 2. 粘贴 JD 并本地匹配

- 在「匹配诊断」填公司 / 岗位名（选填，用于求职信与看板），粘贴 JD 原文，点「开始本地匹配」。
- 结果含：综合匹配分（0–100）与三维（技能匹配 / 职责经验 / 资质素质）命中情况；硬门槛核对（学历、年限、工作地点、证书逐条 ✓/✗）；各维度命中 / 待补强关键词清单。
- 任一硬门槛不满足，综合分自动封顶在 59，并给出醒目提示。
- 免费版每次匹配计入当月免费次数（顶部显示「本月已用 x/5 次」）。

### 3. 可溯源改写建议（专业版）

- 当你其实具备某能力、但简历只写了同义词或版本别名、没写 JD 用的标准名时（例如简历写「vue3」「js」，JD 写「Vue」「JavaScript」），工具给出建议并精确定位到简历原文段落，提示在不改变事实的前提下补全标准名，便于 ATS / HR 关键词检索。
- 工具不会为你没有的经历编造内容；真正缺失的能力请据实判断是否投递，切勿虚构。

### 4. 生成中英文求职信（专业版）

- 在「求职信」填称呼、选中文 / English，点「根据匹配结果生成」。信件只使用岗位 / 公司槽位 + 匹配命中的技能 + 从你简历中匹配到的真实经历要点。
- 生成后可直接在文本框修改，并「导出 Markdown」或「打印 / 另存为 PDF」。

### 5. 投递看板与导出（专业版）

- 在匹配结果页点「加入投递看板」，记录公司、岗位、匹配分；在看板用下拉流转状态（待投递 / 已投递 / 面试中 / Offer / 已拒绝），可按状态筛选，并一键导出带 BOM 的 CSV（Excel 打开中文不乱码）。

- 专业版（一次买断 ¥29.90）：不限岗位数量，解锁技能 / 职责 / 资质三维诊断；基于本人经历的可溯源改写建议（不虚构）；中英文求职信草稿生成与编辑导出；投递看板（状态流转 / 跟进提醒）与 CSV 导出。

## 数据与隐私

- 解析、匹配、求职信、看板全部在本机完成，简历与记录只存在本浏览器（IndexedDB / LocalStorage），不上传。
- 清理浏览器站点数据会同时删除本地简历与看板记录，重要内容请用 Markdown / CSV 导出留存；在公共电脑使用后及时清理站点数据。

## 常见问题

- **PDF 提示「未能提取到文字」？** 多半是扫描件 / 图片版 PDF，请用文字版 PDF 或直接粘贴正文。
- **`.doc` 旧格式无法导入？** 在 Word / WPS 另存为 `.docx`，或粘贴文本。
- **明明会某项技能却出现在「补标准名」建议里？** 简历写的是别名 / 版本号，建议补招聘方常用标准名，能力已计入匹配分，这里只优化关键词命中。
- **匹配分高就一定能拿到面试吗？** 分数只帮你快速发现差距和硬门槛缺口，不作录用承诺。

## 注意事项 / 功能边界

- 简历含姓名、电话等个人信息，请在自己的设备上使用。
- 本期为离线关键词 / 同义词规则匹配，语义级匹配列入后续版本；结果仅供参考。
