# 功能建议：简历 × 招聘 JD 本地匹配与定向优化器

- 序号：001
- 建议形态：网页应用（PWA，纯前端 + 浏览器本地 AI）

## 需求来源
求职市场中“按每一条 JD 定制简历、过 ATS 关键词筛选”是被反复验证的刚需，相关工具付费区间集中且持续：Jobscan/Huntr/FastApply/LoopCV/LazyApply 等月费约 9.9–50 美元、年付 99–999 美元（检索词「resume tailoring job description keyword match tool 2026 ATS」）。
- EasyResume《5 Best Tools to Match Resume to a Job Description》（2026-02）：https://www.easyresume.online/blog/best-job-description-match-tools
- bestjobfinder《Best AI Job Search Tools 2026》（付费 $14.9–50/月）：https://www.bestjobfinder.net/blog/best-ai-job-search-tools
- Jobscan《Best AI Job Search Tools》：https://www.jobscan.co/blog/ai-job-search-tools/
- Huntr《5 Best AI Resume Tailor 2026》（语义匹配是核心卖点）：https://huntr.co/blog/best-resume-tailor
- FastApply《10 Best AI Resume Tailoring Tools 2026》：https://blog.fastapply.co/best-ai-resume-tailoring-tools-2026
痛点另一面：这些产品全部是**云端 SaaS**，要求把完整简历（含真实姓名、电话、住址、工作经历）上传到第三方；国内求职者还面临访问不稳、英文站为主、按订阅收费、投递季过后闲置等问题。同期“浏览器本地 AI / 不上传隐私”趋势明确（检索词「local-first AI browser privacy 2026」：TraceMind、SaaSBrowser.ai 108 个本地工具等）。

## 使用场景
谁：正在找工作/换工作的人（应届生、3–10 年经验跳槽者、出海求职的中文/双语用户），以及帮多人改简历的职业规划师/猎头助理。
时机：在 BOSS 直聘、拉勾、猎聘、LinkedIn、公司官网看到一个心仪岗位，准备投递前。
问题：通用简历海投回复率低；逐条手改简历要反复对照 JD 找关键词、调措辞、写求职信，一份 20–40 分钟；用云端工具又担心隐私、要付订阅、英文站不顺手。

## 功能描述
1. 本地导入简历（PDF/DOCX/TXT/粘贴），解析为结构化经历；可存多个简历版本到 IndexedDB。
2. 粘贴/拖入 JD（文本或截图，截图走本地 OCR）。
3. 本地语义+关键词双通道匹配：技能/职责/资质四维对齐，输出匹配分、命中/缺失关键词清单、硬门槛（学历/年限/地点）核对。
4. 逐条“可采纳/忽略”的改写建议：把缺失但本人确实具备的能力自然补进要点，给出改写前后对照（不虚构经历）。
5. 针对该岗位生成求职信/自荐语草稿；按 ATS 排版规范提示（表格、双栏、特殊字体风险）。
6. 投递追踪看板：公司/岗位/匹配分/状态/时间/下次跟进，本地保存。
7. 全程离线可用（模型首次加载后），数据不出设备，可导出 Markdown/PDF。

## 目标人群
画像：每年有数周到数月处于求职状态的劳动者；中国 + 出海双语求职者；职业规划师（高频、多客户）。规模：仅中国每年高校毕业生超千万，加上社招跳槽，求职人群以亿计；愿为“提高面试邀约率”付费的人群在数千万量级。付费意愿：已有成熟付费市场（$10–50/月）证明购买意愿；本方案以“买断 + 投递季包月”低价切入，降低决策门槛。

## 建议形态
纯前端 PWA。理由：①简历/JD 属高隐私数据，本地处理是核心卖点与差异；②求职者多在个人电脑/手机网页上操作，免安装、即开即用；③无后端可零成本维护，买断可行；④需要一定算力做本地嵌入匹配，复用站内已有本地 AI/WASM 能力可快速落地。

## 落地价值
解决问题：把每份简历定制时间从 20–40 分钟压到 3–5 分钟，并显著降低“关键词不匹配被 ATS 刷掉”的概率；同时消除隐私与订阅顾虑。市场空间：对标海外月费 10–50 美元的成熟品类，用一次性 ¥39–99 买断 / 投递季 ¥9.9 包月覆盖价格敏感人群。盈利点：freemium（每月免费匹配 N 个岗位）→ 买断解锁不限岗位与本地 AI 高级改写；职业规划师多席位/批量授权。

## 多场景链路与红海规避判断
- 是否同质化小工具：否。不是单一“关键词查重”，而是“简历资产→多个 JD→匹配诊断→定向改写→求职信→投递追踪→复盘”的完整求职链路平台。
- 多场景链路：触发（看到岗位）→ 处理（本地解析+匹配+改写）→ 产出（定制简历/求职信）→ 后续动作（投递、看板追踪、按回复率复盘、迭代简历母版）。
- 持续使用频次与付费空间：求职期内每天多次、持续数周到数月；可延伸求职信、面试题库匹配、薪资谈判记录、职业规划师工作台等付费场景。
- 红海规避：海外 Jobscan/Huntr 强但全云端、订阅、英文为主；国内多为云端简历编辑器或大厂招聘附属，缺乏“纯本地隐私 + 双语 + 买断 + 投递追踪”的组合。差异化空间在隐私、价格模型与双语/本地化，非正面功能堆叠竞争。
