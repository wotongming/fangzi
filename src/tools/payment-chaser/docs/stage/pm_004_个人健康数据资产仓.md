## 真实痛点与时机

## 技术风险（如实标注）
**多厂商导出格式碎片化是主要成本**：Apple Health XML（大、嵌套）、Fitbit/Withings zip 多 CSV、华为/小米私有 JSON、Garmin zip。解析器每加一厂商都是一次适配与回归，M~H 档。
- 首版建议只稳定支持：Apple Health XML（步数/心率/睡眠）+ 通用 Fitbit 风格 CSV；其余厂商在 UI 明确标注"实验性/待适配"，不承诺。
- 大 XML/zip 解析可用 Web Worker（复用 worker-post）+ fflate（已有）；趋势图用轻量 canvas/SVG，不引重型图表库。
- 健康数据极敏感，全程本地、IDB 长期累积；就诊 PDF 报告参考 payment-chaser 的 canvas 栅格化方案。
