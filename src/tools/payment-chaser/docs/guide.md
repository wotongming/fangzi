# 自由职业追款助手 · 使用指南

面向设计师、程序员、翻译、摄影师、一人公司：把"客户欠的尾款"从"不好意思催、催了没记录、投诉没证据"变成一条闭环。**所有数据只存在你本机浏览器，不上传、无账号、离线可用。**

## 它能做什么
1. **应收台账**：录入客户、项目、金额、约定付款日，自动算逾期天数。
2. **账龄/现金流看板**：按 0–30 / 30–60 / 60–90 / 90+ 天分桶，一眼看清外面压了多少钱、哪些已疑似坏账。
3. **梯度催收话术**：按逾期天数自动给三档文案——1–7 天礼貌提醒、8–29 天正式催告、30 天以上最后通牒，一键复制为微信/邮件。
4. **沟通留痕时间线**：每次催收（微信/电话/邮件/面访）记一笔，连对方回应一起存档。
5. **证据包导出**：一键导出 PDF（事实、金额、账龄、催收时间线、合计）与 CSV/JSON，用于投诉或起诉。
6. **维权入口指引**：全国违约拖欠中小企业款项投诉平台（sme-dj.miit.gov.cn）、12315。

## 怎么用
1. 在「新增一笔应收」填客户、项目、金额、约定付款日，点「入账」。
2. 看「账龄/现金流看板」，红色为逾期，90+ 天建议尽快升级投诉。
3. 对某笔点「生成话术」，按逾期天数自动选档，点「复制话术」发给客户。
4. 每次沟通后在该笔下「留痕」：选方式、写说了什么、对方怎么回。
5. 需要投诉/起诉时点「导出证据包 PDF」，连同合同/发票/交付记录一起留存。
