# 正则表达式测试器 · 用户指导

## 解决什么问题
实时验证正则表达式是否符合预期，**高亮所有匹配、列出捕获分组**，并提供常用模板，避免正则「写出来不敢确定对不对」。

## 怎么用
1. 在顶部输入正则（不含两侧 `/`），用复选框选择标志位 `g/i/m/s/u`。
2. 在「测试文本」中粘贴待匹配内容，匹配处会黄色高亮，并显示匹配数量。
3. 表格中查看每一处匹配的位置、完整文本与捕获分组。
4. 需要替换时在底部填写替换文本，支持 `$1` 等分组引用。
5. 「常用模板」一键填入手机号、邮箱、身份证、URL、IPv4、日期等规则。

## 边界与提示
- 零宽匹配（如 `a*`）已做防护，不会卡死页面；匹配上限 10 万处。
- 模板是通用校验口径，身份证等场景如需严格校验地区码/校验位，请在业务代码中进一步处理。
- 文本仅在本地处理。
