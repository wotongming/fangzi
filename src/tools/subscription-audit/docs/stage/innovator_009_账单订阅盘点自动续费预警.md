## 使用场景
用户在视频/音乐/网盘/健身/学习/云存储/各类"首月1元试用"上开通了大量自动续费，分散在微信、支付宝两个入口，平时无感、想不起来、逐个翻查麻烦，年底一算白交上千元；想系统盘点"我到底在为哪些订阅付钱、哪些没用、下次什么时候扣、总共多少"。痛点链路：从微信/支付宝导出账单 CSV → 本地解析识别周期性/订阅类扣费 → 汇总订阅清单与年度成本 → 标记"疑似闲置/重复/涨价" → 生成取消指引与下次扣费预警 → 制定续费/退订决策并跟踪。

## 功能描述
- 导入微信支付/支付宝官方导出的账单 CSV（可多份、多月、含压缩包解压），本地解析交易对手、金额、时间、收支方向；提供各平台导出步骤指引。
- 自动识别订阅与周期性扣费：同一商户按近似金额、近似周期（月/季/年）重复出现即判定为订阅，列出名称、周期、单价、最近/下次扣费日、累计金额。
- 风险与省钱标注：疑似闲置（长期未在其它记录出现使用迹象）、重复同类会员（多个视频会员）、涨价（同订阅金额上升）、试用期临近转正；给出一年/三年累计支出与"取消可省 X 元"。
- 每个订阅附对应平台解约入口指引（微信/支付宝路径直达链接），可标记"保留/取消/观望"，生成待办与下次扣费前提醒（系统通知 + .ics）。
- 支出结构概览（按商户/类别/月）与账单去重；全程本地解析，不上传财务数据，可导出报告。

## 目标人群
订阅多的年轻用户、数字内容/工具重度消费者、家庭财务管理者、想省钱的学生与上班族。覆盖面广、复盘频次为每月/每季度，且每年续费季强需求。付费理由：直接算出可省金额（常达数百到上千元/年），投入产出比极高；愿为多账户合并、长期趋势、提醒跟踪、报告导出付小额费用。

## 建议形态
微信/支付宝账单是高度敏感的财务数据，"绝不上传"是核心信任点，纯前端 CSV 解析 + IndexedDB 的网页/PWA 最契合；电脑上导出账单后批量导入分析体验最好，手机查看预警为辅，打开即用、无注册。

## 落地价值
- 直接省钱：把分散无感的订阅集中暴露，取消闲置/重复项，一年常见可省数百至上千元。
- 省时：替代在微信/支付宝两个入口逐个翻协议、手工记账。
- 盈利点：freemium（单份账单、基础订阅识别免费）+ 买断/订阅解锁多月多账户合并、年度趋势、闲置/涨价智能判定、扣费提醒与取消待办、报告导出。

## 多场景链路与红海规避判断
- 是否同质化小工具：否（不是单一记账或金额换算，而是"导账单→识别订阅→算总账→标注闲置/重复/涨价→取消指引+预警→跟踪决策"的省钱链路）。
- 多场景链路：导出→解析→发现→决策→取消/续费→后续提醒，贯穿订阅生命周期。
- 持续使用频次与付费空间：月度/季度复盘 + 续费季高频；直接对应可省现金，付费转化理由强。
- 红海规避：平台只给"解约入口"不做跨平台账单聚合与成本分析；通用记账 App 要长期手动记、门槛高。一次性导入账单即可自动盘点订阅、本地隐私的轻量工具存在明显空白。
