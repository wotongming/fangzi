# 部署运维指引：账单订阅盘点与自动续费本地预警（subscription-audit）

- 对应 architect：architect_009_账单订阅盘点自动续费预警.md
- 编写日期：2026-10-17

## 部署架构与环境准备

纯静态 PWA 工具，无后端、无数据库服务端、无环境变量、无密钥。所有账单解析、聚类、存储在用户浏览器本地完成（IndexedDB）。随 fangzi 主站部署于腾讯云 EdgeOne Pages，push `main` 自动构建发布。

## 软硬件配置清单

- 托管：EdgeOne Pages 免费版（存量项目，沿用）。
- 构建：Node 18+/npm（仓库既定）。
- 运行端：现代浏览器（需支持 TextDecoder('gbk')、IndexedDB、Worker；Chrome/Edge 90+、Safari 15+、Firefox 90+）。
- 无新增服务、无新增 npm 依赖。

## 部署步骤

1. 本地通过质量门（vue-tsc / 单测 / build / verify:tools / E2E）。
2. `git add` 显式列路径（工具目录、两个 reusable-module、README、手册、测试、E2E 脚本）。
3. commit 注明 subscription-audit 与日期，`git push origin HEAD:main`。
4. EdgeOne 监听 main 自动构建发布；线上地址 `https://www.fangzi.asia/#/t/subscription-audit`。
5. 发布后用线上 URL 做一次冒烟：打开工具、查看导出指引、（可选）导入自造样例确认无报错。

## 配置项说明

无运行时环境变量。可调常量集中在 `lib/subscriptions.ts`（金额容差、CV 阈值、周期天数区间、闲置倍数、涨价比例），后续平台版式变化时只需更新 `lib/platforms.ts` 列名候选。

## 上线 / 灰度方案

静态站点无灰度体系，随 main 全量；新工具为独立目录与独立路由，不影响其它工具入口。先在自测环境（vite preview）与线上各冒烟一次。

## 平台对接指南

- **EdgeOne Pages**：沿用现有 Git 接入，无需新建项目或改配置；单文件 <25MiB、文件数与总容量在免费额度内（本工具无大资产）。
- **微信支付 / 支付宝**：本工具**不接入其开放平台、不申请资质、不调用接口、不做自动解约**。仅在“解约指引”中提供用户手动操作路径与公开帮助中心链接：
  - 微信：我 → 服务 → 钱包 → 支付设置 → 自动续费 / 免密支付（腾讯客服/微信支付帮助中心公开说明页）。
  - 支付宝：我的 → 设置（齿轮）→ 支付设置 → 免密支付/自动扣款（支付宝服务中心公开帮助页）。
  - 因不涉及数据抓取与代操作，无金融/支付合规资质要求；所有解约动作由用户本人在官方客户端完成。
- **系统日历 / 通知**：`.ics` 通过 Blob 下载交给用户本地日历 App；Notification 仅用浏览器原生权限，无需任何第三方推送服务（不接 Web Push，故不依赖 push 服务器/VAPID）。

## 运维监控指标与告警

静态资源监控沿用站点；本工具无服务端指标。关注：前端错误上报（若站点已接入）中与该路由相关的解析异常；可据反馈迭代平台列名映射。无独立告警。

## 日志管理

不采集、不上传账单数据；代码中不向 console 输出交易明细。Worker/解析错误仅在页面本地提示。

## 备份与容灾

- 用户数据仅在本机 IndexedDB；清理浏览器数据即清除（隐私优先，不做云备份）。
- 报告/日历由用户主动导出（CSV/.ics）自行保存。
- 站点回滚：`git revert` 该工具提交并重新 push；因独立目录，回滚不影响其它工具。

## 常见故障排查与回滚预案

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 提示“未识别账单格式” | 平台改版/选错文件 | 按页内指引导出标准 CSV；更新 platforms.ts 列名候选后发布 |
| 中文乱码 | 非 UTF-8/GBK 编码 | 已做 BOM+gbk 回退；仍异常时提示另存 UTF-8 |
| 识别出的订阅偏少/偏多 | 金额或周期不规律 | 用户手动合并/拆分/改周期/忽略，override 持久化 |
| 通知没弹出 | 未授权/页面已关闭 | 引导授权；长期提醒改用导出的 .ics |
| 大账单卡顿 | Worker 不可用回退主线程 | 已分批解析；建议按月拆分导入 |

**功能回滚**：删除路由入口即下线（独立目录 + manifest 移除即可，registry 自动发现会随之不再列出）；不影响 Service Worker 主清单与其它工具。
