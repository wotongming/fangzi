## 模块设计与接口约定

```ts
type Platform = 'wechat' | 'alipay' | 'unknown'
interface TxRecord { id:string; platform:Platform; account?:string; time:number; // epoch ms
  merchant:string; amountCents:number; // 支出为正
  direction:'expense'|'income'; orderNo?:string; raw:string[] }
type Cadence = 'monthly'|'quarterly'|'semiannual'|'yearly'
interface Subscription { id:string; merchant:string; displayName:string; platform:Platform;
  cadence:Cadence; priceCents:number; count:number; firstAt:number; lastAt:number;
  avgGapDays:number; nextAt:number; annualCents:number; totalCents:number;
  flags:('price-up'|'duplicate'|'idle'|'trial')[]; confidence:number; txIds:string[] }
```
- `parseBillFile(file:File):Promise<{platform:T003; rows:TxRecord[]}>`（Worker/主线程同实现）
- `detectSubscriptions(rows:TxRecord[], opts?):Subscription[]`
- `summarize(subs, decisions):Report`

## 关键实现方法（要点/伪代码）

```
for rows grouped by normMerchant and priceBucket(±8%, ≤300分):
  days = adjacent date diffs (sorted)
  gap = median(days); cv = stdev/mean
  cadence = bucket(gap); if cv>0.25 → irregular(排除)
  next = last + gap; annual = round(price * 365.25/gap)
flags: max/min price -1 ≥10% → price-up
       sameCategory active ≥2 → duplicate
       now-last > 1.5*gap → idle(弱提示)
       命中试用词 且 nextPrice>paid*1.5 → trial
```
