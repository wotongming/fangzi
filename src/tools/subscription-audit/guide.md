# 账单订阅盘点与自动续费预警 · 使用指导

版本 1.0.0 · 更新于 2026-10-17

## 这是什么

导入你从**微信支付 / 支付宝官方导出的账单 CSV**，它会在你的设备本地自动找出按月/按年重复扣的订阅，算清每个会员一年、三年花多少钱，标出**疑似闲置 / 同类重复 / 涨价 / 试用即将转正**的项目，给出官方关闭入口，并能生成续费日历提醒。**账单全程不上传，刷新/断网都能处理。**

## 第一步：导出账单（在手机或电脑上操作）

**微信支付**
- 手机：我 → 服务 → 钱包 → 账单 → 右上角「常见问题/申请交易账单」→ 选择时间段 →「申请账单明细」，邮箱收到后下载其中的 CSV（交易明细）。
- 文件名常见为「微信支付账单明细.csv」，编码可能是 GBK，工具会自动识别。

**支付宝**
- 手机：我的 → 账单 → 右上角「…」→「开具交易流水证明 / 交易明细」→ 选择时间段并确认，邮箱收到后下载 CSV/明细；电脑端可在支付宝官网「交易记录」里导出。

> 建议一次导出最近 6–12 个月，才能识别年付会员。可同时导入多月、多个账户的多份文件。

## 第二步：导入并识别

1. 点「＋ 导入账单」，选择一份或多份 CSV（可在账户标签里备注如“我的微信”“家人支付宝”）。
2. 工具自动识别平台、去重、只统计支出，并把周期性扣费聚合成订阅。
3. 若提示“未识别账单格式”，请确认导出的是**交易明细 CSV**（不是截图/PDF/汇总页），按上面步骤重新导出。

## 第三步：盘点与决定

- 顶部看到订阅总数、**年支出、三年支出、取消可省**。
- 每条订阅显示：名称、平台、周期、单价、最近/下次扣费、年支出和标签（涨价/重复/闲置/试用）。
- 对每条点「保留 / 取消 / 观望」；专业版可手动改周期、合并、忽略识别错误项，结果会保存在本机。
- 「疑似闲置」是根据“距上次扣费已久仍在续”给的**自查提示**，是否真的没用请以你自己的使用情况为准。

## 第四步：关闭与提醒

- 展开任意订阅的「如何关闭」，按微信/支付宝官方路径在对应 App 里关闭（工具不会、也无法替你操作免密协议）。
- 专业版可「生成续费提醒日历（.ics）」，导入手机/电脑系统日历后，会在每次预计扣费前一天提醒并按周期重复。
- 也可开启浏览器通知：仅在本页面打开期间生效；长期提醒请用导出的 .ics。
- 「导出报告」得到一份 Excel 可打开的订阅清单 CSV，方便和家人一起核对。

## 免费与专业版

- 免费：单份账单、基础订阅识别与年度总览。
- 专业（买断 ¥9.90）：多份多月多账户合并、智能闲置/重复/涨价判定与手动纠错、日历提醒、退订待办与报告导出。

## 隐私与安全

- 账单只在本机浏览器解析，**不会上传到任何服务器**；工具不登录、不触碰你的支付账户，也不能自动解约。
- 逐条账单明细不长期保存；本机仅保留你做的“保留/取消/忽略”等标记，清除浏览器数据即可彻底删除。

## 常见问题

- **年付会员没识别出来？** 请确保导出区间覆盖到至少两次扣费（间隔约一年），尽量导出满 12 个月以上。
- **把不是订阅的也算进来了 / 漏了某个订阅？** 可用「忽略 / 改周期 / 合并」手动纠正，纠正会被记住。
- **金额差几分钱影响识别吗？** 不影响，算法对小幅零头/优惠有容差；明显涨价（≥10%）会单独标注。
