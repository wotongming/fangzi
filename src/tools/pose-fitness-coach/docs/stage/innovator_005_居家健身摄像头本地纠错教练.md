# 功能建议：居家健身摄像头本地纠错教练（WebGPU 姿态识别 · 视频不出设备）

- 序号：005
- 建议形态：网页应用（PWA，纯前端 WebGPU/WASM 姿态识别 + 本地训练日志）

## 需求来源
2026 年“摄像头 AI 数次数 + 实时动作纠错 + 语音提示”成为居家健身新热点，且**端侧推理、零视频上传、隐私**被当作核心卖点：
- Posiqo（AI 实时纠错、错误动作不计数、**Zero data uploaded—100% private、on-device AI**）：https://posiqo.in/
- Repmirror（摄像头看每个动作、计数、0–100 动作分、语音纠错，“住在手机里的私教”）：https://www.repmirror.ai/
- PoseRep App Store（姿态检测自动数组数、实时动作分析，替代私教）：https://apps.apple.com/af/app/poserep-ai-fitness-tracker/id6759505171
- PozeFit（实时语音提示、每组 0–100 动作分/节奏复盘）：https://apps.apple.com/iq/app/pozefit/id6761784100
- Neon Pose（Google Play，AI 自动计数、霓虹骨架、动作打分，面向嫌自己数组数麻烦的人）：https://play.google.com/store/apps/details?id=com.justwitworks.neonpose
技术可行性：WebGPU/WASM 端侧姿态模型（BlazePose/MoveNet 类 33 关键点）已可在浏览器实时跑（检索词「WebGPU on-device pose estimation browser 2026」）。现有多为**原生 App**，浏览器内、免安装、可买断的同类产品稀缺。

## 使用场景
谁：在家做徒手/哑铃训练的上班族、健身新手（怕动作错受伤）、出差只能用酒店房间/手机锻炼的人、不想请私教的学生与预算敏感人群。
时机：下班后/午休在家跟练深蹲、俯卧撑、弓步、平板、肩推等；自己练没人看动作、数组数容易乱、不知道膝盖是否内扣/腰背是否塌。
问题：私教课贵（数百元/节）；跟练视频不能纠正“你”的动作；健身 App 多要订阅、要下载安装、且摄像头视频要上传云端引发隐私顾虑；手动记组数打断训练。

## 功能描述
1. 打开网页授权摄像头即可练（WebGPU 实时姿态，WASM/CPU 降级），画面本地叠加骨架与角度，**视频流绝不上传/不录制**。
2. 支持常见前/侧面可判动作：深蹲、俯卧撑、弓步蹲、臀桥、肩推、平板等；自动数有效次数（错误动作不计）、组/间歇计时、节奏检测。
3. 实时纠错与语音/视觉提示：膝盖内扣、下蹲深度不足、塌腰、肘部角度、左右不平衡等；每组给 0–100 动作分与改进要点。
4. 训练计划：按目标（增肌/减脂/康复入门）与器械（徒手/哑铃）生成本地周期计划，每日“今天练什么”，动作库带标准要点。
5. 本地训练日志与趋势：容量、动作分曲线、连续打卡、薄弱项提醒；IndexedDB 存储。
6. 离线可用（模型首次加载后），可装到主屏像 App 一样用。

## 目标人群
画像：18–45 岁居家/出差健身者、健身新手与轻中度训练者；注重隐私、不愿装一堆 App、讨厌订阅的人。规模：全球居家数字健身用户数以亿计，中文徒手/减脂人群庞大。付费意愿：私教昂贵而 App 订阅 $10–20/月普遍；“一次买断、浏览器即用、视频不上传”对价格与隐私双敏感人群有吸引力，愿付 ¥39–99 买断，进阶计划/动作包可复购。

## 建议形态
纯前端 PWA（WebGPU/WASM）。理由：①核心是摄像头实时推理，端侧 WebGPU 可满足且天然保护隐私（明确卖点）；②免安装、跨手机/平板/笔记本、出差换机即练、可离线；③无后端零边际成本，适合买断；④可装主屏获得近原生体验。

## 落地价值
解决问题：用零成本“数字私教”替代昂贵私教与订阅 App，实时纠正降低受伤风险、自动计数不打断训练；视频不出设备消除健身场景（家居环境、穿着）隐私顾虑。市场空间：数字健身是大品类，差异化切口在“**浏览器免安装 + 端侧隐私 + 买断 + 计划→训练→复盘闭环**”。盈利点：freemium（免费基础动作与计数）→ 买断解锁全动作库、实时纠错、动作分与周期计划；后续可卖康复/专项动作包、哑铃/弹力带器械包。

## 多场景链路与红海规避判断
- 是否同质化小工具：否。不是单一“计数”，而是“评估/计划→每日训练→实时纠错计数→间歇→组后复盘→长期日志与计划调整”的完整训练闭环。
- 多场景链路：触发（今日训练计划）→ 处理（摄像头实时姿态/计数/纠错）→ 产出（动作分、有效容量、要点）→ 后续动作（写入日志、趋势/薄弱项、调整下一周期计划）。
- 持续使用频次与付费空间：健身用户每周 3–5 次、长期高频；可延伸动作库、康复课程、器械包、饮食记录等持续付费场景。
- 红海规避：通用健身 App/跟练内容是红海，但它们要么不上 AI 纠错、要么是需安装的原生 App 且视频上云；“**纯浏览器 + WebGPU 端侧 + 零上传隐私 + 一次买断**”在 2026 年仍是新技术带来的空白窗口，差异化清晰。

## 强规则核对
| 强规则 | 是否满足 | 依据 |
| --- | --- | --- |
| 给用户带来真实价值（节省时间/资金/情感价值，至少其一） | 是 | 替代私教/订阅省钱，实时纠错降低受伤风险、提升效果（省资金+健康价值） |

> 判定：三条强规则全部满足，产出。
