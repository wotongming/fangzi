## 技术选型落地
Vue3+TS；@mediapipe/tasks-vision(Apache-2.0)+pose_landmarker_lite/full.task(Apache-2.0) 同源 /mf；GPU(WebGPU)→CPU(WASM) 回退；speechSynthesis 内置；IndexedDB。全部免费可商用，零后端。

## 模块设计
`camera → pose-runner(帧) → pose-geometry(归一关键点) → exercise FSM(计数/问题/分) → {Overlay, feedback, store}`。几何与 FSM 完全脱离 DOM/摄像头（输入 landmarks 数组），是单测与伪造 E2E 的核心接缝。

## 关键实现方法（伪代码）
```
onFrame(t, lm):
  kp = smooth(lm)                      // One-Euro，低置信点标记 invalid
  st = fsm.update(kp)
  if st.phase up && st.validRep: reps++; repScore=...; pushIssues(st.issues)
  if st.issues.critical && now-lastVoice>2s: speak(...); lastVoice=now
  record(t, {reps, repScore, issues})
// squat: hipAngle<θDown→down, >θUp→up 且 depth 达标才计；膝内扣=两膝间距相对踝过窄
```

## 代码规范与质量要求
TS 严格；device/stream 显式释放；GPU context 用 gpu-detect 公共脚本不提前销毁；几何/FSM 无副作用；中文提示；保守可回退。

## 验收标准
- 类型 0 错；几何+6 动作 FSM 单测（含半程/失衡/抖动/丢点/无人）全过；全量单测与 verify:tools 无回归（工具数+1）；
- 伪造输入 E2E：深蹲/俯卧撑计数与 HUD、落库、买断解锁通过；强制 WebGL2 截图骨架正确；
- 三视图无溢出；真机人工复测（摄像头+语音）列入 guide；无任何帧上传（网络面板断言）；模型/wasm 单文件 <25MiB（或已分片合规），dist 在 EdgeOne 限额内。
