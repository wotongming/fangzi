# 部署运维指引：居家健身摄像头本地纠错教练（pose-fitness-coach）

- 对应 architect：`architect_005_居家健身摄像头本地纠错教练.md`
- 编写日期：2026-10-16

## 部署架构与环境准备
纯静态 PWA：EdgeOne Pages 站点 + 同源 `/mf/` 下 MediaPipe tasks-vision wasm 与 pose_landmarker `.task` 模型 + 现有 Service Worker 缓存。运行依赖浏览器 getUserMedia（HTTPS，已具备）与 WebGPU（不可用自动回退 WASM/CPU）。无后端、无密钥、视频不离开设备。

## 软硬件配置清单
无服务器。构建机 Node≥20.19。端侧：建议较新 Chrome/Edge/Safari（手机含后置摄像头）。模型 lite 体积数 MB（<25MiB 直放；如用 full 超限则走 `sw-model-shards.js`+`mf/shards.json` 分片）。

## 部署步骤
1. 模型/wasm 放 `public/mf/pose/...`（同源，禁止引用 storage.googleapis.com）；如分片在 shards.json 增条目并按 004 经验拒绝 text/html、首字节校验、cache 版本独立。
2. 合入 main，EdgeOne Pages 自动构建发布；构建守卫确认单文件 ≤25MiB、dist 总量/文件数在 5GiB/20000 内。
3. www 域校验：工具页 200、模型/wasm 200 且 MIME 正确、SW 接管；真机大陆网络首次下载、断网二次可开。
4. 真机权限：摄像头授权→姿态→计数；拒绝/无摄像头时给引导。

## 配置项说明
无环境变量/密钥。计费 `manifest.billing`（freemium+买断 4990；免费深蹲/俯卧撑）。模型路径与 delegate 优先级在 pose-runner.ts（GPU→CPU）；帧率/平滑系数集中常量，便于调参。

## 上线/灰度方案
H 档按里程碑：M1 上线深蹲/俯卧撑+计数（标注“Beta”，首页不主推），收集不支持率与计数反馈；M2 开放全动作/纠错/计划并主推。回滚：revert/移除工具目录即可下线，主体与其它工具、共享 /mf 不受影响（pose 用独立 cache 名/子目录）。

## 平台对接指南
- **EdgeOne Pages**：复用现有项目与 www.fangzi.asia HTTPS；wasm 与模型为静态大文件，确认边缘返回正确 `Content-Type`（application/wasm / octet-stream）且不被 SPA 回退成 HTML（004 已踩坑）。
- 浏览器能力：getUserMedia 需安全上下文（https/localhost）；iOS Safari 需 14.5+ 且对 WebGPU 支持不一，靠 CPU 回退并在不支持时明确提示。无插件商店分发。

## 运维监控指标与告警
本地（不上传视频/图像）：GPU vs CPU 路径占比、模型加载成功率、不支持设备提示率、各动作完成数与常见纠错类型、每会话时长。用于动作阈值与 lite/full 选择调优。无服务端告警，靠发版观察。

## 日志管理 / 备份容灾
无服务端日志。训练记录存 IndexedDB `fz-pose-coach-v1`，可提供导出 JSON/导入（M2）。摄像头帧仅内存、不落盘、不录制。

## 常见故障排查与回滚
- 模型 protobuf/session 错误：核对 wasm 与 .task 版本配套、未被 HTML 回退污染（参照 004 sw-model-shards 校验）。
- 黑屏/无点：权限、摄像头被占、前后置切换；camera 生命周期单测覆盖。
- 计数不准：几何阈值按真机微调，问题可用录制 landmarks 在单测复现；光线/取景引导。
- WebGPU 异常：自动降级 WASM 并在设置显示当前 delegate。
- 回滚：单提交下线工具；pose 资源独立缓存，删除不影响 003/004。
