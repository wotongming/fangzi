# 居家健身摄像头本地纠错教练 · 用户指导

版本 1.0.0 · 更新于 2026-10-17

## 这是什么 / 能做什么

打开摄像头即可在本机端侧识别动作关键点，自动为深蹲、俯卧撑计数并给基础幅度提示；专业版另解锁弓步蹲、臀桥、站姿肩推、平板支撑，提供实时纠错、每动作评分、按目标与器械生成的周期训练计划与历史趋势。画面只做实时分析，不录制、不上传，首次加载模型后可离线使用。

**重要边界**：本工具是运动姿态的端侧辅助参考，不能替代专业教练或医疗建议；运动中出现疼痛、眩晕请立即停止，并确保周围环境安全、留有足够活动空间。

## 快速开始

1. 打开工具，默认「自由练」页，顶部动作胶囊选择动作，摆好机位（建议手机侧放地上拍侧面、光线充足、背景简洁、露出全身关节）。
2. 点「开始跟练」，浏览器弹出摄像头授权时选「允许」；首次启动会下载姿态模型，请稍候。
3. 画面叠加骨架与关键点，HUD 显示次数 / 阶段 / 上次评分 / 关键角度；动作不到位会弹出纠错气泡并语音提示（实时纠错为专业版）。
4. 完成后点「结束并保存」，本组数据（次数、合格次数、平均分、时长、问题统计）写入本机历史。

## 分步用法

### 1. 自由练与动作切换

- 免费：深蹲、俯卧撑（摄像头自动计数 + 基础幅度提示）。
- 专业版：弓步蹲、臀桥、站姿肩推、平板支撑；平板为计时型，HUD 显示已坚持秒数，身体塌腰时暂停计时。
- 在自由练页可切换前置 / 后置摄像头、镜像、静音语音。

### 2. 实时纠错与评分（专业版）

- 动作不到位（如蹲得太浅、塌腰、膝内扣）即时弹出纠错气泡并语音提示。
- 每动作给出评分，完成后本组平均分写入记录。
- 侧面机位最稳；动作放慢、幅度做满：深蹲蹲到大腿接近水平，俯卧撑胸口贴近地面，可提升计数与判定准确性。

### 3. 训练计划（专业版）

- 「训练计划」页按目标（减脂 / 增肌 / 改善体态）、器械（自重 / 哑铃）、每周训练天数生成周课表。

### 4. 历史趋势（专业版）

- 「历史趋势」页列出每次训练记录，可单条删除；专业版显示最近若干次平均动作分折线图。所有记录保存在浏览器 IndexedDB，不上传。

### 5. 设置

- 「设置」页查看各项权益解锁状态；端侧推理优先 GPU（WebGL / WebGPU），不可用时自动回退 CPU，功能不受影响、帧率略低。

## 免费与专业版

- 免费：深蹲（摄像头自动计数 + 基础提示）、俯卧撑（摄像头自动计数 + 基础提示）。
- 专业版（一次买断 ¥29.90，无订阅、无后续费用）：弓步蹲 / 臀桥 / 站姿肩推 / 平板支撑四个动作；实时纠错（膝内扣 / 半程 / 塌腰等）+ 每动作评分；按目标与器械生成的周期训练计划；历史趋势分析与无限训练记录。买断授权记录保存在本机。

## 数据与隐私

- 摄像头画面不录制、不存储、不上传，只在本机实时分析；训练记录仅存本机 IndexedDB。
- 清理浏览器站点数据会移除买断授权与训练记录，需在原环境使用；录音 / 拍摄他人时请先取得对方同意。

## 常见问题

- **提示模型加载失败 / Failed to fetch？** 多为首次下载模型网络不稳定，点重新开始重试；模型同源托管，正常网络可恢复。
- **一直显示「未检测到人」？** 退到能拍到全身、正对 / 侧对镜头，改善光线，避免背景与衣着颜色过近。
- **计数不准？** 侧面机位最稳，动作放慢、幅度做满。
- **画面卡顿？** 设备自动回退 CPU，可关闭其他高占用页面；动作均为轻量模型，中端手机可流畅运行。

## 注意事项 / 功能边界

- 本工具不提供医疗诊断或康复处方，有伤病基础请先咨询专业人士。
- 首次需联网下载姿态模型（约数 MB）与推理 wasm，之后缓存可离线；弱网 / 断网环境已加载模型后仍可用。
