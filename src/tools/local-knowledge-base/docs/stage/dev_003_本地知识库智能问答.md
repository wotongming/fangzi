## 技术选型落地

- 推理：`@huggingface/transformers`（Apache-2.0）+ onnxruntime-web（MIT）；模型 Qwen3-Embedding（Apache-2.0）、Qwen2.5（Apache-2.0）自 Hugging Face 免费下载；
- 解析：pdf.js（Apache-2.0）、mammoth（BSD-2）；存储：IndexedDB（复用 indexeddb-kv）；全部动态 import；零成本、商用友好。

见 architect_003 系统架构；ingest→embed→index→generate 单向数据流；UI 分「文档管理」「问答对话」「设置」三区。

## 开发环境与工具链

- Node ≥ 20.19；`npm run dev`；浏览器需支持 WASM（WebGPU 可选）；模型下载需网络（首次）。

## 开发步骤与里程碑

- M1（2-3 天）：ingest 解析分块 + IndexedDB 存储；
- M2（3-4 天）：嵌入 + 检索（含 reembed）；
- M3（3-4 天）：本地生成 + 溯源 UI；
- M4（2-3 天）：模型缓存/降级/Pro 权益/回归。

## 代码规范与质量要求

- fangzi 现有风格；重型依赖动态 import；模型文件不进 SW 预缓存；索引版本字段保证可迁移；隐私：不采集文档内容。

## 验收标准

- `npm run type-check`、`npm test`（新增 chunk/retrieve/confidence 单测）通过；
- 100 页 PDF 导入并检索命中；断网（模型已缓存）问答可用；低置信提示正确；freemium 权益正确；
- `npm run verify:tools` 命中「知识库/文档问答」关键词；存量回归正常。
