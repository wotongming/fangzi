# 部署运维指引：本地知识库智能问答

- 对应 architect：architect_003_本地知识库智能问答.md
- 编写日期：2026-10-15

## 部署架构与环境准备

- 部署架构：EdgeOne Pages 静态托管（同 fangzi）；模型运行时从 Hugging Face 下载（不进部署包，客户端缓存）；数据全在用户本地（IndexedDB）。
- 环境清单：Node ≥ 20.19（构建机）；EdgeOne Pages 账号（已有）；Hugging Face 公开模型免账号下载。

## 软硬件配置清单

| 项 | 规格 |
| --- | --- |
| 构建机 | Node 20+ |
| 部署 | EdgeOne Pages（免费额度） |
| 客户端 | 桌面浏览器（建议 ≥8GB 内存）；WebGPU 可选（CPU 可跑小模型） |
| 模型 | Qwen3-Embedding-0.6B(INT8) + Qwen2.5-0.5B/1.5B(INT4)，首次下载 1.5-3GB（分档） |

## 部署步骤

1. `cd fangzi && npm install && npm run build`
2. EdgeOne Pages CLI/Git 推送 dist/
3. 验证：工具页加载、导入文档、问答可用；首次模型下载进度正常
4. 更新 README 工具清单（登记 local-knowledge-base 七字段）

## 配置项说明

- 无新增环境变量；模型源 URL/缓存键在 `lib/models.ts` 常量维护；检索阈值默认 0.5（可调）。

## 上线/灰度方案

- 内部灰度（文档数/模型档位全量）→ 观察模型下载成功率与问答耗时 → 全量；Pro 权益随计费框架发布。

## 平台对接指南

- **EdgeOne Pages**：个人账号即可；部署 CLI/Git；HTTPS 平台提供；版本更新=重新部署。
- **Hugging Face（模型源，非上架）**：无需注册即可下载公开模型（Qwen 系列 Apache-2.0）；如国内访问不稳，可配置镜像源（models.ts 多源/重试）；无需 API Key。
- 其余平台：不涉及。

## 运维监控指标与告警

- 指标：工具访问量、模型下载失败率/问答耗时（本地打点可选上报）、内存 OOM 率；
- 告警：模型源不可用 → 多源切换提示；OOM 高发 → 引导低配档（0.5B）。

## 日志管理

- console 结构化日志 + error 聚合；**不采集文档内容与提问**（隐私承诺写入工具页）。

## 备份与容灾

- 用户数据在本地 IndexedDB（浏览器自带）；无服务端数据；代码仓 git 备份；提示用户导出对话/知识库元数据（V2 提供导入导出）。

## 常见故障排查与回滚预案

- 模型下载失败/慢：检查网络；切换镜像源；断点续传重试；
- 首问 OOM：切换 0.5B 档；提示释放内存；
- 严重问题：`git revert` + 重部署，仅影响新增工具。
