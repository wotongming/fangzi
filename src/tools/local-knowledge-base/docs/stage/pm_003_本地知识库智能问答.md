# PM 评估报告：本地知识库智能问答

- 对应 innovator：innovator_003_本地知识库智能问答.md
- 评估日期：2026-10-15
- 结论：**可集成（新增）**

## 与 fangzi 现有功能去重与整合判定

对照 fangzi README 与 `src/tools/`：现有工具无知识库/文档检索/问答类功能。fangzi 内置的「向量检索」能力（设置页配置 OpenAI 兼容 Embedding 后搜索升级为向量+关键词混合）服务于**工具检索**（对工具 manifest 做 embedding 排序），与「对用户导入的文档建库做 RAG 问答」是不同对象、不同链路，无功能重叠。

- **判定不重复** → 新增独立工具。

## 需求真伪判断

- 真需求。证据链：LocalRAG!（移动端）已上线订阅制本地文档问答；WPS AI 企业知识问答 599 元/人/年；边界智能睿阁做私有化知识库；爱范儿报道律所/投行/医院「想用但不让用 AI」的合规刚需；ModelScope 出现本地 RAG 技能。云端 ChatPDF 类产品的大量用户说明「文档问答」需求真实，而「数据不出端」是其未满足点。
- 使用频次：律师/金融/科研/知识管理用户日级高频。与 fangzi 用户群匹配：fangzi 主打「生活、工作、合规」场景，合规（个税/离职/加班）与工作（文本处理）用户对「本地文档问答」有天然兴趣；隐私优先与 fangzi 产品气质一致。

## 技术可行性

- 完全可行，纯前端实现：
  - 文档解析：pdf.js（Apache-2.0）/mammoth（BSD-2，docx）/原生文本解析；图片 OCR 可选 tesseract.js（Apache-2.0，较重，MVP 可后置）；
  - 嵌入：`@huggingface/transformers` 跑本地 embedding 模型（如 Qwen3-Embedding 小量化版，Apache-2.0）；
  - 检索：向量（余弦）+ BM25 混合，IndexedDB 存向量（复用 `reusable-module/indexeddb-kv`）；
  - 生成：WebLLM（Apache-2.0）或 Transformers.js 跑 0.5B-1.5B 小模型（Qwen2.5，Apache-2.0）本地生成答案 + 引用溯源。
- 技术风险：浏览器内存（建议 ≥8GB、小模型档位）、模型首次下载体积（1.5-3GB 需进度与续传）、WebGPU 加速依赖——均有降级路径（CPU 推理、更小模型）。

## 集成成本与侵入性

- 新增 `src/tools/local-knowledge-base/`，工具框架自动发现，零核心/路由改动；
- 模型与解析库全部动态 `import()`，主包不膨胀；不触碰 Service Worker 预缓存策略（模型运行时下载，不进预缓存）；
- 存量影响：无（纯新增）。

## 架构兼容性

- 与 fangzi 零后端纯前端架构兼容；不引入 UI 框架；
- 复用现有 IndexedDB KV 模块与「本地优先」模式；计费走现有 billing 框架（freemium）。

## 平台合规评估

- EdgeOne Pages：静态托管无服务端需求；运行时从 Hugging Face 下载模型（外部免费源）不属于部署包；合规；
- 不进插件商店；内容合规：本地文档处理不产生存储/传播，答案含「低置信度」提示防误导，合规。

## 资金成本

- 零成本可行：pdf.js（Apache-2.0）、mammoth（BSD-2）、Transformers.js/WebLLM（Apache-2.0）、Qwen 系列模型（Apache-2.0）、Hugging Face 免费下载；全部商用友好授权。

## 时间成本与开发难度

- 复杂度：高（本地 RAG 全链路 + 模型调度）；
- 独立开发者估算：文档解析+分块 2-3 天、嵌入+检索+IndexedDB 3-4 天、本地生成+溯源 UI 3-4 天、模型缓存/降级/回归 2-3 天，合计约 10-14 人日。

## 用户真实价值

- 核心痛点：敏感文档不能上传云端的合规红线；云问答持续付费；离线不可用；
- 使用频次：从业者日级；对 fangzi 价值：新增「知识管理」品类，吸引合规敏感（法律/金融/医疗/政务）用户，freemium 付费空间大（对标 WPS 599/人/年）。

## 市场与竞争

- 竞品：云端 ChatPDF/文档问答（红海但数据上传是硬伤）、企业私有化 RAG（贵、面向企业）、LocalRAG!（移动端，桌面浏览器空白）；
- 差异化：免费基础 + 桌面浏览器 PWA + 工具集合生态 + 离线；个人平价本地 RAG 桌面端无强势竞品。

## 盈利方式建议

- freemium：免费（文档数 ≤ 20、小模型档）；Pro（buyout ¥49.90 或订阅）解锁多格式/更大模型/跨文档对比/团队共享；后续可出企业内网部署版授权。

## 结论与依据

- **可集成（新增）**：与现有功能无重复；纯前端零资金可行（Qwen/Transformers 均商用友好）、不破坏存量、平台合规；合规+离线+省钱三重刚需，付费意愿强（企业端已验证）。
