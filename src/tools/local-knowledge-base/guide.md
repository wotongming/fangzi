# 本地知识库智能问答 · 用户指导

版本 1.0.0 · 更新于 2026-10-15

## 这是什么 / 能做什么

把合同、研报、笔记、说明书、数据表等文档直接拖进浏览器，在本机完成解析、分块、语义嵌入与索引，随后像聊天一样对自己的资料提问。系统用「本地语义向量 + 关键词（BM25）」混合检索，答案直接引用原文片段并可点开核对。文档、向量、对话全程留在你的设备上，不上传任何服务器；语义模型首次下载缓存后即可离线使用。

**重要边界**：本期答案为「检索 + 原文抽取合成」，不调用生成式大模型，因此不会编造内容，但也不做跨段推理式改写；请结合引用原文判断。

## 快速开始

1. 进入「文档库」，点「＋ 导入文档」，多选 `.txt / .md / .csv / .html / .htm` 文件。
2. 勾选「启用语义嵌入」则用本地模型生成向量（更懂换个说法的问法）；不勾选则只用关键词 BM25 建库，零下载、立即可用。
3. 切到「问答」，在底部输入框提问，答案带 `[n]` 角标并列出来源文件，点来源可看原文核对。
4. 在「设置」页查看模型状态、下载 / 清除模型缓存。

## 分步用法

### 1. 导入文档建立本地知识库

- 导入时依次完成解析、智能分块、（可选）语义嵌入与本地保存，顶部进度条显示当前阶段，模型下载阶段显示百分比。
- 免费版最多 20 个文档；专业版不限数量并支持批量导入更大知识库。
- 本期原生支持 txt / Markdown / CSV / HTML；PDF 与 Word（docx）解析将在下一版本提供，可先另存为 .txt 或 .md 导入。建议单文件 5MB 以内，超大文件先拆分。

### 2. 对文档提问并核对引用

- 在「问答」底部输入框提问（回车或点「发送」）。答案从最相关的原文片段中抽取句子组成，每句末尾带 `[n]` 角标，下方列出对应来源文件。
- 答案下方标注当前使用「语义 + 关键词检索」还是「关键词检索」，以及置信度。
- 点来源按钮（如 `[1] contract.txt`）弹出该片段原文，可逐字核对出处后再决定是否采纳。
- 提问自动保存为对话，左侧可切换历史对话、一键导出为 Markdown。

### 3. 准备 / 管理语义模型与下载源

- 在「设置」页查看模型状态，点按钮探测最快下载源并下载、初始化模型；模型存于浏览器 Cache Storage，二次使用离线可跑，也可「清除模型缓存」后重新下载。
- 下载源按优先级自动探测、故障切换：专业版自定义对象存储 / CDN（按 Hugging Face 目录布局存放，填 Base URL，如 Cloudflare R2、腾讯云 COS + CDN）→ hf-mirror.com 国内镜像（默认优先）→ huggingface.co 官方源兜底。
- 语义模型为 bge-small-zh-v1.5 量化版（约 24MB），MIT 许可、可商用；不下载模型也能纯关键词检索，语义模型未就绪或失败时自动降级为关键词检索，问答不中断。

## 免费与专业版

- 免费：txt / Markdown / CSV / HTML 解析、智能分块与引用溯源；本地语义模型（bge-small，约 24MB）+ 关键词混合检索；本地知识库最多 20 个文档。
- 专业版（一次买断 ¥29.90）：文档数量不限、批量导入更大知识库；自定义模型源（自带 Cloudflare R2 / 腾讯云 COS 对象存储）。

## 数据与隐私

- 文档解析、嵌入、存储全部在浏览器本地完成（IndexedDB + Cache Storage），服务端只在你首次下载公开模型文件时被访问，且不携带你的文档内容。
- 清理浏览器站点数据会删除本地知识库与模型缓存；重要资料请保留原文件，可重新导入。

## 常见问题

- **文档会上传到云端吗？** 不会，全部本地完成，仅首次下载公开模型时访问公共源。
- **不下载模型能用吗？** 能，关闭「启用语义嵌入」即走纯关键词检索，无需下载。
- **第一次下载提示某个源失败？** 系统自动按优先级切换镜像 / 官方源；全部失败多为临时网络问题，稍后重试，已下载文件会缓存不重复下载。
- **支持 PDF / Word 吗？** 本期不支持，可先另存为纯文本 / Markdown 导入。

## 注意事项 / 功能边界

- 答案基于检索到的原文片段抽取合成，不做生成式润色与跨段推理，法律 / 金融等关键结论请回原文核对。
- 本地嵌入模型与推理运行时均为 MIT 许可，模型文件来自公开镜像或你自带的合规对象存储。
