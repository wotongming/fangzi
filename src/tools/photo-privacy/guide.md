# 照片隐私清理工作台 · 使用指导

发照片前，先把会泄露你位置和身份的信息去掉。本工具在**你的浏览器本地**完成全部处理：清除照片里的 GPS 定位、拍摄时间、设备型号/序列号等 EXIF 信息，框选打码敏感区域，清洗文件名并按需压缩，**照片不会上传到任何服务器**。

## 我能用它做什么
- 一键清除 EXIF / GPS / 设备信息（重绘生成新文件，彻底剥离元数据）。
- 在图上拖拽框选，做**马赛克 / 模糊 / 纯色遮挡**（车牌、门牌、手机号、地址、二维码、订单号、孩子正脸等）。
- 统一缩放、压缩、转换 JPEG / WebP / PNG。
- 清洗文件名里的时间戳、品牌、序号，可统一前缀重命名。
- 多张照片批量处理并打包成 ZIP 下载。
- 二手交易、晒娃、证件票据、工作截图、维权留证等**场景预设**，一键套用参数与遮挡清单。

## 单张处理步骤
1. 打开工具，选择「单张处理」，点「＋ 选择照片」。
2. 顶部会提示这张原图将泄露哪些信息（如“精确 GPS 定位、拍摄时间、设备型号”）。
3. 需要遮挡时，选择「矩形框选」（或专业版的「自由涂抹」），在图上拖拽框出敏感区域；可框多个、可点右上角 ✕ 删除。
4. 在上方设置格式、质量、最长边、打码方式与文件名前缀。
5. 点「一键清除隐私并生成」，确认结果提示“已验证清空”后点「下载」。生成的是新文件，不会覆盖原图。

## 批量处理步骤
1. 切到「批量处理」，点「＋ 选择多张照片」一次选入。
2. 列表会标出每张原图是否含 GPS / 设备信息；不支持的格式会跳过并提示。
3. 点「开始批量处理」，进度实时显示；完成后点「下载 ZIP」得到全部处理后的照片（已统一压缩、清洗命名）。
4. 批量模式用于统一去元数据与压缩；需要对某张打码，请在「单张处理」里逐张操作。

## 常见问题 FAQ
- **处理后是不是就绝对安全了？** 工具会清除文件元数据并按你的框选打码；但画面本身能看到的内容（招牌、门牌号、人脸等）需要你主动框选遮挡，发布前请再目检一遍。
- **支持 HEIC / RAW / 视频吗？** 当前支持 JPG / JPEG / PNG / WebP。iPhone 的 HEIC 与 RAW、视频暂不支持，请先用系统“另存为 JPEG”后再处理。
- **为什么转成 JPG 后透明背景变白了？** JPEG 不支持透明通道，会自动铺白底；需要保留透明请选 PNG。
- **会改变画质或方向吗？** 默认按原方向输出并保留较高画质；可调质量与最长边。重绘会丢弃色彩配置文件与内嵌缩略图，用于公开发布没有影响。
- **我的照片会被上传吗？** 不会。读取、重绘、打码、压缩、打包全部在本机内存中完成，离开页面即释放，不留存图片。
- **旧 Safari 选 WebP 怎么办？** 浏览器不支持 WebP 编码时会自动改用 JPEG。
