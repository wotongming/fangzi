# 功能建议：照片发布前本地隐私清理与脱敏工作台

- 序号：006
- 建议形态：网页应用（纯前端 Canvas/文件处理，PWA）

## 需求来源
- 南漳县人民政府《刚发了一条朋友圈，陌生人为何知道你在哪?》——EXIF 记录精确到秒的时间、设备、GPS 经纬度（精确到几米）。http://www.hbnz.gov.cn/xwzx/nzwx/202608/t20260806_4040734.shtml
- 光明网《不要发原图，后果太可怕了》——发原图会一并送出 Exif 时间/地点/设备信息。https://m.gmw.cn/2024-10/29/content_1303883496.htm
- Pixotter《Remove Metadata from Images》——EXIF 含 GPS/设备序列号，风险高，见于 JPEG/HEIC/WebP/RAW。https://pixotter.com/blog/remove-metadata-from-image/
- ImageMarker《Remove EXIF Data Online》——服务端工具会把图上传，浏览器本地处理才不出设备；支持批量是刚需。https://imagemarker.app/en/blog/remove-exif-data-guide
- 检索关键词：照片 EXIF 隐私 清除 GPS 定位 水印 打码 批量 发朋友圈 泄露

## 使用场景
用户在多种场景发布照片前都需要隐私处理却常忘：二手交易/卖房拍门牌票据、晒娃/晒机票证件、维权留证、求职发证件、群里发工作截图、发原图给陌生人。原图携带 GPS、家庭住址线索、设备序列号；截图还可能带姓名/电话/地址/订单号。直接发可能被定位、人肉、诈骗。痛点链路：选图（含多张/HEIC/截图）→ 查看将泄露的信息 → 一键去 EXIF/GPS/序列号 → 按需打码/马赛克/遮罩敏感区域与文件名 → 压缩与格式转换 → 安全发布/发送。

## 功能描述
- 批量导入 JPEG/PNG/WebP/HEIC（HEIC 本地解码转换），先展示每张将泄露的 EXIF：GPS 地图定位、拍摄时间、设备型号、序列号，让用户"看到风险"。
- 一键彻底剥离 EXIF/XMP/IPTC/缩略图元数据；可选手动涂抹/矩形马赛克/高斯模糊打码（人脸、车牌、地址、二维码、屏幕信息），框选实时预览。
- 文件名清洗（去掉 IMG_时间戳/序号等可推断信息）、可选安全水印（用途/日期，如"仅供XX使用"）。
- 发布前压缩（目标体积/分辨率）、格式转换（统一 JPEG/WebP），保持方向正确；批量打包下载，全程不出设备。
- 常用"场景预设"：二手交易、晒娃、证件、工作截图、维权，一键套用打码/压缩组合。

## 目标人群
二手卖家/房东、家长、经常群内/社交平台发图的年轻用户、求职者、自媒体/运营、注重隐私的人群。覆盖面广、频次高（每次发图都用得上）。付费理由：隐私泄露代价大、批量与打码省事；愿为批量大数量、HEIC、高级打码/水印、预设工作流付费。

## 建议形态
网页应用/PWA：隐私处理的核心诉求就是"图片绝不能上传到陌生服务器"，浏览器本地 Canvas/File API 天然契合；电脑批量处理与手机随拍随处理都需要，PWA 免安装跨端。

## 落地价值
- 避险/精神价值：防止 GPS、住址、证件、序列号泄露导致的定位、骚扰、诈骗、人肉。
- 省时：把"找专门 App、逐张处理、再压缩"合成一个打开即用的批处理流程。
- 盈利点：freemium（去 EXIF/基础打码、少量免费）+ 付费批量不限量、HEIC/RAW、高级马赛克与水印、场景预设、尺寸/格式批量模板。

## 多场景链路与红海规避判断
- 是否同质化小工具：否（单纯"去 EXIF"是单点；本功能是"风险可视化→去元数据→区域脱敏→文件名清洗→压缩转码→按场景发布"的完整隐私发布链路）。
- 多场景链路：选图→识别泄露→脱敏/打码→压缩→发布，覆盖二手/晒娃/证件/维权等多个高频场景。
- 持续使用频次与付费空间：每次公开发图都可触发，频次高；批量与高级脱敏、工作流有付费空间。
- 红海规避：在线去 EXIF 多需上传（违背隐私初衷）或功能单一；本地、批量、带风险可视化与区域打码/场景预设的一站式工具仍有差异化空白。

## 强规则核对
| 强规则 | 是否满足 | 依据 |
| --- | --- | --- |
| 给用户带来真实价值 | 是 | 直接避免定位/隐私泄露与人肉诈骗风险，并省批量处理时间 |
| 用户有购买意愿 | 是 | 隐私安全代价高、二手卖家/家长/运营高频，批量与高级功能愿付费 |
| 形态贴合目标人群使用场景 | 是 | 图片不出设备是刚需，本地网页/PWA 双端批处理最贴合 |
