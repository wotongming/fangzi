## 关键实现方法（流程/伪代码）
EXIF：取 arrayBuffer 前 ~128KB；JPEG 检查 FFD8，遍历 marker 找 FFE1，载荷以 `Exif\0\0` 起始，读 TIFF 头字节序与 IFD0 偏移，按 tag 表取 0x010F/0110/0131/0132/0112，ExifIFD 指针 0x8769 取 0x9003/0xA431(序列号)，GPSIFD 0x8825 取 1/2/3/4/5/6 按度分秒与 N/S/E/W 换算十进制。任何越界/缺失都安全返回部分结果。

剥离（核心，重绘法）：
```
const bmp = await createImageBitmap(file,{imageOrientation:'from-image'})
const scale = o.maxEdge ? Math.min(1, o.maxEdge/Math.max(bmp.width,bmp.height)) : 1
canvas.width=round(bmp.width*scale); canvas.height=round(bmp.height*scale)
ctx.drawImage(bmp,0,0,canvas.width,canvas.height)
applyMasks(ctx, canvas.width, canvas.height, o.masks, o.redactMode) // 按 scale 换算
if(outType==='image/jpeg'){ /* 若有透明，先填白底再重绘 */ }
const blob = await canvasToBlob(ctx.canvas, outType, quality) // 输出不含任何元数据
```
马赛克：对区域按 block（约 max(6, w/40)）取色填块；模糊：`ctx.filter='blur(12px)'` 重绘该区域裁剪图，不支持 filter 则多次 1px box blur。

批量：主线程逐张 `postTo(worker,{file,options})`（Worker 内 OffscreenCanvas），收到进度更新 UI；全部 blob 用 fflate 边算边写入 zip（`zipSync` 小批量；大批量用 `Zip`+`strayFlush` 控内存），`URL.createObjectURL` 下载，用完 revoke。

计费：`const b=useToolBilling('photo-privacy')`；点击批量/多区域/预设时 `if(!b.canUse(key).allowed) await b.buy()`；免费按张 `mode='freemium'` 配 `usagePack.freePerDay` 或直接 feature gate（以 manifest 为准，见下）。买断后全功能。

## 代码规范与质量要求
与仓库一致：TS 严格、无 any 兜底滥用、注释中文、函数小而纯（exif/redact/naming 纯函数优先可测）；worker 通信走 worker-post；资源 URL 用完 revoke；显式处理不支持格式与失败，不白屏。

## 验收标准
- tsc 0 错误；全量单测通过（在现有 208 基础上新增用例全绿）；`verify:tools`=21；`build` 成功。
- 功能：处理后文件经 exif 读取无 GPS/设备/时间；打码区域生效、区域外不变；方向正确；批量 ZIP 完整；文件名清洗正确；未付费高级项被拦截且可购买、买断后可用；HEIC 有友好提示。
- 三视口：PC/平板/手机主流程可用、无横向溢出、触摸可拖框。
- 回归：image-converter 等存量工具 E2E 通过；SW/manifest/外壳不受影响。
- 限额：dist 总量、文件数、单文件均在 EdgeOne（5GiB/20000/25MiB）内（本工具无大资源，预期增量 <0.2MiB）。
