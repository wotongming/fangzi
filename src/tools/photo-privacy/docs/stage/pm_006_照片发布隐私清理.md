# PM 评估报告：照片发布前本地隐私清理与脱敏工作台

- 对应 innovator：innovator_006_照片发布隐私清理.md
- 评估日期：2026-10-17
- 结论：**可集成（新增独立轻量工具，本轮优先开发）**；建议档位 M

## 与 fangzi 现有功能去重与整合判定
与 `image-converter`（图片处理工作台）存在"都处理图片/会压缩"的表层重叠，经核对其 manifest 与代码：它聚焦**图像生产侧**——格式转换压缩、电商上新（多平台规格/换底/水印/资料包）、AI 超分/去背景；**完全没有** EXIF/XMP 元数据解析与剥离、GPS 定位风险可视化、区域马赛克/涂抹打码、文件名清洗、发布场景预设。二者**痛点方向相反**（一个是"做图/增强"，一个是"发布前做减法/防泄露"），目标人群心智不同（电商运营 vs 每个发图的普通用户），且 image-converter 已是买断 ¥19.9 的重型工具，把免费高频的隐私脱敏并入会混淆定位与计费、并迫使其存量用户为无关功能承担复杂度。
**结论：判定为"有明显区别"，但不宜并入重工具；按 SKILL"无法与存量安全/定位共存时宁可新开"的例外，新增独立工具 `photo-privacy`**。共享能力（图片解码、zip 打包等）下沉/复用 `reusable-module/`，并在两工具间互链，不做并列重复。

## 需求真伪判断
真实、高频、受众极广。政府/官媒多次提示原图 EXIF 含精确 GPS、时间、设备序列号，发朋友圈/二手交易/晒娃/证件/维权易被定位人肉（南漳县政府、光明网、Pixotter、ImageMarker）。在线去 EXIF 要上传，恰恰违背隐私初衷；批量、打码、文件名清洗分散在多个 App。

## 技术可行性
纯前端成熟 API，可行性高：
- 元数据：解析 JPEG EXIF（APP1 段）/PNG tEXt、展示 GPS（可本地反算经纬度展示，不接地图也可给坐标），剥离通过 Canvas 重绘或重建文件段实现；HEIC 解码按需（可后置或用现有图片解码方案）。
- 区域脱敏：Canvas 矩形/画笔马赛克、高斯模糊，框选实时预览。
- 文件名清洗、压缩（Canvas toBlob 质量/尺寸）、格式转 JPEG/WebP；批量处理用 Web Worker（复用 `reusable-module/worker-post`）避免卡 UI；多文件 ZIP 打包（复用仓库现有打包能力/新增 MIT 许可库）。
- 全程 File/Blob 本地，不上传。

## 集成成本与侵入性
新增 `src/tools/photo-privacy/`，标准 manifest 注册，零核心/路由/SW 改动；把可复用的图片读取/打包能力沉淀到 reusable-module 并更新其 README。侵入性低。

## 架构兼容性
无后端、静态、离线；契合技术栈；批量大图放 Worker 控内存，注意单文件 25MiB 与总体限额（不引入大模型，体积极小）。

## 平台合规评估
PWA 网页工具，无个人上架资质问题；纯本地处理反而满足隐私合规宣传（"图片不出设备"），不涉人脸等敏感识别（打码由用户手选，不做人脸检测，规避额外合规负担）。

## 资金成本
零成本、零数据服务；如需 ZIP/EXIF 库仅引入 MIT/Apache 商用友好的轻量库（EXIF 解析优先手写，零依赖）。

## 时间成本与开发难度
中（M）：EXIF 解析/剥离、Canvas 打码、批量与打包、多格式；无外部数据维护、无持续规则负担，单轮可端到端完成并做 PC/手机/平板三视口验证。

## 用户真实价值
直接避免定位/住址/证件/设备信息泄露导致的骚扰、诈骗、人肉；批量脱敏显著省时；隐私安全钩子强、传播性好，利于拉新与转化。

## 市场与竞争
在线去 EXIF 多需上传或功能单一、批量弱；本地+批量+风险可视化+区域打码+场景预设的一站式工具差异化明显。

## 盈利方式建议
freemium（去 EXIF/基础打码/少量张数免费）＋买断或订阅（批量不限量、HEIC、高级马赛克/水印、场景预设、尺寸/格式批量模板）。

## 存量数据与配置保护
全新工具，不改 image-converter 任何存储与配置；仅在共享纯函数层面复用，回归 image-converter 现有 E2E 确认无影响。

## 结论与依据
真实高频、纯前端可行、零资金、低侵入、单轮可交付，**列为本轮（2026-10-17）首选开发项**。
