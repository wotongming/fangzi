# 宠物健康档案与就医管家 · 使用指导

> 版本 1.0.0 · 更新于 2026-10-18

## 这个工具能做什么

给猫、狗等宠物建立一份**只存在本机**的健康档案：疫苗/驱虫/用药/就诊/症状/体重时间线、化验单处方照片、照护到期提醒、体重曲线、给兽医的病情时间线摘要、全年花费与**自记药价**对照、家庭档案包导入导出。

**重要边界**：本工具只做「记录、提醒、整理」，**不做疾病诊断、不推荐用药、不承诺疗效**，不能替代执业兽医；宠物出现异常请及时就医。药价是你本人手动记录的实付价，仅供换院参考，**不是市场报价**。

## 快速开始

1. 打开工具，点「建立第一只宠物档案」，填写名字、种类、性别（品种、生日、绝育、过敏、基础病可选）。
2. 保存后会自动生成两条常见照护计划：**每月驱虫**、**年度疫苗加强**（可停用、可改周期）。
3. 顶部是宠物切换条与五个分段页签：**待办 / 时间线 / 记一笔 / 就医 / 我的**（手机端页面底部另有方子应用主导航）。

## 记一笔

点顶部「➕ 记一笔」，选择类型（疫苗、驱虫、用药、就诊、症状、饮食、体重、药价）、日期，填写名称与备注，可拍照添加化验单/处方（自动压缩、去除拍摄信息、仅存本机）。

- 记录「疫苗/驱虫」时可在「关联照护计划」选择对应计划，系统会据此自动把下次到期日顺延一个周期。
- 「体重」填写 kg；「就诊/用药/药价/饮食」可填花费；「药价」建议同时填医院与规格，方便对照。

## 照护提醒

- **待办页**打开即显示下次该做什么、还剩几天或已逾期几天，点「已做」会自动补一条当天记录并顺延。
- 手机浏览器在应用完全关闭后**无法保证**收到后台通知，因此提供两种兜底：
  - 「开启通知」：仅在你打开本应用期间提醒；
  - **「导出到系统日历」（推荐）**：生成 `.ics` 文件，导入手机系统日历后由系统长期可靠提醒。
- 疫苗/驱虫程序因地区、品牌、动物个体差异很大，计划里的节奏只是常见参考，**请以执业兽医建议和当地规定为准**。

## 就医助手

- **病情时间线摘要**：选择时间范围，一键把症状、就诊、用药、既往史、过敏整理成结构化文字并复制，面诊时直接发给或念给兽医，避免讲不清。
- **体重曲线**：至少 2 次体重后绘制；短期明显波动请咨询兽医，曲线不用于诊断。
- **年度花费**：按类型汇总全年养宠支出。
- **自记药价对照**：同一药品在不同医院/时间的自录价格并排展示并标出最大相差，帮你换院时有个参照。

## 档案、换机与家人协作

在「我的 → 家庭档案包」：

- **导出 / 加密导出**：把全部宠物、记录与照片打包成一个文件，加密导出可设置口令（忘记无法恢复，请妥善保管）。
- **导入**：选择档案包恢复或合并（按记录合并，不会主动清空现有数据）；加密包需输入口令。
- 清理浏览器数据/卸载会删除本地档案，请**定期导出备份**。页面会显示本机照片占用与浏览器存储用量，占用偏高时可导出后删除旧宠物或旧照片。

## 免费与专业版

- 免费：单只宠物的档案、健康记录与照护提醒。
- 专业版（买断或订阅）：多宠档案、体重曲线与花费分析、病情摘要、家庭档案包导入导出。无论是否付费，数据都只保存在你的设备。

## 常见问题

- **为什么收不到提醒？** 移动 PWA 后台通知受系统限制，请用「导出到系统日历」获得可靠提醒；待办页每次打开都会重新计算逾期。
- **照片存在哪里、占空间吗？** 全部存在本机 IndexedDB，上传时自动压缩到长边约 1600px 并去除元数据，不上传服务器。
- **换手机怎么办？** 在旧机「导出档案包」，新机打开工具「导入」即可。
- **能帮我判断得了什么病、该吃什么药吗？** 不能。本工具刻意不提供诊断与用药建议，只帮你把信息整理清楚，交给专业兽医判断。
