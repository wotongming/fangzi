# PM 评估报告：可嵌入交互组件生成平台

- 对应 innovator：innovator_006_可嵌入交互组件生成平台.md
- 评估日期：2026-10-15
- 结论：**可集成（新增）**

## 与 fangzi 现有功能去重与整合判定

对照 fangzi README 与 `src/tools/`：现有工具无组件生成/表单生成/网站组件类功能（batch-text-processor 是文本处理，image-converter 是图片处理，均无交集）。innovator_006 是面向「站点运营者/创作者无代码生成可嵌入交互组件（表单/计算器/评分/反馈/图表）」的平台，对象与场景完全不同。

- **判定不重复** → 新增独立工具。

## 需求真伪判断

- 真需求。证据链：Web Components 被社区一致列为「第三方可嵌入 widget、CMS 站点（WordPress/Drupal）无框架嵌入」的核心适用场景；表单/问卷 SaaS（Typeform、Tally）与聊天组件（Intercom、Crisp）均为大规模订阅盈利模式；中文社区明确「嵌入式微件：聊天窗口、反馈按钮可直接嵌入任意第三方网站」是 WC 适用场景。WordPress 全球站点超 4 亿，无代码组件生成需求庞大。
- 使用频次：运营/创作者配置期低频、嵌入后长期使用+数据回流；与 fangzi 用户群匹配：fangzi 的「生活/工作」用户（自媒体、运营、个人站长）正是可嵌入组件（问卷/反馈/报名）的目标人群。

## 技术可行性

- 完全可行，纯前端实现：
  - 可视化配置：Vue 表单驱动组件类型/字段/逻辑（条件显示、计算规则）/主题（CSS 变量）；
  - 生成：模板生成含 Shadow DOM 的 Web Component 单文件脚本（无构建步骤，<script> 即用）；
  - 嵌入：产出 `<widget-x data-key="...">` 嵌入代码片段 + 远程脚本引用（脚本由静态托管提供，EdgeOne Pages 可承载）；
  - 数据回流：MVP 阶段提交数据本地导出 CSV（隐私可控）；可选配置 `VITE_WIDGET_ENDPOINT` 类端点做数据收集（与 fangzi 现有 VITE_FEEDBACK_ENDPOINT 模式一致，未配置则本地）。
- 技术风险：远程脚本更新机制（按 data-key 加载、版本化 URL）；跨站嵌入的 CSP/CORS 需说明。

## 集成成本与侵入性

- 新增 `src/tools/embed-widget-builder/`，工具框架自动发现，零核心/路由改动；
- 不触碰 SW/manifest；组件生成器轻量实现；
- 存量影响：无（纯新增）。

## 架构兼容性

- 与 fangzi 零后端纯前端架构兼容；产物是浏览器原生 Web Component，与 PWA 技术栈同构；
- 复用现有「可配置端点」模式（类似 VITE_FEEDBACK_ENDPOINT）处理数据回流，无自研后端。

## 平台合规评估

- EdgeOne Pages：静态托管承载生成器与组件脚本，无服务端函数需求；合规；
- 不进插件商店；内容合规：生成器产出的组件由用户自行嵌入其站点，收集数据需用户站点自行合规（工具内提示），平台无风险。

## 资金成本

- 零成本可行：全部自研/轻量 MIT 库（如 fflate），无付费服务依赖；数据回流可选免费端点或本地。

## 时间成本与开发难度

- 复杂度：中（可视化配置 + 模板生成 + 嵌入代码/数据导出）；
- 独立开发者估算：配置表单 2-3 天、生成器与模板 3 天、嵌入代码与数据导出 2 天、回归 1-2 天，合计约 8-10 人日。

## 用户真实价值

- 核心痛点：站点加交互组件要装插件/绑框架/写代码；iframe 样式冲突；跨技术栈分发组件重复实现；
- 使用频次：配置期低频、数据回流期长期使用；对 fangzi 价值：新增「站点建设/营销」场景，吸引运营/自媒体用户，freemium 订阅空间（对标 Typeform/Tally 模式）。

## 市场与竞争

- 竞品：Typeform/Tally（表单 SaaS，红海但订阅贵/偏专业）、Intercom/Crisp（聊天组件，企业向）、CMS 插件（平台绑定）；
- 差异化：免费基础 + Web Components 任意站点嵌入 + 样式隔离免 iframe + 工具集合生态；「无代码生成器 + WC 运行时」组合在平价市场差异明显。

## 盈利方式建议

- freemium：免费（基础组件、数据量限制）；Pro（buyout ¥39.90 或订阅）解锁更多模板、自定义逻辑、数据导出、品牌定制；可选按站点计费。

## 结论与依据

- **可集成（新增）**：与现有功能无重复；纯前端零资金可行、不破坏存量、平台合规；「可嵌入组件」付费模式已被 Typeform/Tally/Intercom 大规模验证，Web Components 无代码生成是差异化空白。
