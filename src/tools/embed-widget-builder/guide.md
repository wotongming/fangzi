# 可嵌入交互组件生成平台 · 用户指导

版本 1.0.0 · 更新于 2026-10-15

## 这是什么 / 能做什么

无代码生成「可嵌入任意网站的交互小组件」：选择模板 → 可视化配置文案、字段、计价规则、品牌色 → 实时预览并试提交 → 一键导出自包含、零依赖、Shadow DOM 样式隔离的 Web Component 单文件脚本，复制两段代码即可嵌入 React / Vue / 原生 HTML / WordPress 等任意技术栈站点。内置 5 类模板：报名 / 联系表单、满意度反馈、星级评分、价格计算器、活动倒计时。

**重要边界**：生成器本身在本机完成配置与导出；嵌入后收集的数据默认留在访问者浏览器，是否回传你的自有接口由你决定，站点侧的数据合规由你自己负责。

## 快速开始

1. 打开工具，先看到「我的组件」与模板卡片；点卡片即基于该模板新建一个组件（免费版最多保存 3 个）。
2. 在配置区修改标题、描述、按钮文字、成功提示，按需增删表单字段、设置选项 / 评分上限 / 计价规则 / 倒计时目标时间。
3. 点「保存并预览」，在预览区填写并提交，测试数据会回流到「测试提交」列表。
4. 填好脚本托管域名，下载 .js 脚本并复制两段嵌入代码，粘贴到目标网页。

## 分步用法

### 1. 选择模板 / 管理我的组件

- 免费版含前 3 类基础模板：报名 / 联系表单、满意度反馈、星级评分；价格计算器、活动倒计时为专业版模板。
- 免费版最多本地保存 3 个组件，超出需升级或先删除旧组件。

### 2. 可视化配置

- 修改标题、描述、按钮文字、成功提示。
- 联系表单可增删字段，改字段标题 / 数据键名 / 类型（文本 / 邮箱 / 多行 / 数字）与是否必填。
- 满意度反馈每行一个选项；星级可设上限与两端文案；价格计算器设数量名、单价、固定费用、货币；倒计时设目标时间与到期文案。
- 可设置品牌主色（预设色板或自定义取色）、圆角；专业版可关闭「由方子生成」角标。配置会实时保存。

### 3. 实时预览并试提交

- 预览区用与第三方站点一致的方式真实渲染组件（Shadow DOM 内样式与宿主页面隔离）。
- 可直接填写并点提交，成功提示出现的同时，这条测试数据回流到右侧「测试提交」列表（时间、类型、JSON）。

### 4. 导出脚本与复制嵌入代码

- 「下载 .js 脚本」得到单文件（零依赖）；也可下载一个可直接双击打开的 `demo.html` 验证效果。
- 在「脚本托管域名」填入你的站点地址（留空则用相对路径），复制两段代码：一段 `<script src=... defer>`，一段组件标签，粘贴到目标网页即可。

```html
<script src="https://your-site.com/widgets/v1/abc123.js" defer></script>
<widget-fz-abc123 data-key="abc123"></widget-fz-abc123>
```

- 如需把提交数据回传到自有服务，给组件标签加 `data-endpoint="https://你的接口"`，组件会以 keepalive POST JSON 到你的接口。

### 5. 数据面板（专业版）

- 在「数据」查看预览阶段产生的测试提交（时间、类型、JSON），专业版可一键导出带 UTF-8 BOM 的 CSV（Excel 直接识别中文）。

## 免费与专业版

- 免费：报名 / 联系表单、满意度反馈、星级评分 3 类基础模板；本地保存最多 3 个组件、实时预览、导出单文件脚本。
- 专业版（一次买断 ¥24.90）：价格计算器、活动倒计时 2 类进阶模板；不限组件数量、自定义品牌色、移除「由方子生成」角标；提交数据 CSV 导出与数据面板。

## 数据与隐私

- 生成器的组件配置只保存在本机浏览器；嵌入组件收集的数据默认写入访问者浏览器 localStorage（最多保留 200 条），不上传任何第三方。
- 配置 `data-endpoint` 后数据才 POST 到你自己的接口，受浏览器同源 / CORS 限制，嵌入第三方站点的数据不会跨域回流到本生成器。
- 宿主站点需允许该脚本加载（CSP 放行脚本 URL）；跨站收集数据时你的接口需正确配置 CORS。

## 常见问题

- **嵌入后页面样式会串吗？** 不会，组件用 Shadow DOM 封装，内部样式与宿主站点完全隔离。
- **React / Vue 项目能用吗？** 能，把 `<script>` 放到页面，JSX / 模板里直接写组件标签即可，它是浏览器原生自定义元素。
- **WordPress / Notion 怎么加？** 在支持自定义 HTML 的区块 / 代码嵌入块里粘贴那两段代码。
- **更新组件要改宿主代码吗？** 不用，宿主引用固定 URL 的脚本，重新生成并覆盖同名脚本即可，旧标签无需改动。

## 注意事项 / 功能边界

- 组件收集的用户数据由你自己的站点负责合规（请在站点提供隐私说明，问卷 / 录音等场景取得必要同意）。
- 组件本身最大宽度 440px 自适应；配置与预览在平板、手机下自动改为单列布局。
