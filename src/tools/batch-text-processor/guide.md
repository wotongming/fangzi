# 批量文本处理工坊 · 用户指导

## 解决什么问题
对成千上万行的名单、手机号、ID、文本批量做**去重、编号、排序、过滤、大小写与前后缀、分隔符转换**，不用再在 Excel 里反复操作。

## 怎么用
1. 把文本粘贴到「输入」框，每行一条。
2. 勾选需要的处理项（可组合）：去首尾空格、删空行、去重、编号、大小写、排序。
3. 需要统一加前后缀时填写「前缀」「后缀」；想合并成一行时填写分隔符（留空则仍按行输出）。
4. 点击「开始处理」，结果在右侧生成；下方「效果预览」不扣次数，可先确认效果。

## 计费说明
- 本工具为**按次计费**：每月赠送 20 次免费额度，用完后可购买额度包（示例 0.1 元/次，10 次起购），已购额度长期有效。
- 排序对中文使用中文拼音排序规则（`zh-Hans-CN`）。

## 边界
- 去重按「整行文本完全相同」判定，不做模糊/规范化去重。
- 单次处理在浏览器内存中完成，建议单次不超过数十万行，超大列表可分批。
