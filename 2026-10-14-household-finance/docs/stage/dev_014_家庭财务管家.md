## 技术选型落地
Vue3 + TS + 原生 CSS；IndexedDB 本地存储；图表轻量库（确认商用授权）；可选自托管同步；订阅制计费。

## 模块设计
- `store.ts`：IndexedDB 封装（账目/分类/预算 CRUD + 同步）
- `ledger.ts` / `budget.ts` / `report.ts` / `insight.ts`：纯函数业务
- `index.vue`：UI（记账 + 看板 + 预算 + 报表 + 洞察）

## 关键实现方法
```ts
// store.ts 记账
export async function addLedger(entry) { await db.put('ledgers', entry); /* 触发预算/报表刷新 */ }
// budget.ts 超支预警
export function budgetStatus(spent, budget) { return { used: spent/budget, over: spent>budget }; }
// insight.ts 规则洞察
export function topCategory(entries, period) { /* 按分类聚合取占比最高 */ }
```
流程：记账 → 看板 → 预算预警 → 报表 → 洞察 →（订阅）同步。
