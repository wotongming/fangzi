# 用户使用指导书：家庭财务管家

- 对应 dev：`dev_014_家庭财务管家.md`
- 日期：2026-10-14
- 版本：v1.0.0

## 功能简介

把微信、支付宝、银行卡等各平台的收支拢进一个**本地家庭账本**，提供记账分类、月度预算与超支预警、月/年报表与趋势、省钱洞察，形成「记录 → 分析 → 决策 → 行动」的财务闭环。数据只存在浏览器本地（IndexedDB），不上传服务器。

## 运行环境要求

- 浏览器：Chrome / Edge 90+、Firefox 90+、Safari 15+（需支持 IndexedDB；加密备份需 Web Crypto）
- 平台：桌面端与移动端浏览器自适应；作为 PWA 可离线使用、可安装到桌面/主屏
- 依赖：无自研后端、无第三方服务，纯前端运行

## 安装与启动

1. 打开「方子」PWA（首页搜索框输入“记账”或“家庭账本”，或从「全部工具」列表进入）。
2. 点击结果卡片进入「家庭财务管家」工具页。
3. 无需安装或配置：首次打开自动初始化本地账本（内置常用分类），直接开始记账。
4. 常用可点「☆ 添加到首页」收藏；支持 PWA 安装（浏览器地址栏安装图标），安装后离线可用。

## 使用说明

### 场景 1：记账（记一笔支出/收入）

1. 切到「记账」页，选择「支出」或「收入」。
2. 填写金额（元，支持小数）、分类（内置+自定义）、平台（微信/支付宝/银行卡/现金/信用卡/其他）、日期、备注与标签。
3. 点「记一笔」即保存；「最近流水」可查看最近 10 条并随时删除误记。

![记账界面](docs/shots/01-ledger.png)

### 场景 2：看板（钱花哪了）

「看板」页展示本月收入/支出/结余 KPI、支出分类占比环形图、支出平台分布，一眼看清消费结构。

![看板界面](docs/shots/02-board.png)

### 场景 3：预算与超支预警

1. 切到「预算」页，为总支出或每个分类设置每月预算（元），点「保存预算」。
2. 保存后每行实时显示使用进度；超支进度条变红并提示超支比例。
3. 未设预算的分类留空即可。

![预算超支预警](docs/shots/03-budget-over.png)

### 场景 4：月度 / 年度报表（Pro）

「报表」页选择月份查看：收入/支出/结余、支出结构分类占比环形图、月内每日支出趋势、近 12 个月收支趋势图。未订阅时显示升级引导。

![报表界面](docs/shots/04-report.png)

### 场景 5：省钱洞察（Pro）

「洞察」页自动给出：高占比可优化类目（≥30%）、预算超支/接近上限、支出环比上升 ≥15%、储蓄率 ≥30% 等建议。

![洞察界面](docs/shots/05-insight.png)

### 场景 6：数据备份与恢复

页面底部「数据备份与恢复」：
- 导出备份：不填口令导出明文 JSON；填写口令导出 AES-GCM 加密备份（Pro）。
- 恢复导入：选择备份文件（加密备份需输入导入口令）→「恢复导入」，自动清空并还原账目/分类/预算。
- 清空全部本地数据：危险操作，需确认。

## 常见问题（FAQ）

| 问题 | 说明 |
|---|---|
| 数据会不会上传？ | 不会。全部数据存浏览器 IndexedDB，纯本地运行。 |
| 换浏览器/清缓存会丢数据吗？ | 会。建议定期导出备份；同一浏览器内刷新/重开不丢。 |
| 加密备份口令忘了怎么办？ | 无法找回。请用明文备份或牢记口令。 |
| 报表/洞察怎么解锁？ | 点击「升级 Pro ¥29.90/月」订阅解锁（报表/洞察/加密备份）。记账与预算永久免费。 |
| 金额精度？ | 内部按「分」存储，展示保留两位小数，避免浮点误差。 |

## 注意事项

- 数据仅存本地浏览器，**清除浏览器数据会丢失账目**，重要数据请定期导出备份。
- 加密备份口令忘记无法找回，请妥善保存。
- 金额单位为人民币元，展示保留两位小数。
- 订阅为方子平台统一的 Freemium 订阅（当前为本地模拟支付，接入真实支付后自动生效）。
