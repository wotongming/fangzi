> 第一次使用，可在方子页面顶部导航点「**开方指南**」随时回到本手册。

## 2. 打开与安装（PWA）

「方子」是 PWA（渐进式 Web 应用），用现代浏览器访问部署地址即可使用，也可以像原生 App 一样安装到桌面 / 主屏。

### Windows / macOS（Chrome、Edge）

1. 用 Chrome 或 Edge 打开方子网址。
2. 地址栏右侧会出现「安装」图标（一个小方块带向下箭头），点击它；或点击浏览器右上角菜单 →「投放、保存和分享 / 应用」→「安装此网站为应用 / 将方子安装为应用」。
3. 确认后，桌面 / 开始菜单 / 程序坞会出现「方子」图标，双击即以独立窗口打开，看不到浏览器地址栏，体验接近桌面软件。

### Android（Chrome）

打开网址 → 右上角菜单 →「添加到主屏幕 / 安装应用」→ 主屏出现方子图标。

### iPhone / iPad（Safari）

用 **Safari** 打开网址 → 底部分享按钮 →「添加到主屏幕」→ 打开即可全屏使用。

> 安装后，应用外壳会被缓存，**断网也能打开**已访问过的工具。首次使用建议在联网状态下完整打开一次；用到本地 AI 的工具建议先在 Wi-Fi 下下载一次模型。

## 3. 我的方子与搜索

底部第一个标签「**我的方子**」是你的私人收藏柜，只放你收藏的常用工具，从上到下依次是：

- **紧凑搜索入口**：首页顶部一条浅色搜索条，点进去打开独立搜索页；手机端也可以在页面顶部**垂直下拉**（拉到约 1/4 屏）唤起搜索，未拉够会自动回弹。
- **我收藏的工具**：收藏后才出现，以紧凑胶囊形式一键进入，点右侧 × 可移除（详见第 5 节）。
- **空收藏态**：还没收藏时显示引导，点「去方子铺逛逛」进入全部工具浏览页。

### 搜索页怎么用

- **搜索框**：占位提示「说说你遇到的问题，给你开个小方子」。
- **开方子按钮**：输入问题后点击（或直接回车）搜索。输入为空时按钮置灰。
- **大家都在问**：随机浮动的常见口语问题，点任意一条即按该问题搜索；点「换一批」重新抽取。这些示例都经过回归校验，**保证能搜到对应工具**。

### 怎么搜得更准

直接说「人话」即可，不必想关键词。例如：

- 「被公司裁员，N+1 赔偿到底怎么算？」→ 命中离职补偿金计算器
- 「国庆加班 7 天，加班费能拿多少？」→ 命中加班费计算器
- 「1728000000 这个时间戳对应几号？」→ 命中时间戳转换工具

结果页顶部会显示当前检索模式、耗时与命中数量；命中的文字会用**高亮色块**标出，方便判断是不是你要的工具。

- 未配置 AI 时：显示「关键词检索（2-gram + 关键词重叠）」。
- 配置 AI 后：搜索走「向量 + 关键词」混合检索；当 AI 接口不可用，会提示「向量通道暂不可用已自动降级」，搜索依然正常返回结果（见第 8 节）。

## 4. 使用一个工具

在搜索结果或「方子铺」（全部工具）页，点击工具卡片进入：

- **网页工具**：点开即是可用的功能页。页面顶部固定工具条，左侧可返回，右侧始终提供：
  - **☆ 收藏到我的方子 / ★ 已收藏到我的方子**：收藏开关；
  - **用户指导**：查看该工具的使用说明、边界与注意事项。
- **插件类工具**：点开是「使用手册 + 下载」页面（详见第 7 节），不直接运行功能。

各工具只做一件事，页面内会有必要的输入项、选项和结果区。涉及法律、税务、薪酬、健身的工具结果均为**参考**，页面会注明口径与免责提示，实际以当地政策、专业意见或与单位核实为准。

### 手机端：底部导航与全屏沉浸

- **底部主导航**：在手机（及宽度 ≤820px 的设备）上打开方子，屏幕底部会出现四个线性图标标签——**我的方子**（收藏柜）、**方子铺**（全部工具）、**开方指南**（使用帮助）、**设置**，点一下即可切换，当前所在页的标签会高亮；同时顶部那条只放 Logo 的品牌栏会隐藏（导航已在底部），内容从屏幕顶部安全区直接开始，把纵向空间都让给内容。底部栏会自动避开 iPhone 的 Home 指示条和安卓手势条，不会被挡住。
- **边到边布局**：手机上两侧留白更小、内容更接近屏幕边缘，长列表/棋盘/画面能用满屏幕；阅读类内容仍保留舒适行宽。
- **一键全屏（沉浸）**：小游戏合集、健身摄像头这类适合专注使用的工具，顶部工具条会出现「⛶ 全屏」按钮。点一下即隐藏应用顶栏和底部标签、画面铺满整个安全区，更有沉浸感；再点左上角「✕ 退出全屏」即可恢复。安卓/桌面浏览器若支持系统全屏会一并进入，iPhone 等不支持系统全屏的设备也能用应用内全屏，体验不受影响。按系统返回或切到其它页面时也会自动退出全屏。
- **PC / 平板宽屏不变**：在电脑或较宽的平板上，方子仍是顶部导航 + 页脚 + 居中等宽布局，底部标签不会出现。

## 5. 收藏常用工具到我的方子

1. 进入任一工具页，点击右上角「☆ 收藏到我的方子」，按钮变为「★ 已收藏到我的方子」即收藏成功。
2. 回到「我的方子」，出现「我收藏的工具」胶囊分区，可一键进入。
3. 再点一次「★ 已收藏到我的方子」即可取消收藏。

收藏只保存在**当前浏览器本机**，清除浏览器站点数据会一并清除。

## 7. 浏览器插件的下载与安装

以「方子助手浏览器插件」为例（适用于 Chrome / Edge / Brave 等 Chromium 内核浏览器，版本 102 及以上）。

### 下载

在搜索或全部工具中打开「方子助手浏览器插件」，页面展示插件版本、体积、适配的浏览器最低版本，并提供两个按钮：

- **直接下载 zip**；
- **校验 SHA256 后下载**（推荐）：先在浏览器内用 WebCrypto 计算压缩包哈希，与页面公布值一致才允许点「保存已校验文件」，可防止下载损坏或被篡改。

页面会显示官方 SHA256，你也可以下载后用系统命令复核：

```bash
# macOS / Linux
shasum -a 256 fangzi-companion-chrome-0.1.0.zip
# Windows PowerShell
Get-FileHash .\fangzi-companion-chrome-0.1.0.zip -Algorithm SHA256
```

计算结果应与页面公布值一致；不一致切勿加载。

### 安装（加载已解压的扩展程序）

1. 将 zip 解压到一个**固定目录**（加载后不要删除该目录）。
2. 浏览器地址栏打开 `chrome://extensions`（Edge 为 `edge://extensions`）。
3. 打开右上角「开发者模式」。
4. 点「加载已解压的扩展程序」，选择解压出的目录。
5. 扩展列表出现「方子助手」即安装成功，可固定到工具栏。

### 使用

- 在任意网页**选中文字 → 右键 →「用方子搜索」**，会新开标签页用该文字搜索方子工具。
- 点击工具栏插件图标可快速打开方子、配置站点地址。
- 「划词 AI 解读」为高级功能（¥6.90），解锁后把授权码填入插件设置即可；插件本身不接触支付密钥，授权由方子站点校验。
- 卸载：在扩展管理页点「移除」，本地保存的设置随之清除。

## 8. 让首页搜索更懂「口语」（可选）

不配置任何 AI 也能正常使用关键词检索。想要「换个说法、口语化描述」也能更准地在首页**找到工具**，可开启向量混合检索（这是「找工具」用的检索增强，与本地知识库等工具内部的本地模型是两回事）：

1. 进入右上角「设置」→「AI 语义检索（可选）」。
2. 填写三项：
   - **接口基础地址（Base URL）**：OpenAI 兼容的 Embedding 服务地址，如 `https://api.openai.com/v1` 或你自建 / 第三方兼容网关；
   - **嵌入模型名称**：如 `text-embedding-3-small`、`bge-m3` 等；
   - **API Key**；
   - Embeddings 路径一般留空（默认 `/embeddings`），网关路径特殊时才需自定义。
3. 点「保存」，状态变为「已配置完整参数，搜索走混合检索」。
4. 点「测试连接并建立向量索引」可预先把全部工具向量化并缓存，首次搜索更快。
5. 不想要时点「清除配置」即恢复纯关键词检索。

说明：API Key 与配置**只保存在当前浏览器本机**（localStorage），向量缓存保存在 IndexedDB；接口超时或报错会自动降级，不影响使用。**不配置也完全不影响**本地知识库、语音转写、健身教练等工具——它们用的是随站下载、端侧运行的本地模型。

## 9. 没找到工具？提交需求

当某次搜索「命中 0 个工具」，结果区会出现：

> **暂时没有对症的工具**
> 没找到想要的工具？告诉我们你需要什么，我们会考虑开发

点击该提示，弹出反馈窗口。我们**推荐用系统邮件**反馈：在窗口里先选类型——

- **💡 提新需求**：希望方子增加还没有的工具 / 功能；
- **🔧 优化旧工具**：对已有工具的体验、结果或兼容性提出改进。

选定后点「✉️ 打开邮件」，会自动调起你设备上的邮件 App，并已**自动填好收件人 fangziasia@163.com、主题和正文开头模板**（新需求会引导你写清「使用场景 / 现有麻烦 / 希望做到」；优化会引导你写清「哪个工具 / 什么操作 / 期望与实际表现」），按提示补充几句直接发送即可，**无需手动输入邮箱地址**。

- 也可点窗口底部「改用网页表单提交」，用一句话描述想要的工具（例如「希望做一个把多张证件照批量压缩到 200KB 以内并统一改尺寸的工具」）。
- 网页表单在配置服务端投递时会即时发送；未配置 / 当前离线时先在本机排队，可在「设置 → 意见反馈」查看待发队列条数并手动补发。
- 「设置」页也提供「✉️ 提新需求 / 🔧 优化已有工具」两个直达邮件入口。

## 10. 隐私与数据说明

- **本地优先**：文件哈希、图片转换、密码生成、JSON / 正则 / 文本处理，以及知识库问答、语音转写、摄像头健身等，均在浏览器本地完成，默认不上传你的内容。
- **本地 AI 模型**：bge 语义、Whisper 语音、MediaPipe 姿态等模型从方子**同源域名**下载（不走境外源），缓存在浏览器 Cache Storage，之后可离线推理；摄像头画面只做实时分析，不录制、不存储、不上传。
- **本机存储**：收藏、订单与用量、AI 配置、待发反馈分别保存在浏览器 localStorage / IndexedDB，键名形如 `fangzi:*`；向量缓存的 IndexedDB 库名为 `fangzi-vectors`，各本地工具另有各自独立的本地库（如知识库、健身、简历）。
- **仅有的网络请求**（在你主动使用对应能力时）：使用本地 AI 工具时从方子站点下载模型文件；配置后调用你指定的 Embedding 接口做首页语义检索；配置后把反馈 / 支付请求发到部署方指定的服务端。未配置则不发起后两类请求。
- 在「设置」页底部可「清空本机数据」（AI 配置、收藏、订单与用量、反馈队列）。

## 11. 常见问题 FAQ

**Q：一定要联网 / 安装吗？**
A：不安装也能用；安装成 PWA 后离线可打开应用外壳与已缓存工具。首次下载本地 AI 模型、在线 Embedding、反馈补发、真实支付时需要联网。

**Q：本地知识库 / 语音转写 / 健身教练要配 API Key 吗？模型从哪来？**
A：不需要。它们用的是随方子站点同源自托管、在你设备端本地运行的模型，首次使用在 Wi-Fi 下下载一次即可，之后可离线；数据不出设备。

**Q：搜不到我想要的工具怎么办？**
A：换个更大白话、包含场景的说法再试一次；仍没有就点无结果提示提交需求，或邮件 fangziasia@163.com 告诉我们。

**Q：为什么显示「向量通道暂不可用已自动降级」？**
A：你在「设置」里配置了首页语义检索，但 Embedding 接口暂时连不通（网络、Key、地址等），方子已自动回退到关键词检索，结果不受影响；可到设置页点「测试连接」排查。不用该功能可直接忽略。

**Q：点了购买真的会扣钱吗？**
A：当前为本地模拟支付，不产生真实扣款，仅用于体验解锁与额度流程；正式上线接入真实收银台前会有明确的金额与支付确认。

**Q：换浏览器 / 清缓存后收藏和已购记录还在吗？**
A：这些数据存在当前浏览器本机，换浏览器或清除站点数据会丢失；正式版接入账号体系或远程权益后端后可跨设备同步。

**Q：法律 / 税务 / 薪酬 / 健身结果能直接作为依据吗？**
A：不能。相关工具结果仅供参考，法律税务薪酬以现行法律法规、当地政策、官方口径及与用人单位核实 / 专业咨询为准；健身纠错不能替代专业教练，动作不适请立即停止。

**Q：支持哪些浏览器？**
A：推荐近一年版本的 Chrome、Edge、Safari、Firefox（覆盖主流用户的绝大多数）。插件仅支持 Chromium 内核 102+。摄像头姿态识别建议用较新的 Chrome/Edge；图片转换依赖 Canvas、哈希依赖 WebCrypto、密码依赖加密随机数，均为现代浏览器标准能力；极旧浏览器可能不可用。
